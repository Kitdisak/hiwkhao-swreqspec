# งาน: จองห้องอ่านหนังสือ / ห้องประชุม

อ้างอิง: SPEC-จองห้องอ่านหนังสือ-ห้องประชุม-009 (Draft v2)

## ลำดับงาน

### ยืนยันประเด็นคงค้าง

- [ ] **T-01** ยืนยันว่าช่วงเวลาที่ปลายช่วงต่อกันพอดีนับว่าซ้อนหรือไม่ — **รอ Q-01** (FR-จองห้องอ่านหนังสือ-/-ห้องประชุม-01, NFR-CONC-01, NFR-DATA-01, Constraint: ห้องเดียวกันห้ามจองซ้อน)
- [ ] **T-02** ยืนยันว่าต้องปฏิเสธเมื่อจำนวนผู้ใช้เกินความจุห้องหรือไม่ — **รอ Q-02** (FR-จองห้องอ่านหนังสือ-/-ห้องประชุม-01)
- [ ] **T-03** ยืนยันวิธีตัดสินและแจ้งผลเมื่อคำขอพร้อมกัน — **รอ Q-03** (FR-จองห้องอ่านหนังสือ-/-ห้องประชุม-02, FR-จองห้องอ่านหนังสือ-/-ห้องประชุม-03, NFR-CONC-01)
- [ ] **T-04** ยืนยันว่าต้องให้ผู้ใช้ยืนยันซ้ำหลังเลือกเวลาใหม่หรือไม่ — **รอ Q-04** (FR-จองห้องอ่านหนังสือ-/-ห้องประชุม-04)
- [ ] **T-05** ยืนยัน AC/NFR mapping และวิธีตรวจ concurrency — **รอ Q-05** (FR-จองห้องอ่านหนังสือ-/-ห้องประชุม-02, NFR-CONC-01, NFR-DATA-01, AC-จองห้องอ่านหนังสือ-/-ห้องประชุม-01)
- [ ] **T-06** ตรวจนโยบายหรือค่ากำหนด UC Case.pdf — **รอ Q-06** (FR-จองห้องอ่านหนังสือ-/-ห้องประชุม-01)

### พัฒนาและทดสอบ

- [ ] **T-07** รับห้อง วัน เวลาเริ่ม-สิ้นสุด และจำนวนผู้ใช้; ไม่ให้เลือกเวลาที่ผ่านไปหรือมีรายการจอง (FR-จองห้องอ่านหนังสือ-/-ห้องประชุม-01, Constraint: ผู้ใช้เข้าสู่ระบบและห้องว่าง)
- [ ] **T-08** ตรวจสอบความว่างอีกครั้งก่อนบันทึก (FR-จองห้องอ่านหนังสือ-/-ห้องประชุม-02)
- [ ] **T-09** เมื่อยืนยันและห้องยังว่าง สร้างรายการและล็อกช่วงเวลาโดยป้องกันช่วงซ้อน — **รอ Q-01, Q-03** (FR-จองห้องอ่านหนังสือ-/-ห้องประชุม-03, NFR-CONC-01, NFR-DATA-01, Constraint: ห้องเดียวกันห้ามจองซ้อน)
- [ ] **T-10** เมื่อผู้ใช้เลือกเวลาใหม่ ให้ตรวจความว่างของช่วงใหม่และใช้ขั้นตอนยืนยันตามคำตอบทีม — **รอ Q-04** (FR-จองห้องอ่านหนังสือ-/-ห้องประชุม-04)
- [ ] **T-11** หากผู้อื่นจองก่อน แจ้งว่าห้องไม่ว่างและให้เลือกเวลาใหม่ (FR-จองห้องอ่านหนังสือ-/-ห้องประชุม-05)
- [ ] **T-12** ทดสอบยืนยันจองช่วงว่างและล็อกเวลา (FR-จองห้องอ่านหนังสือ-/-ห้องประชุม-01, FR-จองห้องอ่านหนังสือ-/-ห้องประชุม-02, FR-จองห้องอ่านหนังสือ-/-ห้องประชุม-03, AC-จองห้องอ่านหนังสือ-/-ห้องประชุม-01)
- [ ] **T-13** ทดสอบกรณีผู้อื่นจองก่อนยืนยันและให้เลือกเวลาใหม่ (FR-จองห้องอ่านหนังสือ-/-ห้องประชุม-02, FR-จองห้องอ่านหนังสือ-/-ห้องประชุม-05, AC-จองห้องอ่านหนังสือ-/-ห้องประชุม-02)
- [ ] **T-14** ทดสอบการตรวจความว่างหลังผู้ใช้เลือกเวลาใหม่ (FR-จองห้องอ่านหนังสือ-/-ห้องประชุม-04, AC-จองห้องอ่านหนังสือ-/-ห้องประชุม-03)
- [ ] **T-15** ทดสอบช่วงเวลาขอบเขตและคำขอพร้อมกันตามเกณฑ์ที่ทีมยืนยัน — **รอ Q-01, Q-03, Q-05** (FR-จองห้องอ่านหนังสือ-/-ห้องประชุม-02, FR-จองห้องอ่านหนังสือ-/-ห้องประชุม-03, NFR-CONC-01, NFR-DATA-01)
