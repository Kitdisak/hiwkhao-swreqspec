# งาน: ดูรายงานและสถิติห้องสมุด

อ้างอิง: SPEC-ดูรายงานและสถิติห้องสมุด-015 (Draft v2), [plan.md](./plan.md)

## ลำดับงาน

### พัฒนาและทดสอบตามข้อกำหนด

- [x] **T-01** เพิ่ม Permission `view_reports` หรือชื่อ Permission เดียวกันในรายการสิทธิ์ของระบบและให้ Role Admin กับ Librarian มี Permission นี้; Role Member ต้องไม่มี Permission นี้ตาม SPEC-014 (NFR-SEC-01, ASM-04, ASM-11) — สำเร็จ
- [x] **T-02** เพิ่ม guard ตรวจ session และ Permission `view_reports` สำหรับหน้ารายงาน API ดูรายงาน และ API ส่งออก; ไม่มี session ตอบ 401 และพาไปหน้าเข้าสู่ระบบ; มี session แต่ไม่มีสิทธิ์ตอบ 403 พร้อม “คุณไม่มีสิทธิ์ดูรายงาน” และเมนูรายงานไม่แสดง (NFR-SEC-01, ASM-11, AC-ดูรายงานและสถิติห้องสมุด-05) — สำเร็จ
- [x] **T-03** สร้างบริการอ่านข้อมูล read-only จาก SQLite เดิมสำหรับ Loan/Copy Title/Book FineItem และ RoomBooking โดยไม่สร้างตารางที่เก็บรายงานหรือคัดลอกข้อมูลรายงาน (Constraint: รายงานอ้างอิงข้อมูลจาก SQLite เดิม, FR-ดูรายงานและสถิติห้องสมุด-03) — สำเร็จ
- [x] **T-04** เพิ่มตัวตรวจช่วงวันที่ Asia/Bangkok ที่รวมวันเริ่มต้นและวันสิ้นสุด ตรวจวันสิ้นสุดไม่เกินวันนี้ ตรวจช่วงไม่เกิน 1 ปี และวันสิ้นสุดไม่น้อยกว่าวันเริ่ม; ปฏิเสธก่อน query ด้วยสาเหตุที่สอดคล้อง (FR-ดูรายงานและสถิติห้องสมุด-01, ASM-01, ASM-13, AC-ดูรายงานและสถิติห้องสมุด-04) — สำเร็จ
- [x] **T-05** สร้างรายงานการยืมจำนวน Copy ที่วันที่ยืมอยู่ในช่วง และรายงานหนังสือยอดนิยม 10 อันดับจากจำนวนยืมต่อชื่อเรื่องรวมทุก Copy พร้อมเรียงมากไปน้อย ก-ฮ/A-Z สำหรับชื่อเท่ากันแล้วรหัสหนังสือตามลำดับน้อยไปมาก (FR-ดูรายงานและสถิติห้องสมุด-03, ASM-02, ASM-10) — สำเร็จ
- [x] **T-06** สร้างรายงานค่าปรับแยกยอดค่าปรับที่เกิดขึ้นทั้งหมด ชำระแล้ว และยังไม่ชำระ โดยนับตามวันที่รับคืนที่สร้างรายการ FineItem และดูสถานะชำระ ณ เวลาที่ดูรายงาน; แสดงทศนิยม 2 ตำแหน่ง (FR-ดูรายงานและสถิติห้องสมุด-03, ASM-08) — สำเร็จ
- [x] **T-07** สร้างรายงานการใช้ห้องต่อห้องจำนวนรายการจองและจำนวนชั่วโมงที่ถูกจอง โดยไม่นับสถานะยกเลิกและนับตามช่วง start time ภายในช่วงที่เลือก ไม่ใช่วันที่กดจอง (FR-ดูรายงานและสถิติห้องสมุด-03, ASM-09) — สำเร็จ
- [x] **T-08** เพิ่มหน้า `/reports` และ API `GET /api/reports` สำหรับเลือกช่วงวันที่และประเภทรายงานจากข้อมูลชุดเดียวกัน แสดงกราฟ/สถิติ เมนูตามสิทธิ์ และข้อความ “ไม่พบข้อมูลในช่วงเวลาที่เลือก” เมื่อไม่มีข้อมูล (FR-ดูรายงานและสถิติห้องสมุด-01, FR-ดูรายงานและสถิติห้องสมุด-02, FR-ดูรายงานและสถิติห้องสมุด-05) — สำเร็จ
- [x] **T-09** เพิ่ม API export และการสร้าง CSV จาก rows เดียวกับรายงานที่แสดง โดยใช้ UTF-8 พร้อม BOM comma หัวคอลัมน์ภาษาไทยตรงหน้าจอ วันที่ YYYY-MM-DD ยอดทศนิยม 2 ตำแหน่งไม่มีคอมมาหลักพันและไม่มีคำว่าบาท และชื่อ `report-<ประเภท>-<วันเริ่ม>-<วันสิ้นสุด>.csv` (FR-ดูรายงานและสถิติห้องสมุด-04, ASM-03) — สำเร็จ
- [x] **T-10** สำหรับกรณีไม่มีข้อมูล ปิดปุ่มส่งออก CSV ในหน้าจอ และให้ API export ตรงไม่สร้างไฟล์แต่ตอบ “ไม่พบข้อมูลในช่วงเวลาที่เลือก” รวมถึงไม่ประมวลผลกรณีช่วงไม่ถูกต้อง (FR-ดูรายงานและสถิติห้องสมุด-01, FR-ดูรายงานและสถิติห้องสมุด-05, ASM-12, ASM-13) — สำเร็จ
- [x] **T-11** ทดสอบ **AC-ดูรายงานและสถิติห้องสมุด-01** ด้วย `test_AC_ดูรายงานและสถิติห้องสมุด_01_report_metrics` — สร้าง fixture Loan/Copy/Title/FineItem/RoomBooking ในช่วงวันที่แล้วตรวจการนับ ประเภทรายงาน ลำดับอันดับและสิทธิ์ (AC-ดูรายงานและสถิติห้องสมุด-01, FR-ดูรายงานและสถิติห้องสมุด-01, FR-ดูรายงานและสถิติห้องสมุด-02, FR-ดูรายงานและสถิติห้องสมุด-03, NFR-SEC-01) — สำเร็จ
- [x] **T-12** ทดสอบ **AC-ดูรายงานและสถิติห้องสมุด-02** ด้วย `test_AC_ดูรายงานและสถิติห้องสมุด_02_csv_export` และ **AC-03** ด้วย `test_AC_ดูรายงานและสถิติห้องสมุด_03_no_data` — ตรวจ CSV เท่ากับหน้าจอ รูปแบบไฟล์ ชื่อไฟล์ สิทธิ์ส่งออก ปิดปุ่ม ไม่มีข้อมูล และ API ไม่สร้างไฟล์ (AC-ดูรายงานและสถิติห้องสมุด-02, AC-ดูรายงานและสถิติห้องสมุด-03, FR-ดูรายงานและสถิติห้องสมุด-04, FR-ดูรายงานและสถิติห้องสมุด-05) — สำเร็จ
- [x] **T-13** ทดสอบ **AC-ดูรายงานและสถิติห้องสมุด-04** ด้วย `test_AC_ดูรายงานและสถิติห้องสมุด_04_invalid_range` และ **AC-05** ด้วย `test_AC_ดูรายงานและสถิติห้องสมุด_05_report_permission` — ตรวจสามกรณีช่วงวันที่ไม่ถูกต้อง, 401/403, ข้อความปฏิเสธ เมนูและไม่เปิดเผยข้อมูลหน้า/API/export (AC-ดูรายงานและสถิติห้องสมุด-04, AC-ดูรายงานและสถิติห้องสมุด-05, FR-ดูรายงานและสถิติห้องสมุด-01, NFR-SEC-01) — สำเร็จ
- [x] **T-14** ทดสอบ **NFR-PERF-01** ด้วย `test_NFR_PERF_015_report_95_percent_under_5_seconds` — สร้าง dataset 1 ปีตามจำนวนนั้นใน NFR-PERF-01, จำลองเจ้าหน้าที่ 10 คน พร้อมกัน และตรวจอย่างน้อย 95% ของคำขอแสดงรายงานครบภายใน 5 วินาที (NFR-PERF-01, ASM-06) — สำเร็จ
