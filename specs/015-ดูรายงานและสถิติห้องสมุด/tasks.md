# งาน: ดูรายงานและสถิติห้องสมุด

อ้างอิง: SPEC-ดูรายงานและสถิติห้องสมุด-015 (Draft v2)

## ลำดับงาน

- [ ] **T-01** ตรวจการเข้าสู่ระบบและสิทธิ์ก่อนอนุญาตดูหรือส่งออกรายงานทุกประเภท (FR-ดูรายงานและสถิติห้องสมุด-01, FR-ดูรายงานและสถิติห้องสมุด-04, NFR-SEC-01, Constraint: ผู้บริหารเข้าสู่ระบบและมีสิทธิ์ดูรายงาน)
- [ ] **T-02** ใช้ข้อมูลการใช้งานที่มีอยู่เป็นแหล่งรายงาน โดยไม่แก้ธุรกรรมต้นทาง (FR-ดูรายงานและสถิติห้องสมุด-02, FR-ดูรายงานและสถิติห้องสมุด-03, Constraint: รายงานอ้างอิงข้อมูลการใช้งานที่มีอยู่)
- [ ] **T-03** รับช่วงเวลาและประเภทรายงาน โดยรวมวันเริ่มต้น/สิ้นสุดตามเวลาท้องถิ่นของห้องสมุด (FR-ดูรายงานและสถิติห้องสมุด-01)
- [ ] **T-04** ประมวลผลและแสดงรายงานในรูปกราฟหรือสถิติตามประเภทที่เลือก (FR-ดูรายงานและสถิติห้องสมุด-02, FR-ดูรายงานและสถิติห้องสมุด-03)
- [ ] **T-05** คำนวณตัวชี้วัดทั้ง 4 ประเภท: จำนวนรายการยืม, หนังสือยอดนิยมเรียงจากการยืมมากไปน้อย, ยอดค่าปรับรวม, จำนวนรายการจองห้อง (FR-ดูรายงานและสถิติห้องสมุด-03)
- [ ] **T-06** ส่งออก CSV ที่มีข้อมูลเดียวกับรายงานที่แสดง และตรวจสิทธิ์ก่อนส่งออก (FR-ดูรายงานและสถิติห้องสมุด-04, NFR-SEC-01)
- [ ] **T-07** เมื่อไม่มีข้อมูลในช่วงเวลาที่เลือก แจ้งว่าไม่มีข้อมูล (FR-ดูรายงานและสถิติห้องสมุด-05)
- [ ] **T-08** กำหนดเป้าหมายเวลาและชุดข้อมูลสำหรับ NFR-PERF-01 ก่อนทดสอบ (FR-ดูรายงานและสถิติห้องสมุด-02, NFR-PERF-01, ASM-06)
- [ ] **T-09** ทดสอบตัวชี้วัด/ช่วงวันที่และสิทธิ์ดูรายงาน (FR-ดูรายงานและสถิติห้องสมุด-01, FR-ดูรายงานและสถิติห้องสมุด-02, FR-ดูรายงานและสถิติห้องสมุด-03, NFR-SEC-01, AC-ดูรายงานและสถิติห้องสมุด-01)
- [ ] **T-10** ทดสอบส่งออก CSV และตรวจว่าข้อมูลตรงกับรายงานที่แสดง (FR-ดูรายงานและสถิติห้องสมุด-04, NFR-SEC-01, AC-ดูรายงานและสถิติห้องสมุด-02)
- [ ] **T-11** ทดสอบช่วงเวลาที่ไม่มีข้อมูลและตรวจข้อความแจ้ง (FR-ดูรายงานและสถิติห้องสมุด-01, FR-ดูรายงานและสถิติห้องสมุด-05, AC-ดูรายงานและสถิติห้องสมุด-03)
- [ ] **T-12** วัดเวลาประมวลผลตามเป้าหมายและชุดข้อมูลที่กำหนดไว้ (FR-ดูรายงานและสถิติห้องสมุด-02, NFR-PERF-01, ASM-06)
