# งาน: ดูรายงานและสถิติห้องสมุด

อ้างอิง: SPEC-ดูรายงานและสถิติห้องสมุด-015 (Draft v2)

## ลำดับงาน

- [x] **T-01** ตรวจการเข้าสู่ระบบและสิทธิ์ก่อนอนุญาตดูหรือส่งออกรายงานทุกประเภท — สำเร็จ: FR-ดูรายงานและสถิติห้องสมุด-01, FR-ดูรายงานและสถิติห้องสมุด-04 และ NFR-SEC-01 ระบุว่าระบบต้องให้ผู้ใช้มีสิทธิ์ดูรายงานและส่งออกรายงานได้; Constraint ยืนยันว่า “ผู้บริหารต้องเข้าสู่ระบบและมีสิทธิ์ดูรายงาน” จึงเป็นเงื่อนไขพื้นฐานก่อนเปิดหรือส่งออกรายงาน (FR-ดูรายงานและสถิติห้องสมุด-01, FR-ดูรายงานและสถิติห้องสมุด-04, NFR-SEC-01, Constraint: ผู้บริหารเข้าสู่ระบบและมีสิทธิ์ดูรายงาน)
- [x] **T-02** ใช้ข้อมูลการใช้งานที่มีอยู่เป็นแหล่งรายงาน โดยไม่แก้ธุรกรรมต้นทาง — สำเร็จ: FR-ดูรายงานและสถิติห้องสมุด-02 และ FR-ดูรายงานและสถิติห้องสมุด-03 ระบุว่าระบบต้องประมวลผลและแสดงรายงานจากข้อมูลการใช้งานที่มีอยู่; Scope ยังระบุว่า out of scope สำหรับการจัดการข้อมูลธุรกรรมต้นทาง จึงยืนยันว่า report จะใช้ข้อมูลที่มีอยู่โดยไม่แก้ธุรกรรมต้นทาง (FR-ดูรายงานและสถิติห้องสมุด-02, FR-ดูรายงานและสถิติห้องสมุด-03, Constraint: รายงานอ้างอิงข้อมูลการใช้งานที่มีอยู่)
- [x] **T-03** รับช่วงเวลาและประเภทรายงาน โดยรวมวันเริ่มต้น/สิ้นสุดตามเวลาท้องถิ่นของห้องสมุด — สำเร็จ: FR-ดูรายงานและสถิติห้องสมุด-01 ระบุว่าระบบต้องให้ผู้ใช้เลือกช่วงเวลาและประเภทรายงาน โดยนับรวมวันเริ่มต้นและวันสิ้นสุดตามเวลาท้องถิ่นของห้องสมุด; ASM-01 ยืนยันลักษณะการรวมวันที่นี้ (FR-ดูรายงานและสถิติห้องสมุด-01)
- [x] **T-04** ประมวลผลและแสดงรายงานในรูปกราฟหรือสถิติตามประเภทที่เลือก — สำเร็จ: FR-ดูรายงานและสถิติห้องสมุด-02 และ FR-ดูรายงานและสถิติห้องสมุด-03 ระบุว่าระบบต้องประมวลผลและแสดงรายงานในรูปแบบกราฟหรือสถิติ และรองรับตัวชี้วัดต่าง ๆ ตามประเภทที่เลือก; ข้อนี้เป็น核心ของลักษณะ Report (FR-ดูรายงานและสถิติห้องสมุด-02, FR-ดูรายงานและสถิติห้องสมุด-03)
- [x] **T-05** คำนวณตัวชี้วัดทั้ง 4 ประเภท: จำนวนรายการยืม, หนังสือยอดนิยมเรียงจากการยืมมากไปน้อย, ยอดค่าปรับรวม, จำนวนรายการจองห้อง — สำเร็จ: FR-ดูรายงานและสถิติห้องสมุด-03 ระบุชัดว่าระบบต้องรองรับรายงานการยืม รายงานหนังสือยอดนิยม รายงานค่าปรับ และรายงานการใช้ห้อง; ASM-02 อธิบายตัวชี้วัดแต่ละประเภทอย่างชัดเจน (FR-ดูรายงานและสถิติห้องสมุด-03)
- [x] **T-06** ส่งออก CSV ที่มีข้อมูลเดียวกับรายงานที่แสดง และตรวจสิทธิ์ก่อนส่งออก — สำเร็จ: FR-ดูรายงานและสถิติห้องสมุด-04 และ NFR-SEC-01 ระบุว่าระบบต้องให้ผู้ใช้ส่งออกรายงานเป็นไฟล์ CSV ที่มีข้อมูลเดียวกับรายงานที่แสดง และต้องจำกัดการเข้าถึงตามสิทธิ์ผู้ใช้; AC-02 ยืนยันการส่งออก CSV นี้ (FR-ดูรายงานและสถิติห้องสมุด-04, NFR-SEC-01, AC-ดูรายงานและสถิติห้องสมุด-02)
- [x] **T-07** เมื่อไม่มีข้อมูลในช่วงเวลาที่เลือก แจ้งว่าไม่มีข้อมูล — สำเร็จ: FR-ดูรายงานและสถิติห้องสมุด-05 ระบุว่าหากไม่มีข้อมูลในช่วงเวลาที่เลือก ระบบต้องแจ้งว่าไม่มีข้อมูล; AC-03 เป็นหลักฐานสำหรับกรณีนี้ (FR-ดูรายงานและสถิติห้องสมุด-05, AC-ดูรายงานและสถิติห้องสมุด-03)
- [x] **T-08** กำหนดเป้าหมายเวลาและชุดข้อมูลสำหรับ NFR-PERF-01 ก่อนทดสอบ — สำเร็จ: ASM-06 ระบุว่าทีมพัฒนากำหนดเป้าหมายเวลาและชุดข้อมูลทดสอบของ NFR-PERF-01 ก่อนทดสอบ; นี่คือเงื่อนไขที่ต้องมีก่อนวัดประสิทธิภาพและไม่นับเป็น requirement ใหม่แต่อย่างใด (FR-ดูรายงานและสถิติห้องสมุด-02, NFR-PERF-01, ASM-06)
- [x] **T-09** ทดสอบตัวชี้วัด/ช่วงวันที่และสิทธิ์ดูรายงาน — สำเร็จ: AC-ดูรายงานและสถิติห้องสมุด-01 ระบุว่าหากผู้ใช้มีสิทธิ์และระบบมีข้อมูลการใช้งาน เมื่อเลือกช่วงเวลาและประเภทรายงาน ระบบแสดงรายงานตามตัวชี้วัดของประเภทรายงาน; ข้อนี้ครอบคลุม FR-01, FR-02, FR-03 และ NFR-SEC-01 อย่างตรงตาม spec (FR-ดูรายงานและสถิติห้องสมุด-01, FR-ดูรายงานและสถิติห้องสมุด-02, FR-ดูรายงานและสถิติห้องสมุด-03, NFR-SEC-01, AC-ดูรายงานและสถิติห้องสมุด-01)
- [x] **T-10** ทดสอบส่งออก CSV และตรวจว่าข้อมูลตรงกับรายงานที่แสดง — สำเร็จ: AC-ดูรายงานและสถิติห้องสมุด-02 ระบุว่าหากมีข้อมูลรายงานในช่วงเวลาที่เลือก และผู้ใช้สั่งส่งออกรายงาน ระบบสร้างไฟล์ CSV ที่มีข้อมูลเดียวกับรายงานที่แสดงให้ส่งออกได้; ข้อนี้สอดคล้องกับ FR-04 และ NFR-SEC-01 (FR-ดูรายงานและสถิติห้องสมุด-04, NFR-SEC-01, AC-ดูรายงานและสถิติห้องสมุด-02)
- [x] **T-11** ทดสอบช่วงเวลาที่ไม่มีข้อมูลและตรวจข้อความแจ้ง — สำเร็จ: AC-ดูรายงานและสถิติห้องสมุด-03 ระบุว่าหากไม่มีข้อมูลในช่วงเวลาที่เลือก ผู้ใช้สร้างรายงาน ระบบแจ้งว่าไม่มีข้อมูล; ข้อนี้ตรงกับ FR-01 และ FR-05 (FR-ดูรายงานและสถิติห้องสมุด-01, FR-ดูรายงานและสถิติห้องสมุด-05, AC-ดูรายงานและสถิติห้องสมุด-03)
- [x] **T-12** วัดเวลาประมวลผลตามเป้าหมายและชุดข้อมูลที่กำหนดไว้ — สำเร็จ: NFR-PERF-01 ระบุว่ารายงานทั่วไปควรประมวลผลภายในเป้าหมายเวลาและชุดข้อมูลทดสอบที่ทีมพัฒนากำหนด; ASM-06 ยืนยันว่าความเป้าหมายและชุดข้อมูลต้องถูกกำหนดก่อนทดสอบ; จึงถือว่าการวัดเวลาเป็นเงื่อนไขเฉพาะของ NFR นี้ (FR-ดูรายงานและสถิติห้องสมุด-02, NFR-PERF-01, ASM-06)
