# Feature: ดูรายงานและสถิติห้องสมุด
Spec ID: SPEC-ดูรายงานและสถิติห้องสมุด-015 | Source: SRS v0.3 | Use case: UC-15
Owner: ทีม หิวข้าว | Status: Draft v2 | Updated: 2569-11-19

## Goal
ผู้บริหารห้องสมุดหรือผู้จัดการดูรายงานและสถิติการใช้งานเพื่อวิเคราะห์และวางแผนทรัพยากร

## Primary Actor
ผู้บริหารห้องสมุด / ผู้จัดการ

## Scope
### In scope
- เลือกช่วงเวลาและประเภทรายงาน
- แสดงกราฟและสถิติ
- เลือกดูรายงานการยืม หนังสือยอดนิยม ค่าปรับ หรือการใช้ห้อง
- ส่งออกข้อมูลรายงาน
### Out of scope
- จัดการข้อมูลธุรกรรมต้นทาง เช่น ยืม-คืนหรือจองห้อง

## Constraints
- ผู้บริหารต้องเข้าสู่ระบบและมีสิทธิ์ดูรายงาน
- รายงานต้องอ้างอิงข้อมูลการใช้งานจากฐานข้อมูล SQLite เดิมของระบบสำหรับรายการยืม/คืน ค่าปรับ การจองห้อง และหนังสือ ห้ามสร้างที่เก็บรายงานใหม่หรือคัดลอกข้อมูล
- ช่วงวันที่รายงานใช้ปฏิทิน Asia/Bangkok
- ระยะเวลาที่เลือกต้องไม่เกิน 1 ปี วันสิ้นสุดต้องไม่เกินวันนี้ และวันสิ้นสุดต้องไม่น้อยกว่าวันเริ่มต้น

## Requirements
- **FR-ดูรายงานและสถิติห้องสมุด-01** ระบบต้องให้ผู้ใช้เลือกช่วงเวลาและประเภทรายงาน โดยนับรวมวันเริ่มต้นและวันสิ้นสุดตามปฏิทิน Asia/Bangkok; ถ้าวันสิ้นสุดก่อนวันเริ่มต้น วันสิ้นสุดเกินวันนี้ หรือช่วงเกิน 1 ปี ระบบต้องไม่ประมวลผลและแจ้งสาเหตุที่สอดคล้อง
- **FR-ดูรายงานและสถิติห้องสมุด-02** ระบบต้องประมวลผลและแสดงรายงานในรูปแบบกราฟหรือสถิติ
- **FR-ดูรายงานและสถิติห้องสมุด-03** ระบบต้องรองรับรายงานการยืมโดยนับหนึ่ง Copy ต่อหนึ่งรายการ Loan ที่วันที่ยืมอยู่ในช่วงที่เลือก และแสดงหนังสือยอดนิยม 10 อันดับแรกโดยนับรายการยืมต่อชื่อเรื่องรวมทุก Copy; รายงานค่าปรับต้องแสดงค่าปรับที่เกิดขึ้นทั้งหมด ชำระแล้ว และยังไม่ชำระ โดยนับรายการที่วันที่รับคืนซึ่งสร้างรายการค่าปรับอยู่ในช่วงที่เลือก และตรวจสถานะชำระ ณ เวลาที่ดูรายงาน; รายงานการใช้ห้องต้องไม่นับรายการที่สถานะยกเลิกแล้ว นับตามวันที่ใช้ห้องในช่วงที่เลือก และแสดงต่อห้องทั้งจำนวนรายการจองและจำนวนชั่วโมงที่ถูกจอง
- **FR-ดูรายงานและสถิติห้องสมุด-04** ระบบต้องให้ผู้ใช้ส่งออกรายงานเป็นไฟล์ CSV โดยใช้ชุดข้อมูลชุดเดียวกับรายงานที่แสดง คำนวณผ่านฟังก์ชันเดียวกัน UTF-8 พร้อม BOM คั่นด้วย comma แถวแรกเป็นหัวคอลัมน์ภาษาไทยตรงกับหน้าจอ และตั้งชื่อไฟล์ `report-<ประเภท>-<วันเริ่ม>-<วันสิ้นสุด>.csv`
- **FR-ดูรายงานและสถิติห้องสมุด-05** เมื่อไม่มีข้อมูลในช่วงเวลาที่เลือก ระบบต้องแจ้ง “ไม่พบข้อมูลในช่วงเวลาที่เลือก” ปิดปุ่มส่งออก CSV และไม่สร้างไฟล์ หากเรียก API ส่งออกโดยตรงต้องตอบข้อความเดียวกัน (UC-15 Exception 4a)

## Quality Requirements
- **NFR-PERF-01** จากกดดูรายงานจนรายงานแสดงครบต้องไม่เกิน 5 วินาที ผ่านเมื่อคำขออย่างน้อย 95% อยู่ในเกณฑ์ภายใต้ชุดข้อมูลทดสอบ 1 ปีที่มีหนังสือ 2,000 ชื่อเรื่อง 5,000 เล่ม รายการยืม 20,000 รายการ ค่าปรับ 5,000 รายการ การจองห้อง 10,000 รายการ และเจ้าหน้าที่ใช้งานพร้อมกัน 10 คน
- **NFR-SEC-01** ผู้ที่มี Permission “ดูรายงาน” คือ Role Admin และ Librarian จาก SPEC-014 เท่านั้นจึงดูและส่งออกรายงานได้ทุกประเภท; Member ไม่มีสิทธิ์ ผู้ไม่ได้เข้าสู่ระบบต้องตอบ 401 และพาไปหน้าเข้าสู่ระบบ; ผู้เข้าสู่ระบบแต่ไม่มีสิทธิ์ต้องตอบ 403 แสดง “คุณไม่มีสิทธิ์ดูรายงาน” ไม่โหลดหรือแสดงข้อมูลรายงานในหน้าจอและ API ส่งออก และเมนูรายงานต้องไม่แสดง

## Acceptance Criteria
- [ ] **AC-ดูรายงานและสถิติห้องสมุด-01** (FR-ดูรายงานและสถิติห้องสมุด-01, FR-ดูรายงานและสถิติห้องสมุด-02, FR-ดูรายงานและสถิติห้องสมุด-03, NFR-SEC-01)
  - **Given** ผู้ใช้มีสิทธิ์และระบบมีข้อมูลการใช้งาน
  - **When** ผู้ใช้เลือกช่วงเวลาและประเภทรายงาน
  - **Then** ระบบแสดงรายงานตามตัวชี้วัดของประเภทรายงานในช่วงวันที่เลือกตาม Asia/Bangkok; รายงานยืม/ยอดนิยม ค่าปรับ และการใช้ห้องต้องใช้เกณฑ์ใน FR-03
- [ ] **AC-ดูรายงานและสถิติห้องสมุด-02** (FR-ดูรายงานและสถิติห้องสมุด-04, NFR-SEC-01)
  - **Given** มีข้อมูลรายงานในช่วงเวลาที่เลือก
  - **When** ผู้ใช้สั่งส่งออกรายงาน
  - **Then** ระบบสร้างไฟล์ CSV ด้วยชุดข้อมูลเดียวกับรายงานที่แสดง UTF-8 พร้อม BOM comma หัวคอลัมน์ภาษาไทยตรงกับหน้าจอ วันที่เป็น YYYY-MM-DD ยอดเงินสองตำแหน่งโดยไม่มีคอมมาหลักพันและไม่มีคำว่าบาท และชื่อไฟล์รูปแบบที่กำหนด
- [ ] **AC-ดูรายงานและสถิติห้องสมุด-03** (FR-ดูรายงานและสถิติห้องสมุด-01, FR-ดูรายงานและสถิติห้องสมุด-05)
  - **Given** ไม่มีข้อมูลในช่วงเวลาที่เลือก
  - **When** ผู้ใช้สร้างรายงาน
  - **Then** ระบบแจ้ง “ไม่พบข้อมูลในช่วงเวลาที่เลือก” ปิดปุ่มส่งออก CSV และ API ส่งออกต้องไม่สร้างไฟล์
- [ ] **AC-ดูรายงานและสถิติห้องสมุด-04** (FR-ดูรายงานและสถิติห้องสมุด-01)
  - **Given** ผู้ใช้เลือกช่วงวันที่สิ้นสุดก่อนวันเริ่ม วันสิ้นสุดเกินวันนี้ หรือช่วงเกิน 1 ปี
  - **When** ผู้ใช้สร้างรายงาน
  - **Then** ระบบไม่ประมวลผลและแจ้ง “ช่วงวันที่ไม่ถูกต้อง” สำหรับวันสิ้นสุดก่อนวันเริ่มหรือเกินเงื่อนไขช่วงวันที่อื่นตามสาเหตุที่ตรวจพบ
- [ ] **AC-ดูรายงานและสถิติห้องสมุด-05** (NFR-SEC-01)
  - **Given** ผู้ใช้ไม่มี Permission “ดูรายงาน”
  - **When** ผู้ใช้เข้าถึงหน้าหรือ API รายงานหรือส่งออก
  - **Then** ผู้ไม่ได้เข้าสู่ระบบได้รับ 401 และพาไปหน้าเข้าสู่ระบบ; ผู้เข้าสู่ระบบแต่ไม่มีสิทธิ์ได้รับ 403 และข้อความ “คุณไม่มีสิทธิ์ดูรายงาน” โดยไม่โหลดหรือแสดงข้อมูลรายงานใด ๆ และเมนูรายงานไม่แสดง

## Assumptions
- **ASM-01** ช่วงวันที่ของรายงานรวมวันเริ่มต้นและวันสิ้นสุดตามปฏิทิน Asia/Bangkok
- **ASM-02** รายงานการยืมนับหนึ่งรายการต่อ Loan/Copy วันที่ยืมอยู่ในช่วงที่เลือก; หนังสือยอดนิยมนับจำนวนรายการยืมต่อชื่อเรื่องรวมทุก Copy แสดง 10 อันดับแรก
- **ASM-03** ไฟล์ส่งออกเป็น CSV UTF-8 พร้อม BOM คั่น comma มีหัวคอลัมน์ภาษาไทยตรงกับหน้าจอ ใช้ชุดข้อมูลชุดเดียวกับรายงานที่แสดงคำนวณผ่านฟังก์ชันเดียวกัน วันที่รูปแบบ YYYY-MM-DD ยอดเงินทศนิยม 2 ตำแหน่งไม่มีคอมมาหลักพันและไม่มีคำว่าบาท ชื่อไฟล์ `report-<ประเภท>-<วันเริ่ม>-<วันสิ้นสุด>.csv`
- **ASM-04** ผู้ใช้ที่มี Permission “ดูรายงาน” คือ Admin และ Librarian จาก SPEC-014 สามารถเข้าถึงและส่งออกรายงานได้ทุกประเภท Member ไม่มีสิทธิ์
- **ASM-05** AC-01 อ้างอิง FR-01/FR-02/FR-03/NFR-SEC-01; AC-02 อ้างอิง FR-04/NFR-SEC-01; AC-03 อ้างอิง FR-01/FR-05
- **ASM-06** เป้าหมาย NFR-PERF-01 คือ 5 วินาทีต่อคำขอผ่าน 95% ของคำขอภายใต้ชุดข้อมูลทดสอบ 1 ปีที่ระบุใน NFR-PERF-01 โดยมี 10 ผู้ใช้พร้อมกัน
- **ASM-07** ไม่มีนโยบายหรือค่ากำหนดเพิ่มเติมจากที่ระบุใน spec และ UC Case.pdf สำหรับฟีเจอร์นี้
- **ASM-08** รายงานค่าปรับแยกยอดค่าปรับที่เกิดขึ้นทั้งหมด ชำระแล้ว และยังไม่ชำระ โดยนับที่วันที่รับคืนซึ่งสร้าง FineItem ตาม SPEC-012 และดูสถานะชำระ ณ เวลาที่ดูรายงานตาม SPEC-007; ระบบไม่มีสถานะยกเลิก; แสดงตัวเลขทศนิยม 2 ตำแหน่งเช่น “1,250.00 บาท” บนหน้าจอ
- **ASM-09** รายงานการใช้ห้องไม่นับรายการสถานะยกเลิกตาม SPEC-010 และนับตามวันที่ใช้ห้องตามช่วง start time ภายในช่วงที่เลือก ไม่ใช่วันที่กดจอง; แสดงต่อห้องทั้งจำนวนรายการจองและจำนวนชั่วโมงที่ถูกจอง
- **ASM-10** หนังสือยอดนิยม 10 อันดับแรกเรียงตามจำนวนครั้งยืมมากไปน้อย จากจำนวนเท่ากันเรียงชื่อหนังสือ ก-ฮ แล้ว A-Z และถ้ายังเท่ากันใช้รหัสหนังสือจากน้อยไปมาก
- **ASM-11** ผู้ไม่ได้เข้าสู่ระบบตอบ 401 และพาไปหน้าเข้าสู่ระบบ; ผู้เข้าสู่ระบบที่ไม่มี Permission “ดูรายงาน” ตอบ 403 และแสดง “คุณไม่มีสิทธิ์ดูรายงาน” ไม่โหลดข้อมูลรายงานและเมนูรายงานไม่แสดง
- **ASM-12** กรณีไม่มีข้อมูลแสดง “ไม่พบข้อมูลในช่วงเวลาที่เลือก” ปิดปุ่มส่งออกและ API ส่งออกโดยตรงไม่สร้างไฟล์และตอบข้อความเดียวกัน
- **ASM-13** วันสิ้นสุดก่อนวันเริ่ม แสดง “ช่วงวันที่ไม่ถูกต้อง”; วันที่สิ้นสุดเกินวันนี้หรือช่วงเกิน 1 ปีไม่ประมวลผลและแจ้งข้อความตามสาเหตุของเงื่อนไขช่วงวันที่
