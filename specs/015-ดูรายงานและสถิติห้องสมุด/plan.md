# แผนงาน: ดูรายงานและสถิติห้องสมุด

อ้างอิง: SPEC-ดูรายงานและสถิติห้องสมุด-015 (Draft v2)

## 1. สรุปแนวทาง

- ผู้บริหารห้องสมุดหรือผู้จัดการที่เข้าสู่ระบบและมีสิทธิ์เลือกช่วงวันที่กับประเภทรายงาน (Goal, FR-ดูรายงานและสถิติห้องสมุด-01, NFR-SEC-01)
- อ่านข้อมูลการใช้งานจากฐานข้อมูล SQLite เดิมของระบบสำหรับยืม/คืน ค่าปรับ การจองห้อง และหนังสือ ประมวลผลเป็นผลรวม read-only โดยไม่สร้างที่เก็บรายงานใหม่หรือคัดลอกข้อมูล (Constraint: รายงานอ้างอิง SQLite เดิม, FR-ดูรายงานและสถิติห้องสมุด-02, FR-ดูรายงานและสถิติห้องสมุด-03)
- รายงานยืม, หนังสือยอดนิยม 10 อันดับ, ยอดค่าปรับทั้งหมด/ชำระแล้ว/ยังไม่ชำระ และการใช้ห้องต่อห้องประมวลผลตามเกณฑ์ใน ASM-02, ASM-08, ASM-09 และ ASM-10
- หน้าจอและ CSV ต้องเรียกฟังก์ชันคำนวณชุดข้อมูลเดียวกัน ก่อนส่งออกต้องตรวจสิทธิ์และกรณีไม่มีข้อมูล (FR-ดูรายงานและสถิติห้องสมุด-04, FR-ดูรายงานและสถิติห้องสมุด-05, ASM-03, ASM-12)
- ไม่แก้หรือจัดการธุรกรรมต้นทาง ยืม-คืน จองห้อง หรือเปลี่ยนค่าปรับ (Scope: Out of scope)

## 2. เทคโนโลยีที่ใช้

| สิ่งที่เลือก | มาจาก | หมายเหตุ |
|---|---|---|
| React (Vite) สำหรับหน้าบ้าน | **ทีมเลือกเอง ไม่ได้มาจาก spec** | ค่าเริ่มต้นรายวิชาตามคำสั่ง /plan; ไม่มี Constraint ระบุเทคโนโลยีหน้าบ้าน |
| Python FastAPI สำหรับหลังบ้าน | **ทีมเลือกเอง ไม่ได้มาจาก spec** | ค่าเริ่มต้นรายวิชาตามคำสั่ง /plan; ไม่มี Constraint ระบุภาษา/framework หลังบ้าน |
| SQLite เดิมของระบบ | Constraint: รายงานต้องอ้างอิงฐานข้อมูล SQLite เดิม | อ่าน Loan/Copy/FineItem/RoomBooking/Title/User โดยไม่สร้างตารางรายงานหรือคัดลอกข้อมูล |
| Asia/Bangkok และวันที่รูปแบบ YYYY-MM-DD | Constraint: ช่วงวันที่รายงานใช้ปฏิทิน Asia/Bangkok | ใช้ตรวจช่วงวันที่ กรองข้อมูล และรูปแบบวันที่ใน CSV ตาม ASM-01 และ ASM-03 |
| CSV UTF-8 พร้อม BOM คั่นด้วย comma | FR-ดูรายงานและสถิติห้องสมุด-04, ASM-03 | สร้างจาก rows ชุดเดียวกับหน้าจอ เป็นไฟล์ตอบกลับชั่วคราว ไม่เก็บเป็นที่เก็บรายงานถาวร |

## 3. โมเดลข้อมูล

ไม่มี entity ใหม่สำหรับเก็บผลรายงาน; ใช้ข้อมูล read-only จาก SQLite เดิมเท่านั้น

| Entity/view เดิมที่อ่าน | ฟิลด์หลักที่ใช้ | รองรับ |
|---|---|---|
| Loan และ Copy | copy_id, title_id, loan_date, return state | FR-ดูรายงานและสถิติห้องสมุด-03, ASM-02 |
| Title/Book และชื่อเรื่อง | title_id, title_name, book_code, copy_id | FR-ดูรายงานและสถิติห้องสมุด-03, ASM-02, ASM-10 |
| FineItem | fine_id, created_at หรือวันที่รับคืนที่สร้างรายการ, amount, paid status | FR-ดูรายงานและสถิติห้องสมุด-03, ASM-08 |
| RoomBooking | booking_id, room_id, start_time, end_time, status | FR-ดูรายงานและสถิติห้องสมุด-03, ASM-09 |
| User/Role/Permission | role, permissions, account status | NFR-SEC-01, ASM-04, ASM-11 |
| ReportDataset ชั่วคราวในหน่วยประมวลผล | report_type, start_date, end_date, rows/metrics | FR-ดูรายงานและสถิติห้องสมุด-01 ถึง FR-ดูรายงานและสถิติห้องสมุด-05 |
| CSV Export ชั่วคราว | filename, headers Thai, rows, encoding/BOM | FR-ดูรายงานและสถิติห้องสมุด-04, ASM-03 |

แผนนี้ไม่สร้างฟิลด์หรือ entity สำหรับเก็บผลรายงานซ้ำและไม่เก็บข้อมูลที่ไม่จำเป็น เช่น เลขบัตรประชาชน

## 4. API / หน้าจอ

| รายการ | Method / input / output หลัก | รองรับ |
|---|---|---|
| หน้ารายงานและสถิติ | `GET /reports` input: ประเภทรายงาน/ช่วงวันที่; output: กราฟหรือสถิติ, รายละเอียด 10 อันดับยอดนิยม, ปุ่มส่งออกและข้อความไม่มีข้อมูล | FR-ดูรายงานและสถิติห้องสมุด-01, FR-ดูรายงานและสถิติห้องสมุด-02, FR-ดูรายงานและสถิติห้องสมุด-03, FR-ดูรายงานและสถิติห้องสมุด-05 |
| ข้อมูลรายงาน | `GET /api/reports?type={type}&startDate=YYYY-MM-DD&endDate=YYYY-MM-DD` input: ประเภทและช่วงวันที่; output: metrics/rows หรือช่วงวันที่ไม่ถูกต้อง/ไม่มีข้อมูล | FR-ดูรายงานและสถิติห้องสมุด-01, FR-ดูรายงานและสถิติห้องสมุด-02, FR-ดูรายงานและสถิติห้องสมุด-03, FR-ดูรายงานและสถิติห้องสมุด-05 |
| ส่งออก CSV | `GET /api/reports/export?type={type}&startDate=YYYY-MM-DD&endDate=YYYY-MM-DD` input: ประเภทและช่วงวันที่เดียวกับหน้าจอ; output: CSV หรือข้อความไม่มีข้อมูล/ช่วงไม่ถูกต้อง | FR-ดูรายงานและสถิติห้องสมุด-04, FR-ดูรายงานและสถิติห้องสมุด-05, NFR-SEC-01 |
| Helper ตรวจสิทธิ์รายงาน | อ่าน session และ Permission “ดูรายงาน” ก่อน query/export; เพิ่ม Permission เข้าระบบสิทธิ์ของ SPEC-014 สำหรับ Role Admin และ Librarian | NFR-SEC-01, ASM-04, ASM-11, SPEC-014 FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-02 |

พฤติกรรมสิทธิ์: ไม่มี session ตอบ 401 และพาไปหน้าเข้าสู่ระบบ; มี session แต่ไม่มี Permission ตอบ 403 พร้อม “คุณไม่มีสิทธิ์ดูรายงาน” และไม่โหลดข้อมูลหน้า/API/export; Member ไม่มีสิทธิ์และเมนูรายงานไม่แสดง

## 5. ตารางตรวจ Constraints

Constraint ไม่มี ID แยกใน spec จึงระบุด้วยข้อความเต็มของข้อ Constraint

| Constraint ID | ถูกนำไปใช้ที่ไหนใน plan | สถานะ |
|---|---|---|
| Constraint: ผู้บริหารต้องเข้าสู่ระบบและมีสิทธิ์ดูรายงาน | หัวข้อ 4 ตรวจ session และ Permission “ดูรายงาน” ก่อนหน้ารายงาน, API ดูรายงาน และ API export; ต้องมีใน Role Admin/Librarian ตาม NFR-SEC-01 | ใช้แล้ว |
| Constraint: รายงานอ้างอิงข้อมูล SQLite เดิม ห้ามสร้างที่เก็บรายงานหรือคัดลอกข้อมูล | หัวข้อ 3 อ่าน Loan/Copy/FineItem/RoomBooking/Title/User จาก SQLite เดิมและใช้ ReportDataset/CSV ชั่วคราวเท่านั้น ไม่สร้างตารางหรือแคชรายงานถาวร | ใช้แล้ว |
| Constraint: ช่วงวันที่รายงานใช้ Asia/Bangkok | หัวข้อ 2 และหัวข้อ 7 ใช้ zone Asia/Bangkok, รวมวันเริ่มต้นและวันสิ้นสุด และกรองข้อมูลด้วยวันที่ตาม ASM-01 | ใช้แล้ว |
| Constraint: ช่วงไม่เกิน 1 ปี/สิ้นสุดไม่เกินวันนี้/สิ้นสุดไม่น้อยกว่าวันเริ่ม | หัวข้อ 7 ตรวจทุกเงื่อนไขก่อน query; ใช้ข้อความ “ช่วงวันที่ไม่ถูกต้อง” ตาม FR-ดูรายงานและสถิติห้องสมุด-01 และ ASM-13 | ใช้แล้ว |

## 6. แผนทดสอบจาก Acceptance Criteria

| AC ID | ชื่อ test | ทดสอบอย่างไร |
|---|---|---|
| AC-ดูรายงานและสถิติห้องสมุด-01 | `test_AC_ดูรายงานและสถิติห้องสมุด_01_report_metrics` | สร้าง fixture Loan/Copy/FineItem/RoomBooking/Title สำหรับช่วงวันที่; Admin/Librarian เลือกแต่ละประเภทแล้วตรวจจำนวนยืม, หนังสือยอดนิยม 10 อันดับและลำดับตาม ASM-10, ยอดค่าปรับแยกสถานะ และการใช้ห้องต่อห้องตาม ASM-08/ASM-09 |
| AC-ดูรายงานและสถิติห้องสมุด-02 | `test_AC_ดูรายงานและสถิติห้องสมุด_02_csv_export` | แต่ละประเภทที่มีข้อมูลส่งออก CSV และตรวจ rows เท่ากับหน้าจอ; UTF-8 BOM; comma; หัวไทยตรงหน้าจอ; วันที่ YYYY-MM-DD; ยอดสองตำแหน่งไม่มี comma หลักพัน/บาท; ชื่อไฟล์ตามเทมเพลต |

| NFR-PERF-01 | `test_NFR_PERF_015_report_95_percent_under_5_seconds` | สร้าง dataset 1 ปีตามจำนวนนั้นใน NFR-PERF-01 และจำลองผู้ใช้พร้อมกัน 10 คน; วัดกดจนรายงานแสดงครบอย่างน้อย 95% ต้องไม่เกิน 5 วินาที |

## 7. ลำดับงาน

1. เพิ่ม Permission “ดูรายงาน” ลงรายการ Permission และ Role Admin/Librarian ในระบบสิทธิ์ SPEC-014 หากยังไม่มี พร้อมตรวจ Member ไม่ได้รับ Permission (NFR-SEC-01, ASM-04, ASM-11)
2. เพิ่ม helper ตรวจ session และ Permission ก่อนหน้า/API ดูรายงานและส่งออก และกำหนดผล 401/403/ข้อความตาม NFR-SEC-01 (NFR-SEC-01, AC-ดูรายงานและสถิติห้องสมุด-05)
3. สร้าง service read-only ผูก SQLite เดิมสำหรับ Loan/Copy/FineItem/RoomBooking/Title โดยไม่สร้างที่เก็บรายงานหรือคัดลอกข้อมูล (Constraint: SQLite เดิม, FR-ดูรายงานและสถิติห้องสมุด-03)
4. สร้างตัวตรวจช่วงเวลา Asia/Bangkok รวมวันเริ่ม/สิ้นสุด ไม่เกินวันนี้ และช่วงไม่เกิน 1 ปี (FR-ดูรายงานและสถิติห้องสมุด-01, AC-ดูรายงานและสถิติห้องสมุด-04)
5. สร้าง aggregate ยืมและหนังสือยอดนิยม 10 อันดับพร้อมกติกาเรียง ก-ฮ/A-Z/รหัสหนังสือ (FR-ดูรายงานและสถิติห้องสมุด-03, ASM-02, ASM-10)
6. สร้าง aggregate ค่าปรับแยกทั้งหมด/ชำระแล้ว/ยังไม่ชำระ และการใช้ห้องต่อห้องไม่นับรายการยกเลิก (FR-ดูรายงานและสถิติห้องสมุด-03, ASM-08, ASM-09)
7. เพิ่ม API ดูรายงานและหน้าจอเลือกช่วงวันที่/ประเภท แสดงกราฟ/สถิติ เมนูตามสิทธิ์ และข้อความไม่มีข้อมูล (FR-ดูรายงานและสถิติห้องสมุด-01 ถึง FR-ดูรายงานและสถิติห้องสมุด-05)
8. เพิ่ม export CSV โดยเรียก ReportDataset เดียวกับหน้าจอ ตั้งชื่อไฟล์ UTF-8 BOM comma หัวไทย วันที่และยอดเงินตาม spec และปิด export เมื่อตรงกรณีไม่มีข้อมูล (FR-ดูรายงานและสถิติห้องสมุด-04, FR-ดูรายงานและสถิติห้องสมุด-05, ASM-03, ASM-12)
9. เขียน test ครอบคลุม AC-ดูรายงานและสถิติห้องสมุด-01 ถึง AC-ดูรายงานและสถิติห้องสมุด-05 และเพิ่ม test NFR-PERF-01 ตามชุดข้อมูล 10 ผู้ใช้พร้อมกัน (AC-01 ถึง AC-05, NFR-PERF-01)
