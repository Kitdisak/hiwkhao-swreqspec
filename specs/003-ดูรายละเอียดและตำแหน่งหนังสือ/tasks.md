# งาน: ดูรายละเอียดและตำแหน่งหนังสือ

อ้างอิง: SPEC-ดูรายละเอียดและตำแหน่งหนังสือ-003 (Draft v2)

## ลำดับงาน

- [ ] **T-01** อ่านข้อมูลหนังสือที่มีอยู่และแสดงชื่อ ผู้แต่ง ISBN และหมวดหมู่เมื่อเลือกรายการ (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01, Constraint: หนังสือต้องมีข้อมูลอยู่ในระบบ)
- [ ] **T-02** แสดงสถานะล่าสุดที่ระบบมี ณ เวลาที่เปิดรายละเอียด (FR-ดูรายละเอียดและตำแหน่งหนังสือ-02, NFR-ACC-01)
- [ ] **T-03** แสดงตำแหน่งเป็นข้อความเรียงชั้น โซน และเลขเรียกหนังสือ โดยไม่แปลงค่าต้นทาง (FR-ดูรายละเอียดและตำแหน่งหนังสือ-03, NFR-USE-01, Constraint: ใช้มาตรฐานหมวดหมู่และตำแหน่งของห้องสมุด)
- [ ] **T-04** เมื่อข้อมูลไม่ครบ ให้แสดงเฉพาะฟิลด์ที่มี (FR-ดูรายละเอียดและตำแหน่งหนังสือ-04)
- [ ] **T-05** เมื่อสถานะ Borrowed และมีวันคาดว่าจะคืน ให้แสดงวันดังกล่าว (FR-ดูรายละเอียดและตำแหน่งหนังสือ-05)
- [ ] **T-06** คงการยืมหรือจองไว้นอก UC-03; ไม่เพิ่มการบังคับใช้สถานะ Lost, Damaged หรือซ่อมในหน้ารายละเอียด เพราะอยู่นอกขอบเขตการทำรายการ (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01, FR-ดูรายละเอียดและตำแหน่งหนังสือ-02, Constraint: หนังสือ Lost/Damaged/ซ่อมห้ามยืมหรือจอง, Scope: Out of scope)
- [ ] **T-07** ทดสอบรายละเอียด สถานะล่าสุด และลำดับตำแหน่งตาม AC-01 (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01, FR-ดูรายละเอียดและตำแหน่งหนังสือ-02, FR-ดูรายละเอียดและตำแหน่งหนังสือ-03, NFR-USE-01, NFR-ACC-01, AC-ดูรายละเอียดและตำแหน่งหนังสือ-01)
- [ ] **T-08** ทดสอบข้อมูลหนังสือที่ขาดบางฟิลด์และตรวจว่าแสดงเฉพาะข้อมูลที่มี (FR-ดูรายละเอียดและตำแหน่งหนังสือ-04, AC-ดูรายละเอียดและตำแหน่งหนังสือ-02)
- [ ] **T-09** ทดสอบการแสดงวันคาดว่าจะคืนของหนังสือ Borrowed เมื่อมีข้อมูลวัน (FR-ดูรายละเอียดและตำแหน่งหนังสือ-05, AC-ดูรายละเอียดและตำแหน่งหนังสือ-03)

## ตรวจสอบความครอบคลุม

| รายการใน spec | งานที่รองรับ |
|---|---|
| AC-ดูรายละเอียดและตำแหน่งหนังสือ-01 | T-07 |
| AC-ดูรายละเอียดและตำแหน่งหนังสือ-02 | T-08 |
| AC-ดูรายละเอียดและตำแหน่งหนังสือ-03 | T-09 |
| Constraint: หนังสือต้องมีข้อมูลอยู่ในระบบ | T-01 |
| Constraint: หมวดหมู่และตำแหน่งตามมาตรฐานห้องสมุด | T-03 |
| Constraint: Lost/Damaged/ซ่อมห้ามยืมหรือจอง | T-06 (ไม่บังคับใช้ใน UC-03 เพราะอยู่นอกขอบเขต)
