# งาน: ดูรายละเอียดและตำแหน่งหนังสือ

อ้างอิง: SPEC-ดูรายละเอียดและตำแหน่งหนังสือ-003 (Draft v2)

## ลำดับงาน

- [x] **T-01** อ่านข้อมูลหนังสือที่มีอยู่และแสดงชื่อ ผู้แต่ง ISBN และหมวดหมู่เมื่อเลือกรายการ — สำเร็จ: FR-ดูรายละเอียดและตำแหน่งหนังสือ-01 ระบุว่าต้องแสดงรายละเอียดหนังสือได้แก่ ชื่อ ผู้แต่ง ISBN และหมวดหมู่ และ Constraint ระบุว่าหนังสือต้องมีข้อมูลอยู่ในระบบ; จึงยืนยันว่าเป็นข้อมูลพื้นฐานที่ต้องแสดงเมื่อผู้ใช้เลือกรายการ (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01, Constraint: หนังสือต้องมีข้อมูลอยู่ในระบบ)
- [x] **T-02** แสดงสถานะล่าสุดที่ระบบมี ณ เวลาที่เปิดรายละเอียด — สำเร็จ: FR-ดูรายละเอียดและตำแหน่งหนังสือ-02 และ NFR-ACC-01 ระบุว่าต้องแสดงสถานะตามข้อมูลล่าสุด ณ เวลาที่เปิดรายละเอียด; จึงถือเป็นเงื่อนไขสำคัญของเอกสารรายละเอียดหนังสือ (FR-ดูรายละเอียดและตำแหน่งหนังสือ-02, NFR-ACC-01)
- [x] **T-03** แสดงตำแหน่งเป็นข้อความเรียงชั้น โซน และเลขเรียกหนังสือ โดยไม่แปลงค่าต้นทาง — สำเร็จ: FR-ดูรายละเอียดและตำแหน่งหนังสือ-03 และ NFR-USE-01 ระบุว่าต้องแสดงตำแหน่งหนังสือเป็นข้อความเรียงตามลำดับชั้น โซน และเลขเรียกหนังสือ โดยไม่แปลงค่าต้นทาง; นี่สอดคล้องกับ Constraint ที่ใช้มาตรฐานหมวดหมู่และตำแหน่งของห้องสมุด (FR-ดูรายละเอียดและตำแหน่งหนังสือ-03, NFR-USE-01, Constraint: ใช้มาตรฐานหมวดหมู่และตำแหน่งของห้องสมุด)
- [x] **T-04** เมื่อข้อมูลไม่ครบ ให้แสดงเฉพาะฟิลด์ที่มี — สำเร็จ: FR-ดูรายละเอียดและตำแหน่งหนังสือ-04 ระบุว่าเมื่อข้อมูลหนังสือไม่สมบูรณ์ ระบบต้องแสดงเฉพาะข้อมูลที่มี; จึงเป็นเงื่อนไขยืนยันการจัดแสดงข้อมูลแบบ partial (FR-ดูรายละเอียดและตำแหน่งหนังสือ-04)
- [x] **T-05** เมื่อสถานะ Borrowed และมีวันคาดว่าจะคืน ให้แสดงวันดังกล่าว — สำเร็จ: FR-ดูรายละเอียดและตำแหน่งหนังสือ-05 ระบุว่าเมื่อหนังสือถูกยืมและมีวันคาดว่าจะคืน ระบบต้องแสดงวันที่ดังกล่าว; ข้อนี้เป็นเงื่อนไขซึ่งใช้ใน AC-03 (FR-ดูรายละเอียดและตำแหน่งหนังสือ-05)
- [x] **T-06** คงการยืมหรือจองไว้นอก UC-03; ไม่เพิ่มการบังคับใช้สถานะ Lost, Damaged หรือซ่อมในหน้ารายละเอียด เพราะอยู่นอกขอบเขตการทำรายการ — สำเร็จ: Scope ระบุว่า “Out of scope” สำหรับการค้นหาและการสร้างรายการจอง/ยืม; ขณะเดียวกัน Constraint ที่เกี่ยวกับ Lost/Damaged/ซ่อมถูกระบุว่าเป็นเงื่อนไขสำหรับการยืมหรือจอง แต่ไม่ใช่ภารกิจใน UC-03 จึงไม่เพิ่มขั้นตอนหรือการบังคับใช้เพิ่มเติมในฟีเจอร์นี้ (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01, FR-ดูรายละเอียดและตำแหน่งหนังสือ-02, Constraint: หนังสือ Lost/Damaged/ซ่อมห้ามยืมหรือจอง, Scope: Out of scope)
- [x] **T-07** ทดสอบรายละเอียด สถานะล่าสุด และลำดับตำแหน่งตาม AC-01 — สำเร็จ: AC-ดูรายละเอียดและตำแหน่งหนังสือ-01 ระบุว่าหลังเลือกหนังสือ ระบบต้องแสดงรายละเอียด สถานะล่าสุด และตำแหน่งหนังสือเรียงตามลำดับชั้น โซน และเลขเรียกหนังสือ; ข้อนี้ครอบคลุม T-01 ถึง T-03 และ NFR-USE-01/NFR-ACC-01 (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01, FR-ดูรายละเอียดและตำแหน่งหนังสือ-02, FR-ดูรายละเอียดและตำแหน่งหนังสือ-03, NFR-USE-01, NFR-ACC-01, AC-ดูรายละเอียดและตำแหน่งหนังสือ-01)
- [x] **T-08** ทดสอบข้อมูลหนังสือที่ขาดบางฟิลด์และตรวจว่าแสดงเฉพาะข้อมูลที่มี — สำเร็จ: AC-ดูรายละเอียดและตำแหน่งหนังสือ-02 ระบุว่าระบบต้องแสดงเฉพาะข้อมูลที่มีเมื่อหนังสือมีข้อมูลบางส่วนไม่ครบ; จึงเป็นการทดสอบที่ตรงกับ FR-ดูรายละเอียดและตำแหน่งหนังสือ-04 (FR-ดูรายละเอียดและตำแหน่งหนังสือ-04, AC-ดูรายละเอียดและตำแหน่งหนังสือ-02)
- [x] **T-09** ทดสอบการแสดงวันคาดว่าจะคืนของหนังสือ Borrowed เมื่อมีข้อมูลวัน — สำเร็จ: AC-ดูรายละเอียดและตำแหน่งหนังสือ-03 ระบุว่าหากหนังสือมีสถานะ Borrowed และมีวันคาดว่าจะคืน ระบบต้องแสดงวันนั้น; ข้อนี้ครอบคลุม FR-ดูรายละเอียดและตำแหน่งหนังสือ-05 อย่างตรงตาม spec (FR-ดูรายละเอียดและตำแหน่งหนังสือ-05, AC-ดูรายละเอียดและตำแหน่งหนังสือ-03)

## ตรวจสอบความครอบคลุม

| รายการใน spec | งานที่รองรับ |
|---|---|
| AC-ดูรายละเอียดและตำแหน่งหนังสือ-01 | T-07 |
| AC-ดูรายละเอียดและตำแหน่งหนังสือ-02 | T-08 |
| AC-ดูรายละเอียดและตำแหน่งหนังสือ-03 | T-09 |
| Constraint: หนังสือต้องมีข้อมูลอยู่ในระบบ | T-01 |
| Constraint: หมวดหมู่และตำแหน่งตามมาตรฐานห้องสมุด | T-03 |
| Constraint: Lost/Damaged/ซ่อมห้ามยืมหรือจอง | T-06 (ไม่บังคับใช้ใน UC-03 เพราะอยู่นอกขอบเขต)
