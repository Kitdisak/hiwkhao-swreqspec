# งาน: ดูรายละเอียดและตำแหน่งหนังสือ

อ้างอิง: SPEC-ดูรายละเอียดและตำแหน่งหนังสือ-003 (Draft v2)

## ลำดับงาน

- [x] **T-01** อ่านข้อมูลหนังสือที่มีอยู่และแสดงชื่อ ผู้แต่ง ISBN และหมวดหมู่เมื่อเลือกรายการ — สำเร็จ: FR-ดูรายละเอียดและตำแหน่งหนังสือ-01 ระบุว่าต้องแสดงรายละเอียดหนังสือได้แก่ ชื่อ ผู้แต่ง ISBN และหมวดหมู่ และ Constraint ระบุว่าหนังสือต้องมีข้อมูลอยู่ในระบบ; จึงยืนยันว่าเป็นข้อมูลพื้นฐานที่ต้องแสดงเมื่อผู้ใช้เลือกรายการ (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01, Constraint: หนังสือต้องมีข้อมูลอยู่ในระบบ)
- [x] **T-02** แสดงรหัสและสถานะล่าสุดแยกตาม Copy ทุกเล่ม ณ เวลาที่เปิดรายละเอียด — API อ่านข้อมูลจาก catalog ทุกคำขอ, ส่ง `Cache-Control: no-store` และหน้าบ้านใช้ `cache: "no-store"` เพื่อไม่ใช้ผลเก่า; สถานะเป็นข้อมูลระดับ Copy ไม่สรุปรวมเป็นสถานะระดับชื่อเรื่อง (FR-ดูรายละเอียดและตำแหน่งหนังสือ-02, NFR-ACC-01, ASM-02, ASM-07)
- [x] **T-03** แสดงตำแหน่งเป็นข้อความเรียงชั้น โซน และเลขเรียกหนังสือ โดยไม่แปลงค่าต้นทาง — FR-ดูรายละเอียดและตำแหน่งหนังสือ-03 และ NFR-USE-01 กำหนดรูปแบบแสดงตำแหน่ง; UC-03 ไม่ตรวจมาตรฐานและผู้รับผิดชอบตรวจยังเปิดเป็น Q-02 (FR-ดูรายละเอียดและตำแหน่งหนังสือ-03, NFR-USE-01, ASM-03, Q-02)
- [x] **T-04** เมื่อข้อมูลไม่ครบ ให้แสดงเฉพาะฟิลด์ที่มี — สำเร็จ: FR-ดูรายละเอียดและตำแหน่งหนังสือ-04 ระบุว่าเมื่อข้อมูลหนังสือไม่สมบูรณ์ ระบบต้องแสดงเฉพาะข้อมูลที่มี; จึงเป็นเงื่อนไขยืนยันการจัดแสดงข้อมูลแบบ partial (FR-ดูรายละเอียดและตำแหน่งหนังสือ-04)
- [x] **T-05** แสดงวันคาดว่าจะคืนของ Copy สถานะ Borrowed เฉพาะเมื่อมีวันที่ — FR-ดูรายละเอียดและตำแหน่งหนังสือ-05 กำหนดเงื่อนไขทั้งกรณีมีและไม่มีวันที่ รวมถึงไม่แสดงวันของสถานะอื่น (FR-ดูรายละเอียดและตำแหน่งหนังสือ-05, AC-ดูรายละเอียดและตำแหน่งหนังสือ-03)
- [x] **T-06** คงการยืมหรือจองไว้นอก UC-03; ไม่เพิ่มการบังคับใช้สถานะ Lost, Damaged หรือซ่อมในหน้ารายละเอียด — ASM-01 ระบุว่าฟีเจอร์นี้แสดงสถานะเท่านั้น ไม่ทำรายการยืมหรือจอง (ASM-01, Constraint: หนังสือ Lost/Damaged/ซ่อมห้ามยืมหรือจอง, Scope: Out of scope)
- [x] **T-07** ทดสอบรายละเอียดชื่อเรื่อง, ตำแหน่งหนึ่งครั้ง และ Copy ทุกเล่มแยกตามรหัส/สถานะ พร้อมการอ่านสถานะล่าสุดตาม AC-01 (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01, FR-ดูรายละเอียดและตำแหน่งหนังสือ-02, FR-ดูรายละเอียดและตำแหน่งหนังสือ-03, NFR-USE-01, NFR-ACC-01, AC-ดูรายละเอียดและตำแหน่งหนังสือ-01, ASM-07)
- [x] **T-08** ทดสอบการแสดงเฉพาะข้อมูลที่มี รวมถึงตำแหน่งบางส่วน, Copy ที่ไม่มีสถานะ และชื่อเรื่องที่ไม่มี Copy ตาม AC-02 (FR-ดูรายละเอียดและตำแหน่งหนังสือ-04, AC-ดูรายละเอียดและตำแหน่งหนังสือ-02)
- [x] **T-09** ทดสอบวันคืนสามกรณีระดับ Copy: Borrowed มีวัน, Borrowed ไม่มีวัน และสถานะอื่นมีวัน ตาม AC-03 (FR-ดูรายละเอียดและตำแหน่งหนังสือ-05, AC-ดูรายละเอียดและตำแหน่งหนังสือ-03)
- [x] **T-10** ย้ายสถานะและวันคาดว่าจะคืนไปไว้ใน BookCopy พร้อมคืนรายการ Copy ใน API รายละเอียด — สำเร็จ; รายละเอียดชื่อเรื่องยังแยกจาก Copy และทุก Copy แสดงรหัสของตน (FR-ดูรายละเอียดและตำแหน่งหนังสือ-02, FR-ดูรายละเอียดและตำแหน่งหนังสือ-05, ASM-07)
- [x] **T-11** แสดงข้อมูลชื่อเรื่อง/ตำแหน่งครั้งเดียว และรายการ Copy ทุกเล่มพร้อมรหัส สถานะ และวันคืนตามเงื่อนไขในหน้ารายละเอียด (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01 ถึง FR-ดูรายละเอียดและตำแหน่งหนังสือ-05, NFR-USE-01, ASM-07, ASM-08)
- [x] **T-12** ปรับการทดสอบ API ให้ครอบคลุมสถานะทุกประเภทที่ระบุ, การอ่านข้อมูลล่าสุด, การปิด cache, ข้อมูลไม่ครบ และเงื่อนไขวันคืนต่อ Copy (AC-ดูรายละเอียดและตำแหน่งหนังสือ-01 ถึง AC-ดูรายละเอียดและตำแหน่งหนังสือ-03, FR-ดูรายละเอียดและตำแหน่งหนังสือ-02)

## ตรวจสอบความครอบคลุม

| รายการใน spec | งานที่รองรับ |
|---|---|
| AC-ดูรายละเอียดและตำแหน่งหนังสือ-01 | T-07, T-10, T-11, T-12 |
| AC-ดูรายละเอียดและตำแหน่งหนังสือ-02 | T-08, T-11, T-12 |
| AC-ดูรายละเอียดและตำแหน่งหนังสือ-03 | T-09, T-10, T-11, T-12 |
| Constraint: หนังสือต้องมีข้อมูลอยู่ในระบบ | T-01, T-08 |
| Constraint: หมวดหมู่และตำแหน่งตามมาตรฐานห้องสมุด | T-03 (UC-03 แสดงค่าโดยไม่ตรวจมาตรฐาน; ผู้รับผิดชอบตรวจยังเป็น Q-02) |
| Constraint: Lost/Damaged/ซ่อมห้ามยืมหรือจอง | T-06 (ไม่บังคับใช้ใน UC-03 เพราะอยู่นอกขอบเขต)

หมายเหตุ: Q-01 ถึง Q-03 ใน spec ยังคงเปิดอยู่; ไม่เพิ่มการค้นหา สร้างรายการจอง หรือยืมหนังสือ (Scope: Out of scope)
