# Feature: ดูรายละเอียดและตำแหน่งหนังสือ
Spec ID: SPEC-ดูรายละเอียดและตำแหน่งหนังสือ-003 | Source: SRS v0.3 | Use case: UC-03
Owner: ทีม หิวข้าว | Status: Draft v2 | Updated: 2569-11-16

## Goal
ผู้ใช้ดูรายละเอียด สถานะ และตำแหน่งของหนังสือเพื่อค้นหาหนังสือบนชั้นได้

## Primary Actor
นักศึกษา / สมาชิก

## Scope
### In scope
- แสดงชื่อ ผู้แต่ง ISBN และหมวดหมู่
- แสดงรหัสประจำเล่มและสถานะของทุก Copy ตามค่าที่จัดเก็บ
- แสดงวันคาดว่าจะคืนของ Copy ที่มีสถานะ Borrowed และมีข้อมูลดังกล่าว
- แสดงชั้น โซน และเลขเรียกหนังสือของชื่อเรื่อง
### Out of scope
- ค้นหารายการหนังสือจากคำค้น (UC-01)
- สร้างรายการจองหนังสือ (UC-04)

## Constraints
- หนังสือต้องมีข้อมูลอยู่ในระบบ
- หมวดหมู่และตำแหน่งหนังสือต้องเป็นไปตามมาตรฐานที่ห้องสมุดกำหนด โดย DDC เป็นตัวอย่างหนึ่ง (อ้างอิง Constraint ของ SPEC-013 และ UC-Case.pdf Domain 6); ฟีเจอร์นี้แสดงค่าที่จัดเก็บโดยไม่แปลงและไม่ตรวจสอบมาตรฐาน โดยไม่ได้ระบุว่าฟีเจอร์ใดรับผิดชอบการตรวจสอบ
- หนังสือสถานะ Lost, Damaged หรืออยู่ระหว่างซ่อมต้องไม่สามารถยืมหรือจองได้จนกว่าจะกลับมาพร้อมให้บริการ; UC-03 แสดงสถานะเท่านั้นและไม่บังคับใช้นโยบายการยืมหรือจอง

## Requirements
- **FR-ดูรายละเอียดและตำแหน่งหนังสือ-01** ระบบต้องแสดงรายละเอียดหนังสือ ได้แก่ ชื่อ ผู้แต่ง ISBN และหมวดหมู่ เมื่อผู้ใช้เลือกรายการหนังสือ
- **FR-ดูรายละเอียดและตำแหน่งหนังสือ-02** ระบบต้องแสดงรหัสประจำเล่มและสถานะล่าสุดของแต่ละ Copy ที่บันทึกในระบบ ณ เวลาที่ระบบได้รับคำขอเปิดรายละเอียดหนังสือ โดยอ่านข้อมูลใหม่จากระบบทุกครั้ง ไม่ใช้ข้อมูลจากหน้าค้นหาหรือข้อมูลแคช
- **FR-ดูรายละเอียดและตำแหน่งหนังสือ-03** ระบบต้องแสดงตำแหน่งของชื่อเรื่อง ได้แก่ ชั้น โซน และเลขเรียกหนังสือ โดยแสดงครั้งเดียวต่อชื่อเรื่อง
- **FR-ดูรายละเอียดและตำแหน่งหนังสือ-04** เมื่อข้อมูลหนังสือไม่สมบูรณ์ ระบบต้องแสดงเฉพาะข้อมูลที่มี โดยข้อมูลที่ไม่มีค่าไม่แสดงทั้งป้ายกำกับและค่า; ถ้ามีผู้แต่งหรือหมวดหมู่หลายค่าให้แสดงเฉพาะค่าที่มีข้อมูล; รายการ Copy ที่ไม่มีสถานะไม่แสดงหัวข้อสถานะ และถ้าชื่อเรื่องไม่มี Copy ไม่แสดงรายการ Copy; ตำแหน่งที่มีข้อมูลบางส่วนให้แสดงเฉพาะส่วนนั้นตามลำดับชั้น โซน และเลขเรียกหนังสือ และถ้าไม่มีข้อมูลตำแหน่งเลยไม่แสดงหัวข้อตำแหน่ง (UC-03 Exception 2a)
- **FR-ดูรายละเอียดและตำแหน่งหนังสือ-05** สำหรับแต่ละ Copy ที่มีสถานะ Borrowed ระบบต้องแสดงวันที่คาดว่าจะคืนเมื่อมีข้อมูล; หากไม่มีวันที่ต้องไม่แสดงทั้งป้ายกำกับและค่า และหากสถานะของ Copy ไม่ใช่ Borrowed ต้องไม่แสดงวันที่คาดว่าจะคืน แม้มีข้อมูลดังกล่าว (UC-03 Alternative 3a)

## Quality Requirements
- **NFR-USE-01** ระบบต้องแสดงข้อมูลตำแหน่งหนังสือเป็นข้อความเรียงตามลำดับชั้น โซน และเลขเรียกหนังสือ โดยใช้รูปแบบ "ชั้น <ค่า> · โซน <ค่า> · เลขเรียกหนังสือ <ค่า>"; ให้ละส่วนที่ไม่มีค่าและตัวคั่นที่เกี่ยวข้อง โดยไม่เปลี่ยนลำดับส่วนที่เหลือ
- **NFR-ACC-01** สถานะของแต่ละ Copy ที่แสดงต้องตรงกับสถานะล่าสุดที่บันทึกในระบบ ณ เวลาที่ระบบได้รับคำขอเปิดรายละเอียด โดยการเปลี่ยนแปลงที่บันทึกสำเร็จก่อนคำขอต้องปรากฏเมื่อเปิดรายละเอียด; หน้าที่เปิดค้างไว้ไม่ต้องปรับสถานะอัตโนมัติ

## Acceptance Criteria
- [ ] **AC-ดูรายละเอียดและตำแหน่งหนังสือ-01** (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01, FR-ดูรายละเอียดและตำแหน่งหนังสือ-02, FR-ดูรายละเอียดและตำแหน่งหนังสือ-03, NFR-USE-01, NFR-ACC-01)
  - **Given** มีข้อมูลชื่อเรื่องและหลาย Copy อยู่ในระบบ โดยแต่ละ Copy มีรหัสประจำเล่มและมีสถานะที่บันทึกไว้ต่างกัน
  - **When** ผู้ใช้เลือกรายการหนังสือ
  - **Then** ระบบแสดงรายละเอียดและตำแหน่งหนึ่งครั้งต่อชื่อเรื่อง และแสดง Copy ทุกรายการพร้อมรหัสประจำเล่มและสถานะล่าสุดของแต่ละ Copy แยกจากกัน โดยไม่สรุปรวมสถานะ
  - **Given** มีการบันทึกการยืมของ Copy สำเร็จก่อนผู้ใช้เปิดรายละเอียดหนังสือ
  - **When** ผู้ใช้เปิดรายละเอียดหนังสือ
  - **Then** ระบบแสดงสถานะ Borrowed ของ Copy นั้นจากข้อมูลที่บันทึกไว้ ไม่ใช้สถานะเก่าจากหน้าค้นหาหรือข้อมูลแคช
- [ ] **AC-ดูรายละเอียดและตำแหน่งหนังสือ-02** (FR-ดูรายละเอียดและตำแหน่งหนังสือ-04)
  - **Given** ข้อมูลหนังสือมีบางฟิลด์ว่างหรือไม่มีในระบบ
  - **When** ผู้ใช้เปิดรายละเอียดหนังสือ
  - **Then** ระบบแสดงเฉพาะค่าที่มี โดยไม่แสดงทั้งป้ายกำกับและค่าของข้อมูลที่ไม่มี; หากตำแหน่งมีข้อมูลบางส่วนให้แสดงเฉพาะส่วนที่มีตามลำดับชั้น โซน และเลขเรียกหนังสือ และหากไม่มีส่วนใดเลยไม่แสดงหัวข้อตำแหน่ง; Copy ที่ไม่มีสถานะไม่แสดงหัวข้อสถานะ และชื่อเรื่องที่ไม่มี Copy ไม่แสดงรายการ Copy
- [ ] **AC-ดูรายละเอียดและตำแหน่งหนังสือ-03** (FR-ดูรายละเอียดและตำแหน่งหนังสือ-05)
  - **Given** Copy มีสถานะ Borrowed และมีวันคาดว่าจะคืน
  - **When** ผู้ใช้เปิดรายละเอียด
  - **Then** ระบบแสดงวันที่คาดว่าจะคืนของ Copy นั้น
  - **Given** Copy มีสถานะ Borrowed แต่ไม่มีวันคาดว่าจะคืน
  - **When** ผู้ใช้เปิดรายละเอียด
  - **Then** ระบบแสดงสถานะ Borrowed ของ Copy นั้น และไม่แสดงทั้งป้ายกำกับและค่าของวันที่คาดว่าจะคืน
  - **Given** Copy มีสถานะอื่นที่ไม่ใช่ Borrowed และมีข้อมูลวันคาดว่าจะคืน
  - **When** ผู้ใช้เปิดรายละเอียด
  - **Then** ระบบไม่แสดงวันที่คาดว่าจะคืนของ Copy นั้น

## Assumptions
- **ASM-01** ฟีเจอร์นี้แสดงสถานะ Available, Borrowed, Reserved, Lost, Damaged หรืออยู่ระหว่างซ่อมตามค่าที่จัดเก็บ; การยืมหรือสร้างรายการจอง, รวมถึงการบังคับนโยบายการยืมหรือจอง, ไม่ใช่พฤติกรรมของฟีเจอร์นี้
- **ASM-02** สถานะที่แสดงมาจากข้อมูลระบบที่อ่านใหม่เมื่อได้รับคำขอเปิดรายละเอียด; การเปลี่ยนแปลงที่บันทึกสำเร็จก่อนคำขอต้องปรากฏเมื่อเปิดหน้า และหน้าที่เปิดค้างไว้ไม่ต้องปรับสถานะอัตโนมัติ
- **ASM-03** ระบบแสดงหมวดหมู่และตำแหน่งตามข้อมูลที่จัดเก็บโดยไม่แปลงหรือตรวจสอบมาตรฐาน; เมื่อมีทั้งรหัสและชื่อหมวดหมู่ให้แสดง "<รหัส> - <ชื่อ>", เมื่อมีค่าเดียวให้แสดงค่านั้น และหลายหมวดหมู่คั่นด้วย ", "; ข้อกำหนดให้ข้อมูลเป็นไปตามมาตรฐานอ้างอิงจาก Constraints ของ SPEC-003 และ SPEC-013 รวมถึง UC-Case.pdf Domain 6 แต่ไม่ได้ระบุว่าฟีเจอร์ใดรับผิดชอบการตรวจมาตรฐาน
- **ASM-04** ตำแหน่งแสดงเป็น "ชั้น <ค่า> · โซน <ค่า> · เลขเรียกหนังสือ <ค่า>" โดยแสดงเฉพาะส่วนที่มีค่า เรียงตามลำดับชั้น โซน และเลขเรียกหนังสือ และไม่เหลือตัวคั่นเกิน
- **ASM-05** AC-01 อ้างอิง FR-01 ถึง FR-03 และ NFR-USE-01/NFR-ACC-01; AC-02 อ้างอิง FR-04; AC-03 อ้างอิง FR-05
- **ASM-06** ไม่มีนโยบายหรือค่ากำหนดเพิ่มเติมจากที่ระบุใน spec และ UC Case.pdf สำหรับฟีเจอร์นี้
- **ASM-07** ชื่อเรื่องหนึ่งรายการอาจมีหลาย Copy; ระบบแสดง Copy ทุกเล่มแยกกันพร้อมรหัสประจำเล่ม (DOM-OPAC-05 และ ASM-07 ของ SPEC-001), สถานะ และวันคาดว่าจะคืนเมื่อเข้าเงื่อนไข โดยไม่สรุปรวมสถานะ; ข้อมูลระดับชื่อเรื่องแสดงครั้งเดียว
- **ASM-08** ระหว่างรอคำตอบ Q-03 ให้แสดงตำแหน่งครั้งเดียวต่อชื่อเรื่อง ไม่แยกตาม Copy

## Open Questions
- **Q-01** ผู้ใช้ทั่วไปควรเห็นชื่อสถานะ Lost, Damaged และอยู่ระหว่างซ่อมตามค่าที่จัดเก็บ หรือควรรวม/แสดงเป็นข้อความทั่วไป เช่น “ไม่พร้อมให้บริการ”? ต้องถามบรรณารักษ์/เจ้าหน้าที่ห้องสมุด
- **Q-02** การตรวจว่าหมวดหมู่และตำแหน่งเป็นไปตามมาตรฐานห้องสมุดทำโดยระบบตอนบันทึกข้อมูล (เช่น SPEC-013) หรือบรรณารักษ์ตรวจเอง และมาตรฐานที่ใช้จริงคืออะไร (เช่น DDC, LC หรือระบบของห้องสมุดเอง)? คำตอบไม่มีผลต่อ UC-03 ซึ่งไม่ตรวจมาตรฐาน แต่อาจกระทบ SPEC-013; ต้องถามบรรณารักษ์/เจ้าหน้าที่ห้องสมุดและทีมผู้ดูแล SPEC-013
- **Q-03** Copy ในชื่อเรื่องเดียวกันอาจมีตำแหน่งคนละชั้นหรือคนละโซนได้หรือไม่ และถ้าได้ต้องแสดงตำแหน่งอย่างไร? ระหว่างรอคำตอบให้แสดงตำแหน่งระดับชื่อเรื่องตาม ASM-08; ต้องถามบรรณารักษ์/เจ้าหน้าที่ห้องสมุด
