# แผนงาน: ดูรายละเอียดและตำแหน่งหนังสือ

อ้างอิง: SPEC-ดูรายละเอียดและตำแหน่งหนังสือ-003 (Draft v2)

## 1. สรุปแนวทาง

- นักศึกษา/สมาชิกเลือกรายการหนังสือเพื่อดูชื่อ ผู้แต่ง ISBN และหมวดหมู่ (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01)
- หน้ารายละเอียดแสดงสถานะล่าสุดที่ระบบมี ณ เวลาที่เปิดข้อมูล (FR-ดูรายละเอียดและตำแหน่งหนังสือ-02, NFR-ACC-01, ASM-02)
- แสดงตำแหน่งเป็นข้อความตามลำดับชั้น โซน และเลขเรียกหนังสือ โดยไม่แปลงค่าต้นทาง (FR-ดูรายละเอียดและตำแหน่งหนังสือ-03, NFR-USE-01, ASM-03, ASM-04)
- แสดงเฉพาะข้อมูลที่มี และแสดงวันคาดว่าจะคืนเมื่อหนังสือถูกยืมและมีข้อมูลวันดังกล่าว (FR-ดูรายละเอียดและตำแหน่งหนังสือ-04, FR-ดูรายละเอียดและตำแหน่งหนังสือ-05)
- ขอบเขตเป็นการอ่านรายละเอียดเท่านั้น ไม่สร้างรายการยืมหรือจอง และไม่รวมการค้นหารายการหนังสือ (ASM-01, Scope: Out of scope)

## 2. เทคโนโลยีที่ใช้

| สิ่งที่เลือก | มาจาก | หมายเหตุ |
|---|---|---|
| React (Vite) สำหรับหน้าบ้าน | **ทีมเลือกเอง ไม่ได้มาจาก spec** | ค่าเริ่มต้นตามรายวิชาใน prompt /plan; ไม่มี Constraint ระบุ framework |
| Python FastAPI สำหรับหลังบ้าน | **ทีมเลือกเอง ไม่ได้มาจาก spec** | ค่าเริ่มต้นตามรายวิชาใน prompt /plan; ไม่มี Constraint ระบุภาษา/framework |

## 3. โมเดลข้อมูล

แบบจำลองเชิงแนวคิดสำหรับข้อมูลที่หน้ารายละเอียดต้องอ่าน; ใช้ค่าหมวดหมู่และตำแหน่งตามข้อมูลต้นทาง (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01, FR-ดูรายละเอียดและตำแหน่งหนังสือ-03, ASM-03)

| Entity | ฟิลด์หลัก | รองรับ |
|---|---|---|
| Book | title, author, isbn, category, status, shelf, zone, call_number, expected_return_date (ไม่บังคับ) | FR-ดูรายละเอียดและตำแหน่งหนังสือ-01 ถึง FR-ดูรายละเอียดและตำแหน่งหนังสือ-05; NFR-USE-01; NFR-ACC-01 |

ค่าของ `status` ต้องสะท้อนข้อมูลล่าสุดที่ระบบมีเมื่อเปิดรายละเอียด; `expected_return_date` แสดงเมื่อมีข้อมูล; ข้อมูลตำแหน่งแสดงตามลำดับ shelf, zone, call_number โดยไม่แปลงค่าต้นทาง (FR-ดูรายละเอียดและตำแหน่งหนังสือ-02, FR-ดูรายละเอียดและตำแหน่งหนังสือ-03, FR-ดูรายละเอียดและตำแหน่งหนังสือ-05, NFR-USE-01, NFR-ACC-01, ASM-02, ASM-03, ASM-04).

Constraint ระบุว่าสถานะ Lost, Damaged หรืออยู่ระหว่างซ่อมต้องไม่สามารถยืมหรือจองได้; แผน UC-03 ไม่เพิ่มฟิลด์หรือการทำรายการยืม/จองเพื่อบังคับข้อนี้ เพราะการสร้างรายการจองอยู่นอกขอบเขตและการยืมไม่ใช่พฤติกรรมของฟีเจอร์นี้ (Constraint: สถานะ Lost/Damaged/ซ่อม, ASM-01, Scope: Out of scope).

## 4. API / หน้าจอ

ข้อเสนอ API/หน้าจอเพื่อรองรับ FR ที่ระบุ โดยยังไม่รวมการค้นหา การยืม หรือการสร้างรายการจอง (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01 ถึง FR-ดูรายละเอียดและตำแหน่งหนังสือ-05, Scope: Out of scope)

| รายการ | Method / path หรือ input/output หลัก | รองรับ |
|---|---|---|
| อ่านรายละเอียดหนังสือ | `GET /api/books/{bookId}`; input: ตัวระบุหนังสือที่เลือก; output: title, author, isbn, category, status, shelf, zone, call_number และ expected_return_date เมื่อมี | FR-ดูรายละเอียดและตำแหน่งหนังสือ-01 ถึง FR-ดูรายละเอียดและตำแหน่งหนังสือ-05, NFR-USE-01, NFR-ACC-01 |
| หน้ารายละเอียดหนังสือ | input: หนังสือที่ผู้ใช้เลือก; output: แสดงเฉพาะข้อมูลที่มี, สถานะล่าสุด, ตำแหน่งตามลำดับที่กำหนด และวันคาดว่าจะคืนเมื่อมีข้อมูล | FR-ดูรายละเอียดและตำแหน่งหนังสือ-01 ถึง FR-ดูรายละเอียดและตำแหน่งหนังสือ-05, NFR-USE-01, NFR-ACC-01 |

## 5. ตารางตรวจ Constraints

Constraints ใน spec ไม่มีรหัสเฉพาะ จึงอ้างอิงด้วยข้อความของ Constraint และ Spec ID เดิม (SPEC-ดูรายละเอียดและตำแหน่งหนังสือ-003)

| Constraint ID | ถูกนำไปใช้ที่ไหนใน plan | สถานะ |
|---|---|---|
| ไม่มี ID: หนังสือต้องมีข้อมูลอยู่ในระบบ | หน้ารายละเอียดอ่านข้อมูล Book ที่มีอยู่; กรณีข้อมูลไม่ครบแสดงเฉพาะฟิลด์ที่มี (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01, FR-ดูรายละเอียดและตำแหน่งหนังสือ-04) | ใช้แล้ว |
| ไม่มี ID: หนังสือควรมีการจัดหมวดหมู่และตำแหน่งตามมาตรฐานที่ห้องสมุดกำหนด | แสดงหมวดหมู่/ตำแหน่งจากข้อมูลต้นทางโดยไม่แปลงค่า ซึ่งต้องเป็นไปตามมาตรฐานห้องสมุด (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01, FR-ดูรายละเอียดและตำแหน่งหนังสือ-03, ASM-03) | ใช้แล้ว |
| ไม่มี ID: Lost, Damaged หรืออยู่ระหว่างซ่อมต้องไม่สามารถยืมหรือจองได้ | ไม่สร้างการยืมหรือจองใน UC-03; การสร้างรายการจองอยู่นอกขอบเขต และการบังคับใช้การยืม/จองต้องอยู่ในฟีเจอร์ที่รับผิดชอบการทำรายการ (ASM-01, Scope: Out of scope) | ยังไม่ได้ใช้ เพราะ UC-03 แสดงรายละเอียดเท่านั้นและไม่ทำรายการยืมหรือจอง |

## 6. แผนทดสอบจาก Acceptance Criteria

| AC ID | ชื่อ test | ทดสอบอย่างไร |
|---|---|---|
| AC-ดูรายละเอียดและตำแหน่งหนังสือ-01 | `test_AC_ดูรายละเอียดและตำแหน่งหนังสือ_01` | เตรียมข้อมูลหนังสือครบและข้อมูลยืม-คืนปัจจุบัน เปิดรายละเอียดแล้วตรวจชื่อ ผู้แต่ง ISBN หมวดหมู่ สถานะที่มีล่าสุด และตำแหน่งตามลำดับชั้น โซน เลขเรียกหนังสือ (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01 ถึง FR-ดูรายละเอียดและตำแหน่งหนังสือ-03, NFR-USE-01, NFR-ACC-01) |
| AC-ดูรายละเอียดและตำแหน่งหนังสือ-02 | `test_AC_ดูรายละเอียดและตำแหน่งหนังสือ_02` | เตรียมข้อมูลหนังสือที่ขาดบางฟิลด์ เปิดรายละเอียดแล้วตรวจว่ามีเฉพาะฟิลด์ที่มี และไม่มีค่าหรือช่องข้อมูลสำหรับฟิลด์ที่ไม่มี (FR-ดูรายละเอียดและตำแหน่งหนังสือ-04) |
| AC-ดูรายละเอียดและตำแหน่งหนังสือ-03 | `test_AC_ดูรายละเอียดและตำแหน่งหนังสือ_03` | เตรียมหนังสือสถานะ Borrowed ที่มีวันคาดว่าจะคืน เปิดรายละเอียดแล้วตรวจว่าระบบแสดงวันที่ดังกล่าว (FR-ดูรายละเอียดและตำแหน่งหนังสือ-05) |

## 7. ลำดับงาน

1. เตรียมข้อมูลหนังสือที่มีชื่อ ผู้แต่ง ISBN หมวดหมู่ สถานะ และตำแหน่งตามมาตรฐานห้องสมุด (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01 ถึง FR-ดูรายละเอียดและตำแหน่งหนังสือ-03, Constraint: ข้อมูล/มาตรฐานหนังสือ)
2. ออกแบบการอ่านและแสดงรายละเอียดหนังสือที่ผู้ใช้เลือก (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01, AC-ดูรายละเอียดและตำแหน่งหนังสือ-01)
3. แสดงตำแหน่งตามลำดับชั้น โซน และเลขเรียกหนังสือโดยไม่แปลงค่าต้นทาง (FR-ดูรายละเอียดและตำแหน่งหนังสือ-03, NFR-USE-01, ASM-03, ASM-04)
4. อ่านและแสดงสถานะล่าสุดที่ระบบมีเมื่อเปิดรายละเอียด (FR-ดูรายละเอียดและตำแหน่งหนังสือ-02, NFR-ACC-01, ASM-02)
5. รองรับการแสดงเฉพาะข้อมูลที่มีเมื่อข้อมูลหนังสือไม่ครบ (FR-ดูรายละเอียดและตำแหน่งหนังสือ-04, AC-ดูรายละเอียดและตำแหน่งหนังสือ-02)
6. แสดงวันคาดว่าจะคืนเมื่อหนังสือถูกยืมและมีข้อมูลวันดังกล่าว (FR-ดูรายละเอียดและตำแหน่งหนังสือ-05, AC-ดูรายละเอียดและตำแหน่งหนังสือ-03)
7. ทดสอบรายละเอียด สถานะ ตำแหน่ง ข้อมูลไม่ครบ และวันคาดว่าจะคืนตาม AC ทั้งสามข้อ (AC-ดูรายละเอียดและตำแหน่งหนังสือ-01 ถึง AC-ดูรายละเอียดและตำแหน่งหนังสือ-03)

## 8. สิ่งที่ยังไม่ทำ

ไม่มี Open Questions ใน SPEC-ดูรายละเอียดและตำแหน่งหนังสือ-003 (Draft v2); จึงไม่มีงานที่ต้องระงับไว้ตามคำถามคงค้าง (SPEC-ดูรายละเอียดและตำแหน่งหนังสือ-003).
