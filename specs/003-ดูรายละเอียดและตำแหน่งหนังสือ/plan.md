# แผนงาน: ดูรายละเอียดและตำแหน่งหนังสือ

อ้างอิง: SPEC-ดูรายละเอียดและตำแหน่งหนังสือ-003 (Draft v2)

## 1. สรุปแนวทาง

- นักศึกษา/สมาชิกเลือกชื่อเรื่องเพื่อดูชื่อ ผู้แต่ง ISBN และหมวดหมู่ โดยข้อมูลชื่อเรื่องแสดงครั้งเดียว (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01, ASM-07)
- อ่านข้อมูลรายละเอียดและสถานะใหม่เมื่อเปิดหน้า โดยแสดง Copy ทุกเล่มแยกตามรหัสและสถานะล่าสุด (FR-ดูรายละเอียดและตำแหน่งหนังสือ-02, NFR-ACC-01, ASM-02, ASM-07)
- แสดงตำแหน่งระดับชื่อเรื่องตามลำดับชั้น โซน และเลขเรียกหนังสือ โดยไม่แปลงค่าหรือแสดงส่วนที่ไม่มี (FR-ดูรายละเอียดและตำแหน่งหนังสือ-03, NFR-USE-01, ASM-03, ASM-04, ASM-08)
- ซ่อนข้อมูลและป้ายกำกับที่ไม่มีค่า; แสดงวันคาดว่าจะคืนเฉพาะ Copy สถานะ Borrowed ที่มีวันคืน (FR-ดูรายละเอียดและตำแหน่งหนังสือ-04, FR-ดูรายละเอียดและตำแหน่งหนังสือ-05)
- จำกัดฟีเจอร์ไว้ที่การอ่านรายละเอียด ไม่รวมการค้นหา การยืม หรือการสร้างรายการจอง (Scope: Out of scope, ASM-01)

## 2. เทคโนโลยีที่ใช้

| สิ่งที่เลือก | มาจาก | หมายเหตุ |
|---|---|---|
| React (Vite) สำหรับหน้าบ้าน | **ทีมเลือกเอง ไม่ได้มาจาก spec** | ค่าเริ่มต้นตามคำสั่ง /plan; ใน SPEC-003 ไม่มี Constraint ระบุ framework |
| Python FastAPI สำหรับหลังบ้าน | **ทีมเลือกเอง ไม่ได้มาจาก spec** | ค่าเริ่มต้นตามคำสั่ง /plan; ใน SPEC-003 ไม่มี Constraint ระบุภาษา/framework |

## 3. โมเดลข้อมูล

แบบจำลองเชิงแนวคิดสำหรับข้อมูลที่ UC-03 อ่าน ไม่กำหนดเทคโนโลยีหรือวิธีจัดเก็บ (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01 ถึง FR-ดูรายละเอียดและตำแหน่งหนังสือ-05, ASM-03, ASM-07, ASM-08)

| Entity | ฟิลด์หลัก | รองรับ |
|---|---|---|
| Book (ชื่อเรื่อง) | title, authors[], isbn, categories[] (แต่ละค่าอาจมี code/name), shelf?, zone?, call_number? | FR-ดูรายละเอียดและตำแหน่งหนังสือ-01, FR-ดูรายละเอียดและตำแหน่งหนังสือ-03, FR-ดูรายละเอียดและตำแหน่งหนังสือ-04, NFR-USE-01, ASM-03, ASM-04, ASM-07, ASM-08 |
| Copy | copy_id, status?, expected_return_date? | FR-ดูรายละเอียดและตำแหน่งหนังสือ-02, FR-ดูรายละเอียดและตำแหน่งหนังสือ-04, FR-ดูรายละเอียดและตำแหน่งหนังสือ-05, NFR-ACC-01, ASM-01, ASM-02, ASM-07 |

`status` และ `expected_return_date` เป็นข้อมูลระดับ Copy; สถานะที่แสดงอ่านจากข้อมูลล่าสุดในระบบตามคำขอเปิดรายละเอียด (FR-ดูรายละเอียดและตำแหน่งหนังสือ-02, FR-ดูรายละเอียดและตำแหน่งหนังสือ-05, NFR-ACC-01, ASM-02, ASM-07). ข้อมูล Book เช่น ชื่อ ผู้แต่ง ISBN หมวดหมู่ และตำแหน่งแสดงครั้งเดียวต่อชื่อเรื่อง; ตำแหน่งยังถือเป็นระดับชื่อเรื่องระหว่างรอคำตอบ Q-03 (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01, FR-ดูรายละเอียดและตำแหน่งหนังสือ-03, ASM-07, ASM-08, Q-03).

## 4. API / หน้าจอ

ข้อเสนอด้าน API และหน้าจอเพื่อรองรับการอ่านข้อมูลตามข้อกำหนด ไม่รวมการค้นหา การยืม หรือการสร้างรายการจอง (Scope: Out of scope).

| รายการ | Method / path หรือ input/output หลัก | รองรับ |
|---|---|---|
| อ่านรายละเอียดชื่อเรื่อง | `GET /api/books/{bookId}`; input: ตัวระบุชื่อเรื่องที่เลือก; output: ข้อมูล Book และรายการ `copies[]` ซึ่งแต่ละรายการมี `copy_id`, `status?`, `expected_return_date?` | FR-ดูรายละเอียดและตำแหน่งหนังสือ-01 ถึง FR-ดูรายละเอียดและตำแหน่งหนังสือ-05, NFR-USE-01, NFR-ACC-01, ASM-07 |
| หน้ารายละเอียดหนังสือ | input: ชื่อเรื่องที่เลือก; output: ข้อมูลระดับชื่อเรื่องหนึ่งชุด, ตำแหน่งรูปแบบชั้น/โซน/เลขเรียกหนังสือ และ Copy ทุกเล่มแยกกัน; ไม่แสดงป้ายกำกับ/ค่าที่ไม่มี | FR-ดูรายละเอียดและตำแหน่งหนังสือ-01 ถึง FR-ดูรายละเอียดและตำแหน่งหนังสือ-05, NFR-USE-01, NFR-ACC-01, ASM-04, ASM-07, ASM-08 |

Path API เป็นข้อเสนอทางเทคนิคจากทีม ไม่ได้กำหนดโดย SPEC-003 (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01, ASM-07).

## 5. ตารางตรวจ Constraints

Constraints ใน SPEC-003 ไม่มีรหัส CON/DOM/IF แยกต่างหาก จึงอ้างอิงด้วยข้อความของแต่ละข้อและ Spec ID (SPEC-ดูรายละเอียดและตำแหน่งหนังสือ-003).

| Constraint ID | ถูกนำไปใช้ที่ไหนใน plan | สถานะ |
|---|---|---|
| ไม่มี ID: หนังสือต้องมีข้อมูลอยู่ในระบบ | อ่านข้อมูล Book และ Copy ที่มีอยู่; เมื่อข้อมูลขาด ให้แสดงเฉพาะข้อมูลที่มี (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01, FR-ดูรายละเอียดและตำแหน่งหนังสือ-02, FR-ดูรายละเอียดและตำแหน่งหนังสือ-04) | ใช้แล้ว |
| ไม่มี ID: หมวดหมู่และตำแหน่งต้องเป็นไปตามมาตรฐานที่ห้องสมุดกำหนด (DDC เป็นตัวอย่าง) | UC-03 แสดงค่าที่จัดเก็บโดยไม่แปลงและไม่ตรวจมาตรฐาน; ไม่กำหนดผู้รับผิดชอบตรวจจนกว่าจะได้คำตอบ Q-02 (ASM-03, Q-02) | ยังไม่ได้ใช้ เพราะ UC-03 ไม่ตรวจมาตรฐาน และผู้รับผิดชอบ/มาตรฐานจริงยังเป็น Open Question |
| ไม่มี ID: Copy สถานะ Lost, Damaged หรืออยู่ระหว่างซ่อมต้องไม่สามารถยืมหรือจองได้ | UC-03 แสดงสถานะ Copy แต่ไม่มีการยืมหรือสร้างรายการจอง; การบังคับเงื่อนไขการทำรายการอยู่นอกขอบเขตของฟีเจอร์นี้ (ASM-01, Scope: Out of scope) | ยังไม่ได้ใช้ เพราะ UC-03 เป็นฟีเจอร์อ่านรายละเอียด ไม่ทำรายการยืมหรือจอง |

## 6. แผนทดสอบจาก Acceptance Criteria

| AC ID | ชื่อ test | ทดสอบอย่างไร |
|---|---|---|
| AC-ดูรายละเอียดและตำแหน่งหนังสือ-01 | `test_AC_ดูรายละเอียดและตำแหน่งหนังสือ_01` | เตรียมชื่อเรื่องที่มีหลาย Copy พร้อมรหัสและสถานะต่างกัน; เปิดรายละเอียดแล้วตรวจว่าข้อมูลระดับชื่อเรื่อง/ตำแหน่งแสดงครั้งเดียว และ Copy ทุกเล่มแสดงแยกตามรหัสกับสถานะ ไม่ถูกรวม. จากนั้นบันทึกการยืมของ Copy ก่อนเปิดรายละเอียด และตรวจว่าแสดง Borrowed ล่าสุด ไม่ใช้ข้อมูลจากหน้าค้นหาหรือแคช (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01 ถึง FR-ดูรายละเอียดและตำแหน่งหนังสือ-03, NFR-USE-01, NFR-ACC-01, ASM-07) |
| AC-ดูรายละเอียดและตำแหน่งหนังสือ-02 | `test_AC_ดูรายละเอียดและตำแหน่งหนังสือ_02` | เตรียมข้อมูลที่ขาดค่าระดับชื่อเรื่อง/ตำแหน่ง/สถานะ Copy, ตำแหน่งที่มีบางส่วน และชื่อเรื่องที่ไม่มี Copy; ตรวจว่าไม่แสดงป้ายกำกับและค่าที่ไม่มี, ละส่วนตำแหน่งที่ขาดตามลำดับ และไม่แสดงหัวข้อสถานะหรือรายการ Copy ในกรณีที่กำหนด (FR-ดูรายละเอียดและตำแหน่งหนังสือ-04) |
| AC-ดูรายละเอียดและตำแหน่งหนังสือ-03 | `test_AC_ดูรายละเอียดและตำแหน่งหนังสือ_03` | ตรวจสามกรณีระดับ Copy: Borrowed พร้อมวันคืนแสดงวัน, Borrowed ไม่มีวันคืนไม่แสดงช่องวัน, และสถานะอื่นไม่แสดงวันคืนแม้มีค่า (FR-ดูรายละเอียดและตำแหน่งหนังสือ-05) |

การตรวจ AC-01 ที่ต้องแสดงสถานะหลังบันทึกการยืมขึ้นกับการมีข้อมูล/ขั้นตอนยืมในสภาพแวดล้อมทดสอบ; หากทดสอบการทำรายการยืมร่วมไม่ได้ ให้เตรียมสถานะ Copy ในระบบก่อนเรียก endpoint และทดสอบว่าการเปิดรายละเอียดอ่านค่าล่าสุด (AC-ดูรายละเอียดและตำแหน่งหนังสือ-01, FR-ดูรายละเอียดและตำแหน่งหนังสือ-02, NFR-ACC-01). ส่วน Q-01 และ Q-03 อาจทำให้รายละเอียดการแสดงผลบางประเด็นยังยืนยันไม่ได้ จึงไม่กำหนดผลทดสอบแทนคำตอบทีม (Q-01, Q-03).

## 7. ลำดับงาน

1. ตรวจรูปแบบข้อมูล Book และ Copy ที่มีอยู่เพื่อระบุแหล่งข้อมูลสำหรับรายละเอียด โดยยังไม่เปลี่ยนโครงสร้างเกินข้อกำหนด (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01, FR-ดูรายละเอียดและตำแหน่งหนังสือ-02, ASM-07)
2. ออกแบบการอ่านรายละเอียดจากตัวระบุชื่อเรื่อง โดยผลลัพธ์มีข้อมูลชื่อเรื่องและรายการ Copy แยกกัน (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01, FR-ดูรายละเอียดและตำแหน่งหนังสือ-02, ASM-07)
3. สร้าง endpoint อ่านรายละเอียดที่คืนสถานะ Copy ล่าสุดจากระบบทุกครั้งที่เปิดรายละเอียด (FR-ดูรายละเอียดและตำแหน่งหนังสือ-02, NFR-ACC-01, ASM-02)
4. สร้างหน้ารายละเอียดที่แสดงชื่อ ผู้แต่ง ISBN และหมวดหมู่ครั้งเดียวต่อชื่อเรื่อง และแสดง Copy ทุกเล่มแยกกัน (FR-ดูรายละเอียดและตำแหน่งหนังสือ-01, FR-ดูรายละเอียดและตำแหน่งหนังสือ-02, ASM-07)
5. จัดรูปแบบตำแหน่งชั้น/โซน/เลขเรียกหนังสือตามลำดับและข้ามค่าที่ไม่มี โดยคงค่าต้นทาง (FR-ดูรายละเอียดและตำแหน่งหนังสือ-03, NFR-USE-01, ASM-03, ASM-04, ASM-08)
6. ทำการแสดงข้อมูลแบบมีเงื่อนไขสำหรับฟิลด์ที่ขาด สถานะ Copy ที่ไม่มีค่า และชื่อเรื่องที่ไม่มี Copy (FR-ดูรายละเอียดและตำแหน่งหนังสือ-04, AC-ดูรายละเอียดและตำแหน่งหนังสือ-02)
7. แสดงวันคาดว่าจะคืนเฉพาะ Copy สถานะ Borrowed ที่มีวันดังกล่าว (FR-ดูรายละเอียดและตำแหน่งหนังสือ-05, AC-ดูรายละเอียดและตำแหน่งหนังสือ-03)
8. ทดสอบตาม AC-01 ถึง AC-03 รวมทั้งข้อมูลล่าสุด การแสดง Copy หลายเล่ม และตำแหน่งแบบบางส่วน; ไม่เพิ่มพฤติกรรมค้นหา ยืม หรือจอง (AC-ดูรายละเอียดและตำแหน่งหนังสือ-01 ถึง AC-ดูรายละเอียดและตำแหน่งหนังสือ-03, Scope: Out of scope)

## 8. สิ่งที่ยังไม่ทำ

- **Q-01** ผู้ใช้ทั่วไปควรเห็นชื่อสถานะ Lost, Damaged และอยู่ระหว่างซ่อมตามค่าที่จัดเก็บ หรือควรรวม/แสดงเป็นข้อความทั่วไป เช่น “ไม่พร้อมให้บริการ”? ต้องถามบรรณารักษ์/เจ้าหน้าที่ห้องสมุด

  ส่วนที่เกี่ยวข้องกับข้อนี้จะยังไม่สร้างจนกว่าจะได้คำตอบ
- **Q-02** การตรวจว่าหมวดหมู่และตำแหน่งเป็นไปตามมาตรฐานห้องสมุดทำโดยระบบตอนบันทึกข้อมูล (เช่น SPEC-013) หรือบรรณารักษ์ตรวจเอง และมาตรฐานที่ใช้จริงคืออะไร (เช่น DDC, LC หรือระบบของห้องสมุดเอง)? คำตอบไม่มีผลต่อ UC-03 ซึ่งไม่ตรวจมาตรฐาน แต่อาจกระทบ SPEC-013; ต้องถามบรรณารักษ์/เจ้าหน้าที่ห้องสมุดและทีมผู้ดูแล SPEC-013

  ส่วนที่เกี่ยวข้องกับข้อนี้จะยังไม่สร้างจนกว่าจะได้คำตอบ
- **Q-03** Copy ในชื่อเรื่องเดียวกันอาจมีตำแหน่งคนละชั้นหรือคนละโซนได้หรือไม่ และถ้าได้ต้องแสดงตำแหน่งอย่างไร? ระหว่างรอคำตอบให้แสดงตำแหน่งระดับชื่อเรื่องตาม ASM-08; ต้องถามบรรณารักษ์/เจ้าหน้าที่ห้องสมุด

  ส่วนที่เกี่ยวข้องกับข้อนี้จะยังไม่สร้างจนกว่าจะได้คำตอบ
