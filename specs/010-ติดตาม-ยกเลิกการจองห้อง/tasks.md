# งาน: ติดตาม / ยกเลิกการจองห้อง

อ้างอิง: SPEC-ติดตาม-ยกเลิกการจองห้อง-010 (Draft v2)

## ลำดับงาน

- [x] **T-01** แสดงรายการจองของผู้ใช้พร้อมวัน เวลา และห้อง — สำเร็จ: FR-ติดตาม-/-ยกเลิกการจองห้อง-01 ระบุว่าระบบต้องแสดงรายการจองห้องของผู้ใช้พร้อมวัน เวลา และห้อง; Constraint ยืนยันว่าต้องมีรายการจองห้องก่อนจึงจะทำการติดตาม/ยกเลิกได้ (FR-ติดตาม-/-ยกเลิกการจองห้อง-01, Constraint: ต้องมีรายการจองห้อง)
- [x] **T-02** เปิดดูรายละเอียดโดยไม่เปลี่ยนข้อมูลรายการจอง — สำเร็จ: FR-ติดตาม-/-ยกเลิกการจองห้อง-05 ระบุว่าหากผู้ใช้เพียงดูรายละเอียด ระบบต้องไม่เปลี่ยนแปลงข้อมูล; ข้อนี้เป็นหลักของ AC-03 และเป็นเงื่อนไขที่ถูกกำหนดไว้ชัดเจนใน spec (FR-ติดตาม-/-ยกเลิกการจองห้อง-05)
- [x] **T-03** ตรวจว่ารายการเป็นของผู้ใช้ปัจจุบันและยังไม่ถึงเวลาเริ่มก่อนให้ยืนยันการยกเลิก — สำเร็จ: FR-ติดตาม-/-ยกเลิกการจองห้อง-02 และ Constraint ระบุว่าระบบต้องให้ผู้ใช้ยืนยันการยกเลิกรายการของตนเองก่อนเวลาเริ่มรายการ; ดังนั้นการตรวจสอบเจ้าของและเวลาเริ่มเป็นเงื่อนไขที่จำเป็นก่อนอนุญาตยกเลิก (FR-ติดตาม-/-ยกเลิกการจองห้อง-02, Constraint: ยกเลิกได้เฉพาะรายการของผู้ใช้และก่อนเวลาเริ่ม)
- [x] **T-04** เมื่อถึงหรือเกินเวลาเริ่ม ปฏิเสธและแสดง “ไม่สามารถยกเลิกได้” — สำเร็จ: FR-ติดตาม-/-ยกเลิกการจองห้อง-04 ระบุว่าถึงหรือเกินเวลาเริ่มรายการ ระบบต้องปฏิเสธคำขอยกเลิกและแจ้งข้อความทั่วไปว่า “ไม่สามารถยกเลิกได้”; AC-02 ยืนยันว่าสถานะนี้เป็นผลลัพธ์ที่ต้องเกิดขึ้น (FR-ติดตาม-/-ยกเลิกการจองห้อง-04, AC-ติดตาม-/-ยกเลิกการจองห้อง-02)
- [x] **T-05** หลังยืนยันรายการที่ยกเลิกได้ ให้ยกเลิกรายการ คืนช่วงเวลาให้ว่าง และอัปเดตตารางทันทีหลังยืนยัน — สำเร็จ: FR-ติดตาม-/-ยกเลิกการจองห้อง-02 และ FR-ติดตาม-/-ยกเลิกการจองห้อง-03 ระบุว่าระบบต้องให้ผู้ใช้ยืนยันก่อนยกเลิก และเมื่อยกเลิกสำเร็จต้องคืนช่วงเวลาให้ว่างและอัปเดตตาราง; NFR-REL-01 ยืนยันว่าสิ่งนี้ต้องอัปเดตทันทีหลังยืนยัน (FR-ติดตาม-/-ยกเลิกการจองห้อง-02, FR-ติดตาม-/-ยกเลิกการจองห้อง-03, NFR-REL-01)
- [x] **T-06** ทดสอบยกเลิกก่อนเวลาเริ่มและตรวจช่วงเวลาว่าง/ตารางหลังยืนยัน — สำเร็จ: AC-ติดตาม-/-ยกเลิกการจองห้อง-01 ระบุว่าหากมีรายการจองที่ยังยกเลิกได้ เมื่อผู้ใช้ยืนยันยกเลิก ระบบต้องยกเลิกรายการ ทำให้ช่วงเวลานั้นว่าง และอัปเดตตารางทันที; ข้อนี้ครอบคลุม FR-02, FR-03, NFR-REL-01 อย่างตรงตาม spec (FR-ติดตาม-/-ยกเลิกการจองห้อง-02, FR-ติดตาม-/-ยกเลิกการจองห้อง-03, NFR-REL-01, AC-ติดตาม-/-ยกเลิกการจองห้อง-01)
- [x] **T-07** ทดสอบยกเลิกเมื่อถึงหรือเกินเวลาเริ่มและตรวจข้อความปฏิเสธ — สำเร็จ: AC-ติดตาม-/-ยกเลิกการจองห้อง-02 ระบุว่ารายการที่ถึงหรือเกินเวลาเริ่มเมื่อยืนยันยกเลิก ระบบต้องปฏิเสธและแสดงข้อความทั่วไปว่า “ไม่สามารถยกเลิกได้”; ข้อนี้สอดคล้องกับ FR-04 อย่างชัดเจน (FR-ติดตาม-/-ยกเลิกการจองห้อง-04, AC-ติดตาม-/-ยกเลิกการจองห้อง-02)
- [x] **T-08** ทดสอบเปิดดูรายละเอียดและยืนยันว่าข้อมูลไม่เปลี่ยน — สำเร็จ: AC-ติดตาม-/-ยกเลิกการจองห้อง-03 ระบุว่าผู้ใช้ที่ต้องการเพียงดูรายละเอียดเมื่อเปิดรายการจอง ระบบต้องแสดงรายละเอียดโดยไม่เปลี่ยนข้อมูล; ข้อนี้ครอบคลุม FR-01 และ FR-05 อย่างตรงตาม spec (FR-ติดตาม-/-ยกเลิกการจองห้อง-01, FR-ติดตาม-/-ยกเลิกการจองห้อง-05, AC-ติดตาม-/-ยกเลิกการจองห้อง-03)
