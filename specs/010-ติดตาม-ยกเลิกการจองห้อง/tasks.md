# งาน: ติดตาม / ยกเลิกการจองห้อง

อ้างอิง: SPEC-ติดตาม-ยกเลิกการจองห้อง-010 (Draft v2)

## ลำดับงาน

- [ ] **T-01** แสดงรายการจองของผู้ใช้พร้อมวัน เวลา และห้อง (FR-ติดตาม-/-ยกเลิกการจองห้อง-01, Constraint: ต้องมีรายการจองห้อง)
- [ ] **T-02** เปิดดูรายละเอียดโดยไม่เปลี่ยนข้อมูลรายการจอง (FR-ติดตาม-/-ยกเลิกการจองห้อง-05)
- [ ] **T-03** ตรวจว่ารายการเป็นของผู้ใช้ปัจจุบันและยังไม่ถึงเวลาเริ่มก่อนให้ยืนยันการยกเลิก (FR-ติดตาม-/-ยกเลิกการจองห้อง-02, Constraint: ยกเลิกได้เฉพาะรายการของผู้ใช้และก่อนเวลาเริ่ม)
- [ ] **T-04** เมื่อถึงหรือเกินเวลาเริ่ม ปฏิเสธและแสดง “ไม่สามารถยกเลิกได้” (FR-ติดตาม-/-ยกเลิกการจองห้อง-04)
- [ ] **T-05** หลังยืนยันรายการที่ยกเลิกได้ ให้ยกเลิกรายการ คืนช่วงเวลาให้ว่าง และอัปเดตตารางทันทีหลังยืนยัน (FR-ติดตาม-/-ยกเลิกการจองห้อง-02, FR-ติดตาม-/-ยกเลิกการจองห้อง-03, NFR-REL-01)
- [ ] **T-06** ทดสอบยกเลิกก่อนเวลาเริ่มและตรวจช่วงเวลาว่าง/ตารางหลังยืนยัน (FR-ติดตาม-/-ยกเลิกการจองห้อง-02, FR-ติดตาม-/-ยกเลิกการจองห้อง-03, NFR-REL-01, AC-ติดตาม-/-ยกเลิกการจองห้อง-01)
- [ ] **T-07** ทดสอบยกเลิกเมื่อถึงหรือเกินเวลาเริ่มและตรวจข้อความปฏิเสธ (FR-ติดตาม-/-ยกเลิกการจองห้อง-04, AC-ติดตาม-/-ยกเลิกการจองห้อง-02)
- [ ] **T-08** ทดสอบเปิดดูรายละเอียดและยืนยันว่าข้อมูลไม่เปลี่ยน (FR-ติดตาม-/-ยกเลิกการจองห้อง-01, FR-ติดตาม-/-ยกเลิกการจองห้อง-05, AC-ติดตาม-/-ยกเลิกการจองห้อง-03)
