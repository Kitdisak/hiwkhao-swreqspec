# งาน: ติดตามสถานะการจองหนังสือ

อ้างอิง: SPEC-ติดตามสถานะการจองหนังสือ-005 (Draft v2)

## ลำดับงาน

- [ ] **T-01** อ่านรายการจองทั้งหมดที่ยังอยู่ในระบบโดยผูกกับผู้ใช้ที่เข้าสู่ระบบ รวมสถานะ Completed ที่ยังไม่ถูกลบ (FR-ติดตามสถานะการจองหนังสือ-01, Constraint: ผู้ใช้ต้องเข้าสู่ระบบ, ASM-01)
- [ ] **T-02** แสดงสถานะ Waiting / Ready / Completed และลำดับคิวเฉพาะรายการ Waiting (FR-ติดตามสถานะการจองหนังสือ-02, ASM-02)
- [ ] **T-03** แสดงสถานะล่าสุดที่ระบบมี ณ เวลาที่เปิดเมนูรายการจองของฉัน (FR-ติดตามสถานะการจองหนังสือ-02, NFR-ACC-01, Constraint: สถานะต้องตรงกับข้อมูลล่าสุด)
- [ ] **T-04** แสดงวันหมดเขตรับเป็นข้อความสำหรับ Ready เมื่อมีข้อมูล และไม่แสดงวันเมื่อไม่มี (FR-ติดตามสถานะการจองหนังสือ-03, NFR-USE-01, ASM-04, ASM-05)
- [ ] **T-05** เมื่อไม่มีรายการจอง แจ้งว่าไม่มีรายการ (FR-ติดตามสถานะการจองหนังสือ-04)
- [ ] **T-06** ทดสอบรายการจองและสถานะล่าสุด โดยตรวจว่าคิวแสดงเฉพาะ Waiting (FR-ติดตามสถานะการจองหนังสือ-01, FR-ติดตามสถานะการจองหนังสือ-02, NFR-ACC-01, AC-ติดตามสถานะการจองหนังสือ-01)
- [ ] **T-07** ทดสอบ Ready ที่มีวันหมดเขตและกรณีไม่มีวันหมดเขต (FR-ติดตามสถานะการจองหนังสือ-03, NFR-USE-01, AC-ติดตามสถานะการจองหนังสือ-02)
- [ ] **T-08** ทดสอบผู้ใช้ที่ไม่มีรายการจองและตรวจข้อความแจ้ง (FR-ติดตามสถานะการจองหนังสือ-04, AC-ติดตามสถานะการจองหนังสือ-03)
