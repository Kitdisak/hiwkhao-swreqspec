# งาน: ติดตามสถานะการจองหนังสือ

อ้างอิง: SPEC-ติดตามสถานะการจองหนังสือ-005 (Draft v2)

## ลำดับงาน

- [x] **T-01** อ่านรายการจองทั้งหมดที่ยังอยู่ในระบบโดยผูกกับผู้ใช้ที่เข้าสู่ระบบ รวมสถานะ Completed ที่ยังไม่ถูกลบ — สำเร็จ: FR-ติดตามสถานะการจองหนังสือ-01 ระบุว่าระบบต้องแสดงรายการจองทั้งหมดของผู้ใช้ที่เข้าสู่ระบบ และ ASM-01 ยืนยันว่ารายการจองทั้งหมดหมายถึงรายการที่ยังอยู่ในระบบรวมถึง Completed ที่ยังไม่ถูกลบ; จึงถือเป็น requirement ที่ต้องปฏิบัติโดยใช้ผู้ใช้ที่เข้าสู่ระบบเป็นเงื่อนไขหลัก (FR-ติดตามสถานะการจองหนังสือ-01, Constraint: ผู้ใช้ต้องเข้าสู่ระบบ, ASM-01)
- [x] **T-02** แสดงสถานะ Waiting / Ready / Completed และลำดับคิวเฉพาะรายการ Waiting — สำเร็จ: FR-ติดตามสถานะการจองหนังสือ-02 ระบุชัดว่าต้องแสดงสถานะทุกรายการ และแสดงลำดับคิวเฉพาะ Waiting; ASM-02 ยิ่งเน้นว่าแสดงคิวเฉพาะรายการสถานะ Waiting เท่านั้น (FR-ติดตามสถานะการจองหนังสือ-02, ASM-02)
- [x] **T-03** แสดงสถานะล่าสุดที่ระบบมี ณ เวลาที่เปิดเมนูรายการจองของฉัน — สำเร็จ: NFR-ACC-01 ระบุว่าต้องตรงกับข้อมูลล่าสุดที่ระบบมี ณ เวลาที่ผู้ใช้เปิดเมนู; FR-ติดตามสถานะการจองหนังสือ-02 กำหนดให้แสดงสถานะและลำดับคิวตามข้อมูลล่าสุด; จึงถือว่าการแสดงสถานะล่าสุดเป็นองค์ประกอบสำคัญของฟีเจอร์นี้ (FR-ติดตามสถานะการจองหนังสือ-02, NFR-ACC-01, Constraint: สถานะต้องตรงกับข้อมูลล่าสุด)
- [x] **T-04** แสดงวันหมดเขตรับเป็นข้อความสำหรับ Ready เมื่อมีข้อมูล และไม่แสดงวันเมื่อไม่มี — สำเร็จ: FR-ติดตามสถานะการจองหนังสือ-03 ระบุว่าต้องแสดงวันหมดเขตรับกรณี Ready และมีข้อมูลตัววัน; ASM-04/ASM-05 อธิบายว่าถ้าไม่มีข้อมูลหรือไม่มีวันหมดเขตรับ ระบบไม่แสดงวันดังกล่าว และต้องแสดงเป็นข้อความในรายการจอง (FR-ติดตามสถานะการจองหนังสือ-03, NFR-USE-01, ASM-04, ASM-05)
- [x] **T-05** เมื่อไม่มีรายการจอง แจ้งว่าไม่มีรายการ — สำเร็จ: FR-ติดตามสถานะการจองหนังสือ-04 ระบุว่าเมื่อไม่มีรายการจอง ระบบต้องแจ้งว่าไม่มีรายการ; AC-ติดตามสถานะการจองหนังสือ-03 ยืนยันหลักฐานการทดสอบสำหรับกรณีนี้ (FR-ติดตามสถานะการจองหนังสือ-04)
- [x] **T-06** ทดสอบรายการจองและสถานะล่าสุด โดยตรวจว่าคิวแสดงเฉพาะ Waiting — สำเร็จ: AC-ติดตามสถานะการจองหนังสือ-01 ระบุว่าหลังเปิดเมนูรายการจองของฉัน ระบบต้องแสดงรายการทั้งหมดพร้อมสถานะล่าสุด และแสดงลำดับคิวเฉพาะ Waiting; สิ่งนี้ครอบคลุม FR-ติดตามสถานะการจองหนังสือ-01, FR-ติดตามสถานะการจองหนังสือ-02, NFR-ACC-01 (FR-ติดตามสถานะการจองหนังสือ-01, FR-ติดตามสถานะการจองหนังสือ-02, NFR-ACC-01, AC-ติดตามสถานะการจองหนังสือ-01)
- [x] **T-07** ทดสอบ Ready ที่มีวันหมดเขตและกรณีไม่มีวันหมดเขต — สำเร็จ: AC-ติดตามสถานะการจองหนังสือ-02 ระบุว่าระบบต้องแสดงวันหมดเขตรับเป็นข้อความในรายการ เมื่อมีข้อมูลวัน หากไม่มีข้อมูลให้ไม่แสดง; ข้อนี้ตรงกับ FR-ติดตามสถานะการจองหนังสือ-03 และ NFR-USE-01 (FR-ติดตามสถานะการจองหนังสือ-03, NFR-USE-01, AC-ติดตามสถานะการจองหนังสือ-02)
- [x] **T-08** ทดสอบผู้ใช้ที่ไม่มีรายการจองและตรวจข้อความแจ้ง — สำเร็จ: AC-ติดตามสถานะการจองหนังสือ-03 ระบุว่าผู้ใช้ไม่มีรายการจองเมื่อเปิดเมนู ต้องแจ้งว่าไม่มีรายการ; เป็นการตรวจรับตรงตาม FR-ติดตามสถานะการจองหนังสือ-04 (FR-ติดตามสถานะการจองหนังสือ-04, AC-ติดตามสถานะการจองหนังสือ-03)
