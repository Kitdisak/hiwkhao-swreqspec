# Feature: ติดตามสถานะการจองหนังสือ
Spec ID: SPEC-ติดตามสถานะการจองหนังสือ-005 | Source: SRS v0.3 | Use case: UC-05
Owner: ทีม หิวข้าว | Status: Draft v2 | Updated: 2569-11-17

## Goal
ผู้ใช้ตรวจสอบรายการจอง ลำดับคิว และสถานะล่าสุดของหนังสือที่จองไว้

## Primary Actor
นักศึกษา / สมาชิก

## Scope
### In scope
- แสดงรายการจองของผู้ใช้
- แสดงสถานะ Waiting / Ready / Completed และแสดงลำดับคิวสำหรับรายการ Waiting
- แสดงวันหมดเขตรับหนังสือเมื่อพร้อมรับ
### Out of scope
- สร้างรายการจองใหม่ (UC-04)
- ยกเลิกการจอง (การยกเลิกหนังสือไม่ปรากฏเป็น Use Case แยกในชุดนี้)

## Constraints
- ผู้ใช้ต้องเข้าสู่ระบบ
- สถานะต้องตรงกับข้อมูลการจองล่าสุด

## Requirements
- **FR-ติดตามสถานะการจองหนังสือ-01** ระบบต้องแสดงรายการจองทั้งหมดของผู้ใช้ที่เข้าสู่ระบบ ในสถานะ Waiting / Ready / Completed พร้อมรายละเอียดตาม ASM-09 (ASM-01)
- **FR-ติดตามสถานะการจองหนังสือ-02** ระบบต้องแสดงสถานะ Waiting / Ready / Completed ของแต่ละรายการเป็นข้อความ และแสดงลำดับคิวเฉพาะรายการ Waiting โดยจัดคิวตาม ASM-02 และ ASM-08
- **FR-ติดตามสถานะการจองหนังสือ-03** เมื่อรายการอยู่ในสถานะ Ready และมีข้อมูลวันหมดเขตรับ ระบบต้องแสดงวันหมดเขตเป็นข้อความในรูปแบบ “20 พ.ย. 2569”; หากไม่มีข้อมูลวันหมดเขต ระบบต้องไม่แสดงวัน ป้ายกำกับ ช่อง หรือข้อความทดแทน และรายการ Waiting / Completed ต้องไม่แสดงวันหมดเขตแม้มีข้อมูล (UC-05 Alternative 4a, ASM-04, ASM-05)
- **FR-ติดตามสถานะการจองหนังสือ-04** เมื่อไม่มีรายการจอง ระบบต้องแจ้งว่าไม่มีรายการ (UC-05 Exception 2a)

## Quality Requirements
- **NFR-ACC-01** ทุกครั้งที่ผู้ใช้เปิดเมนูรายการจองของฉัน ระบบต้องอ่านข้อมูลการจองที่ server มี ณ เวลานั้น ห้ามใช้ข้อมูลที่แคชไว้ในหน้าเว็บหรือจากหน้าอื่น และไม่ต้องอัปเดตอัตโนมัติขณะเปิดหน้าค้างไว้ (ASM-03)
- **NFR-USE-01** ระบบต้องแสดงสถานะเป็นข้อความในทุกรายการจอง และแสดงวันหมดเขตรับเป็นข้อความเฉพาะรายการ Ready ที่มีข้อมูลวันหมดเขต โดยใช้รูปแบบ “20 พ.ย. 2569” (ASM-04, ASM-05)

## Acceptance Criteria
- [ ] **AC-ติดตามสถานะการจองหนังสือ-01** (FR-ติดตามสถานะการจองหนังสือ-01, FR-ติดตามสถานะการจองหนังสือ-02, NFR-ACC-01, ASM-01, ASM-02, ASM-03, ASM-08, ASM-09)
  - **Given** ผู้ใช้เข้าสู่ระบบและมีรายการจอง
  - **When** เปิดเมนูรายการจองของฉัน
  - **Then** ระบบอ่านข้อมูลจาก server ตาม NFR-ACC-01 และแสดงรายการทุกสถานะที่มีอยู่พร้อมชื่อหนังสือ ผู้แต่ง และวันที่จอง โดยไม่แสดงรหัสประจำเล่ม; แสดงสถานะทุกรายการเป็นข้อความ และแสดงลำดับคิวเฉพาะ Waiting ตาม ASM-08 โดยคำนวณใหม่ทุกครั้งที่เปิดเมนู
- [ ] **AC-ติดตามสถานะการจองหนังสือ-02** (FR-ติดตามสถานะการจองหนังสือ-03, NFR-USE-01, ASM-04, ASM-05)
  - กรณี 02-1: **Given** มีรายการ Ready ที่มีข้อมูลวันหมดเขตรับเป็นวันที่ 20 พฤศจิกายน 2569; **When** ผู้ใช้เปิดรายการจอง; **Then** ระบบแสดงวันหมดเขตรับเป็นข้อความ “20 พ.ย. 2569”
  - กรณี 02-2: **Given** มีรายการ Ready ที่ไม่มีข้อมูลวันหมดเขตรับ; **When** ผู้ใช้เปิดรายการจอง; **Then** ระบบแสดงสถานะ Ready ตามปกติและไม่แสดงวันหมดเขต ป้ายกำกับ ช่อง หรือข้อความทดแทน
  - กรณี 02-3: **Given** มีรายการ Waiting หรือ Completed ที่มีข้อมูลวันหมดเขตรับ; **When** ผู้ใช้เปิดรายการจอง; **Then** ระบบไม่แสดงวันหมดเขต
- [ ] **AC-ติดตามสถานะการจองหนังสือ-03** (FR-ติดตามสถานะการจองหนังสือ-04, ASM-01)
  - **Given** ผู้ใช้ไม่มีรายการจอง
  - **When** เปิดเมนูรายการจองของฉัน
  - **Then** ระบบแจ้งว่าไม่มีรายการ

## Assumptions
- **ASM-01** แสดงรายการจองทั้งหมดของผู้ใช้ที่มีอยู่ในระบบในทุกสถานะ Waiting / Ready / Completed; ฟีเจอร์นี้ไม่มีกรณีลบหรือซ่อนรายการและไม่กำหนดอายุการเก็บ โดยนโยบายลบหรือเก็บประวัติยังเป็น Open Question Q-01 และไม่กระทบการสร้างฟีเจอร์นี้
- **ASM-02** แสดงลำดับคิวเฉพาะรายการสถานะ Waiting
- **ASM-03** สถานะล่าสุดหมายถึงข้อมูลการจองที่ server มี ณ เวลาที่ผู้ใช้เปิดเมนูรายการจองของฉันทุกครั้ง; ไม่ใช้ข้อมูลที่แคชไว้ในหน้าเว็บหรือจากหน้าอื่น และไม่ต้องอัปเดตอัตโนมัติขณะเปิดหน้าค้างไว้
- **ASM-04** แสดงวันหมดเขตเฉพาะรายการ Ready ที่มีข้อมูล; หากไม่มีข้อมูล ไม่แสดงวัน ป้ายกำกับ ช่อง หรือข้อความทดแทน; รายการ Waiting / Completed ไม่แสดงวันหมดเขตแม้มีข้อมูล
- **ASM-05** แสดงสถานะทุกรายการเป็นข้อความ และแสดงวันหมดเขตเป็นข้อความเฉพาะรายการ Ready ที่มีข้อมูล โดยใช้รูปแบบ “20 พ.ย. 2569”
- **ASM-06** AC-01 อ้างอิง FR-01/FR-02/NFR-ACC-01 และ ASM-01/ASM-02/ASM-03/ASM-08/ASM-09; AC-02 อ้างอิง FR-03/NFR-USE-01/ASM-04/ASM-05; AC-03 อ้างอิง FR-04/ASM-01
- **ASM-07** ฟีเจอร์นี้ไม่สร้างรายการจองใหม่หรือยกเลิกรายการจอง; การสร้างรายการจองอยู่นอกขอบเขตตาม UC-04 และการยกเลิกอยู่นอกขอบเขตของ UC-05
- **ASM-08** คิว Waiting แยกตามชื่อเรื่อง ไม่แยกตาม Copy; ลำดับคิวเท่ากับจำนวนรายการ Waiting ของชื่อเรื่องเดียวกันที่อยู่ก่อนหน้า + 1 และเริ่มที่ 1; ใช้เกณฑ์เรียงเดียวกับ FR-จองหนังสือ-03, NFR-DATA-01 และ ASM-01 ของ SPEC-004 โดยไม่สร้างกติกาจัดคิวใหม่; คำนวณลำดับคิวใหม่ทุกครั้งที่เปิดเมนูตาม ASM-03
- **ASM-09** แต่ละรายการจองแสดงชื่อหนังสือ ผู้แต่ง และวันที่จอง; ใช้รหัสรายการจองเป็นตัวระบุภายในและไม่แสดงรหัสประจำเล่ม เพราะคิวเป็นระดับชื่อเรื่องและรายการ Waiting ยังไม่ผูกกับเล่มใด

## Open Questions
- **Q-01** นโยบายการลบรายการจองหรือการเก็บประวัติเป็นอย่างไร? ต้องถามบรรณารักษ์; คำตอบไม่กระทบการสร้างฟีเจอร์นี้ตาม ASM-01
