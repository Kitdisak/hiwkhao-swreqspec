# แผนงาน: ติดตามสถานะการจองหนังสือ

อ้างอิง: SPEC-ติดตามสถานะการจองหนังสือ-005 (Draft v2)

## 1. สรุปแนวทาง

- นักศึกษา/สมาชิกที่เข้าสู่ระบบเปิดเมนูรายการจองของฉันเพื่อดูรายการจองทั้งหมดที่ยังอยู่ในระบบ (FR-ติดตามสถานะการจองหนังสือ-01, ASM-01)
- แสดง Waiting / Ready / Completed และแสดงลำดับคิวเฉพาะรายการ Waiting (FR-ติดตามสถานะการจองหนังสือ-02, ASM-02)
- อ่านสถานะล่าสุดที่ระบบมี ณ เวลาที่เปิดเมนูรายการจองของฉัน (NFR-ACC-01, ASM-03)
- สำหรับ Ready แสดงวันหมดเขตรับเป็นข้อความเมื่อมีข้อมูล และไม่แสดงวันเมื่อไม่มีข้อมูล (FR-ติดตามสถานะการจองหนังสือ-03, NFR-USE-01, ASM-04, ASM-05)
- เมื่อไม่มีรายการจองให้แจ้งว่าไม่มีรายการ โดยไม่สร้างหรือยกเลิกรายการจองในฟีเจอร์นี้ (FR-ติดตามสถานะการจองหนังสือ-04, Scope: Out of scope)

## 2. เทคโนโลยีที่ใช้

| สิ่งที่เลือก | มาจาก | หมายเหตุ |
|---|---|---|
| React (Vite) สำหรับหน้าบ้าน | **ทีมเลือกเอง ไม่ได้มาจาก spec** | ค่าเริ่มต้นตามรายวิชาใน prompt /plan; ไม่มี Constraint ระบุเทคโนโลยี |
| Python FastAPI สำหรับหลังบ้าน | **ทีมเลือกเอง ไม่ได้มาจาก spec** | ค่าเริ่มต้นตามรายวิชาใน prompt /plan; ไม่มี Constraint ระบุเทคโนโลยี |

## 3. โมเดลข้อมูล

| Entity | ฟิลด์หลักที่ต้องอ่าน | รองรับ |
|---|---|---|
| Reservation | member reference, book reference, status (Waiting/Ready/Completed), queue position (สำหรับ Waiting), pickup deadline (อาจไม่มี) | FR-ติดตามสถานะการจองหนังสือ-01, FR-ติดตามสถานะการจองหนังสือ-02, FR-ติดตามสถานะการจองหนังสือ-03, FR-ติดตามสถานะการจองหนังสือ-04 |
| Member / authenticated user | user reference สำหรับจำกัดรายการให้ตรงกับผู้ใช้ที่เข้าสู่ระบบ | FR-ติดตามสถานะการจองหนังสือ-01, Constraint: ผู้ใช้ต้องเข้าสู่ระบบ |

อ่านสถานะจากข้อมูลล่าสุดที่ระบบมีขณะเปิดเมนู; เก็บ/แสดงวันหมดเขตเฉพาะเมื่อมีข้อมูล และแสดงสถานะกับวันหมดเขตเป็นข้อความในแต่ละรายการ (NFR-ACC-01, NFR-USE-01, ASM-03, ASM-04, ASM-05).

## 4. API / หน้าจอ

| รายการ | Method / path หรือ input/output หลัก | รองรับ |
|---|---|---|
| รายการจองของผู้ใช้ปัจจุบัน | `GET /api/me/reservations`; input: authenticated user context; output: รายการจองทั้งหมดที่ยังอยู่ในระบบ พร้อม status, queue position เฉพาะ Waiting และ pickup deadline เมื่อมีข้อมูล | FR-ติดตามสถานะการจองหนังสือ-01, FR-ติดตามสถานะการจองหนังสือ-02, FR-ติดตามสถานะการจองหนังสือ-03, NFR-ACC-01 |
| เมนูรายการจองของฉัน | input: ผู้ใช้ที่เข้าสู่ระบบ; output: รายการจองพร้อมสถานะ/วันหมดเขตเป็นข้อความ หรือข้อความ “ไม่มีรายการ” เมื่อไม่มีรายการ | FR-ติดตามสถานะการจองหนังสือ-01 ถึง FR-ติดตามสถานะการจองหนังสือ-04, NFR-USE-01, NFR-ACC-01, AC-ติดตามสถานะการจองหนังสือ-01 ถึง AC-ติดตามสถานะการจองหนังสือ-03 |

## 5. ตารางตรวจ Constraints

Constraints ใน spec ไม่มี ID เฉพาะ จึงอ้างอิงด้วยข้อความ Constraint ภายใต้ SPEC-ติดตามสถานะการจองหนังสือ-005

| Constraint ID | ถูกนำไปใช้ที่ไหนใน plan | สถานะ |
|---|---|---|
| ไม่มี ID: ผู้ใช้ต้องเข้าสู่ระบบ | ใช้ authenticated user context และคืนเฉพาะรายการของผู้ใช้ปัจจุบัน (FR-ติดตามสถานะการจองหนังสือ-01) | ใช้แล้ว |
| ไม่มี ID: สถานะต้องตรงกับข้อมูลการจองล่าสุด | อ่านสถานะล่าสุดที่ระบบมี ณ เวลาที่เปิดเมนูรายการจองของฉัน (NFR-ACC-01, ASM-03) | ใช้แล้ว |

## 6. แผนทดสอบจาก Acceptance Criteria

| AC ID | ชื่อ test | ทดสอบอย่างไร |
|---|---|---|
| AC-ติดตามสถานะการจองหนังสือ-01 | `test_AC_ติดตามสถานะการจองหนังสือ_01` | ใช้ผู้ใช้ที่เข้าสู่ระบบและมีรายการ Waiting, Ready และ Completed ที่ยังอยู่ในระบบ เปิดเมนูรายการจอง ตรวจว่ารายการเหล่านั้นและสถานะล่าสุดแสดงครบ และมีลำดับคิวเฉพาะ Waiting (FR-ติดตามสถานะการจองหนังสือ-01, FR-ติดตามสถานะการจองหนังสือ-02, NFR-ACC-01) |
| AC-ติดตามสถานะการจองหนังสือ-02 | `test_AC_ติดตามสถานะการจองหนังสือ_02` | เปิดรายการ Ready ที่มีวันหมดเขต ตรวจว่าระบบแสดงวันเป็นข้อความในรายการ; ทดสอบกรณีไม่มีวันหมดเขตและตรวจว่าไม่แสดงวัน (FR-ติดตามสถานะการจองหนังสือ-03, NFR-USE-01) |
| AC-ติดตามสถานะการจองหนังสือ-03 | `test_AC_ติดตามสถานะการจองหนังสือ_03` | ใช้ผู้ใช้ที่เข้าสู่ระบบและไม่มีรายการจอง เปิดเมนูแล้วตรวจว่าระบบแจ้งว่าไม่มีรายการ (FR-ติดตามสถานะการจองหนังสือ-04) |

## 7. ลำดับงาน

1. เตรียมการเข้าถึงข้อมูลรายการจองโดยผูกกับผู้ใช้ที่เข้าสู่ระบบ (FR-ติดตามสถานะการจองหนังสือ-01, Constraint: ผู้ใช้ต้องเข้าสู่ระบบ)
2. อ่านรายการจองทั้งหมดที่ยังอยู่ในระบบ รวมสถานะ Completed (FR-ติดตามสถานะการจองหนังสือ-01, ASM-01)
3. แสดงสถานะล่าสุดที่ระบบมี ณ เวลาที่เปิดเมนู (NFR-ACC-01, ASM-03)
4. แสดงลำดับคิวเฉพาะรายการ Waiting (FR-ติดตามสถานะการจองหนังสือ-02, ASM-02)
5. แสดงวันหมดเขตรับเป็นข้อความสำหรับ Ready เมื่อมีข้อมูล และไม่แสดงเมื่อไม่มีข้อมูล (FR-ติดตามสถานะการจองหนังสือ-03, NFR-USE-01, ASM-04, ASM-05)
6. แสดงข้อความว่าไม่มีรายการเมื่อผลการอ่านว่าง (FR-ติดตามสถานะการจองหนังสือ-04)
7. ทดสอบรายการ สถานะ คิว วันหมดเขต และกรณีไม่มีรายการตาม AC ทั้งสามข้อ (AC-ติดตามสถานะการจองหนังสือ-01 ถึง AC-ติดตามสถานะการจองหนังสือ-03)

## 8. สิ่งที่ยังไม่ทำ

ไม่มี Open Questions ใน SPEC-ติดตามสถานะการจองหนังสือ-005 (Draft v2); ไม่มีรายการที่ต้องระงับการสร้างจนกว่าจะได้คำตอบ (ASM-07).
