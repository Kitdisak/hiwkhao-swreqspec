# Feature: รับคืนหนังสือและคำนวณค่าปรับ
Spec ID: SPEC-รับคืนหนังสือและคำนวณค่าปรับ-012 | Source: SRS v0.3 | Use case: UC-12
Owner: ทีม หิวข้าว | Status: Draft v3 | Updated: 2569-11-18

## Goal
บรรณารักษ์รับคืนหนังสือ ตรวจสอบกำหนดคืน คำนวณค่าปรับตามกฎห้องสมุด และปรับสถานะหนังสือ

## Primary Actor
บรรณารักษ์

## Scope
### In scope
- ค้นหารายการยืมจากหนังสือ
- ตรวจสอบวันกำหนดคืน
- คำนวณค่าปรับเมื่อเกินกำหนด
- บันทึกการคืนและอัปเดตสถานะหนังสือ
### Out of scope
- ชำระค่าปรับออนไลน์ (UC-07)

## Constraints
- ค่าปรับต้องคำนวณตามจำนวนวันที่เกินกำหนดและอัตราที่ห้องสมุดกำหนด
- ต้องมีรายการยืมของหนังสือที่นำมาคืน

## Requirements
- **FR-รับคืนหนังสือและคำนวณค่าปรับ-01** ระบบต้องค้นหารายการยืมจากรหัสหนังสือที่สแกน
- **FR-รับคืนหนังสือและคำนวณค่าปรับ-02** ระบบต้องตรวจสอบวันกำหนดคืนและคำนวณค่าปรับหากคืนเกินกำหนด
- **FR-รับคืนหนังสือและคำนวณค่าปรับ-03** ระบบต้องคำนวณค่าปรับจากจำนวนวันปฏิทินที่เกินกำหนดคูณอัตราต่อวันที่ห้องสมุดกำหนด โดยไม่มีช่วงผ่อนผันหรือเพดานค่าปรับ และปัดยอดเป็นทศนิยมสองตำแหน่ง; วิธีนับวันและการปัดเป็นไปตาม ASM-09 และ ASM-10
- **FR-รับคืนหนังสือและคำนวณค่าปรับ-04** เมื่อบรรณารักษ์ยืนยัน ระบบต้องบันทึกการคืนและปรับสถานะ Copy: หากไม่มีรายการจอง Waiting ให้เปลี่ยนเป็น Available; หากมี Waiting ให้เปลี่ยนเป็น Reserved และเลื่อนรายการแรกในคิวเป็น Ready พร้อมผูก Copy ตาม ASM-12 ถึง ASM-14
- **FR-รับคืนหนังสือและคำนวณค่าปรับ-05** หากไม่พบรายการยืมที่ยังไม่คืน ระบบต้องแจ้งให้ตรวจสอบข้อมูลและไม่บันทึกการคืน (UC-12 Exception 2a)
- **FR-รับคืนหนังสือและคำนวณค่าปรับ-06** หากคืนตรงเวลา ระบบต้องไม่คิดค่าปรับ (UC-12 Alternative 4a)

## Quality Requirements
- **NFR-ACC-01** ระบบต้องคำนวณค่าปรับตามกฎห้องสมุดอย่างถูกต้อง

## Acceptance Criteria
- [ ] **AC-รับคืนหนังสือและคำนวณค่าปรับ-01** (FR-รับคืนหนังสือและคำนวณค่าปรับ-01, FR-รับคืนหนังสือและคำนวณค่าปรับ-02, FR-รับคืนหนังสือและคำนวณค่าปรับ-03, FR-รับคืนหนังสือและคำนวณค่าปรับ-04, NFR-ACC-01)
  - **Given** มีรายการยืมและหนังสือเกินกำหนด
  - **When** บรรณารักษ์ยืนยันรับคืน
  - **Then** ระบบบันทึกการคืนและค่าปรับ (ถ้ามียอดมากกว่า 0) ตามจำนวนวันปฏิทินและอัตราต่อวัน ปัดทศนิยมสองตำแหน่ง; เปลี่ยน Copy เป็น Available เมื่อไม่มี Waiting reservation หรือเป็น Reserved พร้อมเลื่อนรายการ Waiting แรกเป็น Ready และผูก Copy เมื่อมีคิว
- [ ] **AC-รับคืนหนังสือและคำนวณค่าปรับ-02** (FR-รับคืนหนังสือและคำนวณค่าปรับ-04, FR-รับคืนหนังสือและคำนวณค่าปรับ-06)
  - **Given** มีรายการยืมและคืนตรงเวลา
  - **When** บรรณารักษ์ยืนยันรับคืน
  - **Then** ระบบบันทึกการคืนโดยไม่มีค่าปรับ; เปลี่ยน Copy เป็น Available เมื่อไม่มี Waiting reservation หรือเป็น Reserved พร้อมเลื่อนรายการ Waiting แรกเป็น Ready และผูก Copy เมื่อมีคิว
- [ ] **AC-รับคืนหนังสือและคำนวณค่าปรับ-03** (FR-รับคืนหนังสือและคำนวณค่าปรับ-01, FR-รับคืนหนังสือและคำนวณค่าปรับ-05)
  - **Given** ไม่พบรายการยืมจากรหัสหนังสือ
  - **When** บรรณารักษ์สแกนหนังสือ
  - **Then** ระบบแจ้งให้ตรวจสอบข้อมูลและไม่บันทึกการคืน

## Assumptions
- **ASM-01** ค่าปรับคิดจากจำนวนวันปฏิทินที่เกินกำหนดคูณอัตราต่อวันที่ห้องสมุดกำหนด ไม่มีช่วงผ่อนผันหรือเพดานค่าปรับ และปัดยอดเป็นทศนิยมสองตำแหน่ง
- **ASM-02** เมื่อรับคืนสำเร็จ Copy เปลี่ยนเป็น Available หากไม่มีรายการจอง Waiting; หากมี Waiting ให้ใช้สถานะ Reserved และเลื่อนคิวตาม ASM-14
- **ASM-03** เมื่อสแกนรหัสประจำเล่ม หากพบ Loan ที่ยังไม่คืนหนึ่งรายการ ระบบเลือก Loan นั้น; หากไม่พบให้ทำตาม ASM-04 และหากพบมากกว่าหนึ่งรายการให้ทำตาม ASM-15
- **ASM-04** หากไม่พบ Loan ที่ยังไม่คืน ระบบแจ้งให้ตรวจสอบข้อมูลและไม่บันทึกการคืน
- **ASM-05** AC-01 อ้างอิง FR-01 ถึง FR-04/NFR-ACC-01; AC-02 อ้างอิง FR-04/FR-06; AC-03 อ้างอิง FR-01/FR-05
- **ASM-06** ขอบเขตของฟีเจอร์ยังไม่รวมการชำระค่าปรับออนไลน์; ใช้เฉพาะนโยบายและสมมติฐานที่ระบุใน spec นี้กับ UC-12
- **ASM-07** ใช้อัตราค่าปรับต่อวันเพียงค่าเดียวจากค่ากำหนด ไม่แยกตามประเภทสมาชิกหรือหนังสือ; ใช้ค่า provisional 5.00 บาทต่อวันต่อเล่มจนกว่าจะทราบค่าจริงตาม Q-01; หากระบบมีค่ากำหนดอัตราอยู่แล้วให้ใช้แหล่งเดิม มิฉะนั้นให้มีแหล่งกำหนดค่าเดียวและไม่เขียนอัตราตายในโค้ด
- **ASM-08** คำนวณค่าปรับแยกต่อ Loan/เล่ม ไม่รวมยอดหลายเล่มเข้าด้วยกัน และใช้อัตราค่าปรับที่มีผล ณ วันที่รับคืน
- **ASM-09** Server ใช้วันที่ปัจจุบันในเขตเวลา Asia/Bangkok; วันเกินกำหนดเท่ากับวันที่รับคืนลบวันกำหนดคืนตามวันปฏิทิน โดยวันกำหนดคืนเองยังไม่เกินกำหนด
- **ASM-10** ใช้ Decimal ในการคำนวณและปัดด้วย ROUND_HALF_UP เป็นทศนิยมสองตำแหน่ง; แสดงยอดเงินสองตำแหน่งเสมอ
- **ASM-11** เมื่อค่าปรับมากกว่า 0 ให้สร้าง FineItem หนึ่งรายการต่อ Loan โดยผูกกับสมาชิกและ Loan พร้อมวันเกินกำหนด อัตรา ยอด และสถานะยังไม่ชำระ; หากค่าปรับเป็น 0 ไม่สร้าง FineItem; ใช้ FineItem และสัญญา store ที่ SPEC-007 ใช้อยู่ โดยเก็บ metadata ความสัมพันธ์ Loan/อัตราเพิ่มใน backing store ได้โดยไม่เปลี่ยนสัญญาเดิม
- **ASM-12** การตรวจและการบันทึกการคืน, Loan, Copy, FineItem และ Reservation ต้องอยู่ภายใต้ lock/transaction เดียวแบบ all-or-nothing; หากส่วนใดล้มเหลวต้องไม่มีข้อมูลส่วนใดเปลี่ยน
- **ASM-13** เมื่อไม่มีรายการ Reservation สถานะ Waiting สำหรับชื่อเรื่องนั้น การคืนสำเร็จทำให้ Copy เป็น Available
- **ASM-14** เมื่อมี Reservation สถานะ Waiting ให้เลือกคิวแรกตามลำดับใน SPEC-004, เปลี่ยนเป็น Ready และผูกกับ Copy ที่คืน; Copy เป็น Reserved; pickup deadline ชั่วคราวคือวันรับคืนบวก 3 วัน โดยค่าจริงรอ Q-02
- **ASM-15** หากพบ Loan ที่ยังไม่คืนมากกว่าหนึ่งรายการสำหรับ Copy เดียวกัน ให้ปฏิเสธการคืน แจ้งให้เจ้าหน้าที่ตรวจสอบ และไม่เปลี่ยนข้อมูลใด

## Open Questions
- **Q-01** อัตราค่าปรับจริงต่อวันของห้องสมุดยังไม่ทราบ (สัมพันธ์กับ SPEC-007 Q-07); ผู้ที่ควรถามต่อ: บรรณารักษ์/ผู้กำหนดนโยบายห้องสมุด
- **Q-02** จำนวนวันรับหนังสือจริงหลัง Reservation เป็น Ready ยังไม่ทราบ; ผู้ที่ควรถามต่อ: บรรณารักษ์/ผู้กำหนดนโยบายห้องสมุด
- **Q-03** เมื่อผู้จองไม่มารับหนังสือภายใน pickup deadline ต้องเปลี่ยนสถานะ Reservation และ Copy อย่างไรยังไม่ทราบ; ผู้ที่ควรถามต่อ: บรรณารักษ์/ผู้กำหนดนโยบายห้องสมุด
- **Q-04** ต้องแจ้งเตือนผู้จองเมื่อ Reservation เปลี่ยนเป็น Ready หรือไม่ และใช้ช่องทางใดยังไม่ทราบ; ผู้ที่ควรถามต่อ: บรรณารักษ์/ผู้กำหนดนโยบายห้องสมุด
