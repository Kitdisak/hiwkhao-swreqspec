# งาน: รับคืนหนังสือและคำนวณค่าปรับ

อ้างอิง: SPEC-รับคืนหนังสือและคำนวณค่าปรับ-012 (Draft v2)

## ลำดับงาน

- [x] **T-01** สแกนรหัสหนังสือและค้นหา Loan ที่ยังไม่คืน — สำเร็จ: FR-รับคืนหนังสือและคำนวณค่าปรับ-01 ระบุว่าระบบต้องค้นหารายการยืมจากรหัสหนังสือที่สแกน; Constraint เพิ่มว่าต้องมีรายการยืมของหนังสือที่นำมาคืน จึงเป็นเงื่อนไขแรกของ flow การรับคืน (FR-รับคืนหนังสือและคำนวณค่าปรับ-01, Constraint: ต้องมีรายการยืมของหนังสือที่นำมาคืน)
- [x] **T-02** ตรวจวันกำหนดคืนและแยกกรณีคืนตรงเวลาหรือเกินกำหนดตามจำนวนวันปฏิทิน — สำเร็จ: FR-รับคืนหนังสือและคำนวณค่าปรับ-02 และ FR-รับคืนหนังสือและคำนวณค่าปรับ-06 ระบุชัดว่าระบบต้องตรวจสอบวันกำหนดคืนและแยกกรณีคืนตรงเวลา vs เกินกำหนด; นี่คือการตัดสินใจหลักในการคำนวณค่าปรับ (FR-รับคืนหนังสือและคำนวณค่าปรับ-02, FR-รับคืนหนังสือและคำนวณค่าปรับ-06)
- [x] **T-03** เมื่อเกินกำหนด คำนวณค่าปรับจากวันปฏิทินคูณอัตราต่อวันที่ห้องสมุดกำหนด ไม่มีช่วงผ่อนผัน/เพดาน และปัดสองตำแหน่ง — สำเร็จ: FR-รับคืนหนังสือและคำนวณค่าปรับ-03 และ NFR-ACC-01 ระบุว่าค่าปรับต้องคำนวณตามกฎห้องสมุดอย่างถูกต้องและมีรูปแบบการปัดทศนิยมสองตำแหน่ง; Constraint ยังระบุว่า ค่าปรับต้องคำนวณตามจำนวนวันที่เกินกำหนดและอัตราที่ห้องสมุดกำหนด (FR-รับคืนหนังสือและคำนวณค่าปรับ-03, NFR-ACC-01, Constraint: ค่าปรับตามจำนวนวันและอัตราห้องสมุด)
- [x] **T-04** เมื่อบรรณารักษ์ยืนยัน บันทึกการคืนและเปลี่ยนสถานะหนังสือเป็น Available — สำเร็จ: FR-รับคืนหนังสือและคำนวณค่าปรับ-04 ระบุว่าหลังยืนยัน ระบบต้องบันทึกการคืนและเปลี่ยนสถานะหนังสือเป็น Available; AC-01 และ AC-02 ยืนยันผลลัพธ์นี้ทั้งแบบเกินกำหนดและตรงเวลา (FR-รับคืนหนังสือและคำนวณค่าปรับ-04)
- [x] **T-05** เมื่อไม่พบ Loan ที่ยังไม่คืน แจ้งให้ตรวจสอบและไม่บันทึกการคืน — สำเร็จ: FR-รับคืนหนังสือและคำนวณค่าปรับ-05 ระบุว่าหากไม่พบรายการยืมที่ยังไม่คืน ระบบต้องแจ้งให้ตรวจสอบข้อมูลและไม่บันทึกการคืน; AC-03 เป็นหลักฐานของกรณีนี้ (FR-รับคืนหนังสือและคำนวณค่าปรับ-05)
- [x] **T-06** ทดสอบคืนเกินกำหนด ตรวจจำนวนวัน ค่าปรับที่ปัดสองตำแหน่ง การบันทึกคืน และสถานะ Available — สำเร็จ: AC-รับคืนหนังสือและคำนวณค่าปรับ-01 ระบุว่าหากมีรายการยืมและหนังสือเกินกำหนด เมื่อบรรณารักษ์ยืนยันรับคืน ระบบจะบันทึกการคืน คำนวณค่าปรับตามจำนวนวันปฏิทินและอัตราต่อวัน ปัดทศนิยมสองตำแหน่ง และเปลี่ยนสถานะเป็น Available; ข้อนี้ครอบคลุม FR-01 ถึง FR-04 และ NFR-ACC-01 อย่างตรงตาม spec (FR-รับคืนหนังสือและคำนวณค่าปรับ-01, FR-รับคืนหนังสือและคำนวณค่าปรับ-02, FR-รับคืนหนังสือและคำนวณค่าปรับ-03, FR-รับคืนหนังสือและคำนวณค่าปรับ-04, NFR-ACC-01, AC-รับคืนหนังสือและคำนวณค่าปรับ-01)
- [x] **T-07** ทดสอบคืนตรงเวลาและตรวจว่าไม่มีค่าปรับ พร้อมสถานะ Available — สำเร็จ: AC-รับคืนหนังสือและคำนวณค่าปรับ-02 ระบุว่าหากคืนตรงเวลา ระบบต้องบันทึกการคืนโดยไม่มีค่าปรับและเปลี่ยนสถานะหนังสือเป็น Available; ข้อนี้สอดคล้องกับ FR-04 และ FR-06 (FR-รับคืนหนังสือและคำนวณค่าปรับ-04, FR-รับคืนหนังสือและคำนวณค่าปรับ-06, AC-รับคืนหนังสือและคำนวณค่าปรับ-02)
- [x] **T-08** ทดสอบรหัสหนังสือที่ไม่มี Loan ค้างและตรวจว่าไม่บันทึกการคืน — สำเร็จ: AC-รับคืนหนังสือและคำนวณค่าปรับ-03 ระบุว่าถ้าไม่พบรายการยืมจากรหัสหนังสือ ระบบต้องแจ้งให้ตรวจสอบข้อมูลและไม่บันทึกการคืน; ข้อนี้ครอบคลุม FR-01 และ FR-05 อย่างตรงตาม spec (FR-รับคืนหนังสือและคำนวณค่าปรับ-01, FR-รับคืนหนังสือและคำนวณค่าปรับ-05, AC-รับคืนหนังสือและคำนวณค่าปรับ-03)
