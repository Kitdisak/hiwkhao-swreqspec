# งาน: รับคืนหนังสือและคำนวณค่าปรับ

อ้างอิง: SPEC-รับคืนหนังสือและคำนวณค่าปรับ-012 (Draft v2)

## ลำดับงาน

- [ ] **T-01** สแกนรหัสหนังสือและค้นหา Loan ที่ยังไม่คืน (FR-รับคืนหนังสือและคำนวณค่าปรับ-01, Constraint: ต้องมีรายการยืมของหนังสือที่นำมาคืน)
- [ ] **T-02** ตรวจวันกำหนดคืนและแยกกรณีคืนตรงเวลาหรือเกินกำหนดตามจำนวนวันปฏิทิน (FR-รับคืนหนังสือและคำนวณค่าปรับ-02, FR-รับคืนหนังสือและคำนวณค่าปรับ-06)
- [ ] **T-03** เมื่อเกินกำหนด คำนวณค่าปรับจากวันปฏิทินคูณอัตราต่อวันที่ห้องสมุดกำหนด ไม่มีช่วงผ่อนผัน/เพดาน และปัดสองตำแหน่ง (FR-รับคืนหนังสือและคำนวณค่าปรับ-03, NFR-ACC-01, Constraint: ค่าปรับตามจำนวนวันและอัตราห้องสมุด)
- [ ] **T-04** เมื่อบรรณารักษ์ยืนยัน บันทึกการคืนและเปลี่ยนสถานะหนังสือเป็น Available (FR-รับคืนหนังสือและคำนวณค่าปรับ-04)
- [ ] **T-05** เมื่อไม่พบ Loan ที่ยังไม่คืน แจ้งให้ตรวจสอบและไม่บันทึกการคืน (FR-รับคืนหนังสือและคำนวณค่าปรับ-05)
- [ ] **T-06** ทดสอบคืนเกินกำหนด ตรวจจำนวนวัน ค่าปรับที่ปัดสองตำแหน่ง การบันทึกคืน และสถานะ Available (FR-รับคืนหนังสือและคำนวณค่าปรับ-01, FR-รับคืนหนังสือและคำนวณค่าปรับ-02, FR-รับคืนหนังสือและคำนวณค่าปรับ-03, FR-รับคืนหนังสือและคำนวณค่าปรับ-04, NFR-ACC-01, AC-รับคืนหนังสือและคำนวณค่าปรับ-01)
- [ ] **T-07** ทดสอบคืนตรงเวลาและตรวจว่าไม่มีค่าปรับ พร้อมสถานะ Available (FR-รับคืนหนังสือและคำนวณค่าปรับ-04, FR-รับคืนหนังสือและคำนวณค่าปรับ-06, AC-รับคืนหนังสือและคำนวณค่าปรับ-02)
- [ ] **T-08** ทดสอบรหัสหนังสือที่ไม่มี Loan ค้างและตรวจว่าไม่บันทึกการคืน (FR-รับคืนหนังสือและคำนวณค่าปรับ-01, FR-รับคืนหนังสือและคำนวณค่าปรับ-05, AC-รับคืนหนังสือและคำนวณค่าปรับ-03)

## ตรวจสอบความครอบคลุม

| รายการใน spec | งานที่รองรับ |
|---|---|
| AC-รับคืนหนังสือและคำนวณค่าปรับ-01 | T-06 |
| AC-รับคืนหนังสือและคำนวณค่าปรับ-02 | T-07 |
| AC-รับคืนหนังสือและคำนวณค่าปรับ-03 | T-08 |
| Constraint: ค่าปรับตามจำนวนวันเกินกำหนดและอัตราห้องสมุด | T-03, T-06 |
| Constraint: ต้องมีรายการยืมของหนังสือที่นำมาคืน | T-01, T-05, T-08 |
