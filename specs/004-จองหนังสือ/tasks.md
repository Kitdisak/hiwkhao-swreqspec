# งาน: จองหนังสือ

อ้างอิง: SPEC-จองหนังสือ-004 (Draft v2)

## ลำดับงาน

### ยืนยันประเด็นคงค้าง

- [ ] **T-01** ยืนยันเงื่อนไขสิทธิ์และสถานะหนังสือที่ต้องปฏิเสธเพิ่มเติม — **รอ Q-01** (FR-จองหนังสือ-01, Constraint: ผู้ใช้ต้องเข้าสู่ระบบและหนังสือต้องอนุญาตให้จอง)
- [ ] **T-02** ยืนยันระดับการแยกคิวและเลขเริ่มต้น — **รอ Q-02** (FR-จองหนังสือ-02, FR-จองหนังสือ-03)
- [ ] **T-03** ยืนยันเกณฑ์เรียงคิวต่อเมื่ออักษรแรกของชื่อซ้ำ — **รอ Q-03** (FR-จองหนังสือ-03, NFR-DATA-01)
- [ ] **T-04** นิยามคำขอเดียวกันและแยกการส่งซ้ำจากการจองซ้ำโดยตั้งใจ — **รอ Q-04** (FR-จองหนังสือ-05, NFR-REL-01)
- [ ] **T-05** ยืนยัน AC/FR/NFR mapping และวิธีทดสอบการป้องกันคำขอซ้ำ — **รอ Q-05** (FR-จองหนังสือ-05, NFR-REL-01, AC-จองหนังสือ-01 ถึง AC-จองหนังสือ-03)
- [ ] **T-06** ตรวจนโยบายหรือค่ากำหนดใน UC Case.pdf — **รอ Q-06** (FR-จองหนังสือ-01, FR-จองหนังสือ-02)

### พัฒนาและทดสอบ

- [ ] **T-07** ตรวจผู้ใช้เข้าสู่ระบบ มีสิทธิ์ และหนังสืออนุญาตให้จองก่อนสร้างรายการ (FR-จองหนังสือ-01, Constraint: ต้องเข้าสู่ระบบและหนังสือต้องอนุญาตให้จอง)
- [ ] **T-08** เมื่อผู้ใช้ยืนยัน บันทึกรายการจองและแสดงลำดับคิว (FR-จองหนังสือ-02)
- [ ] **T-09** เรียงคิวตามเวลาที่บันทึกก่อน-หลัง และกรณีเวลาเท่ากันตามอักษรแรก ก-ฮ; กรณีอักษรแรกซ้ำรอเกณฑ์ทีม — **รอ Q-03** (FR-จองหนังสือ-03, NFR-DATA-01)
- [ ] **T-10** ปฏิเสธผู้ถูกระงับและแจ้งสาเหตุ (FR-จองหนังสือ-04)
- [ ] **T-11** ป้องกันคำขอเดียวกันสร้างรายการจองซ้ำตามนิยามที่ทีมยืนยัน — **รอ Q-04** (FR-จองหนังสือ-05, NFR-REL-01)
- [ ] **T-12** ทดสอบการสร้างรายการจองและแสดงคิว (FR-จองหนังสือ-01, FR-จองหนังสือ-02, AC-จองหนังสือ-01)
- [ ] **T-13** ทดสอบลำดับคิวจากเวลาและ tie-break ที่ระบุ (FR-จองหนังสือ-03, NFR-DATA-01, AC-จองหนังสือ-02)
- [ ] **T-14** ทดสอบการปฏิเสธผู้ถูกระงับพร้อมสาเหตุ (FR-จองหนังสือ-04, AC-จองหนังสือ-03)
- [ ] **T-15** ทดสอบคำขอซ้ำหลังนิยามและเกณฑ์ตรวจรับได้รับการยืนยัน — **รอ Q-04, Q-05** (FR-จองหนังสือ-05, NFR-REL-01)
