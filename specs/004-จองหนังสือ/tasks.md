# งาน: จองหนังสือ

อ้างอิง: SPEC-จองหนังสือ-004 (Draft v2), `plan.md`

## ลำดับงาน

### วิเคราะห์และออกแบบ

- [x] **T-01** ตรวจจุดเชื่อมต่อข้อมูลผู้ใช้/บัญชี, หนังสือ และ Copy ที่มีอยู่ เพื่อเตรียมตรวจสิทธิ์และสถานะก่อนจอง (FR-จองหนังสือ-01, FR-จองหนังสือ-04, Constraints)
- [x] **T-02** ออกแบบการจัดเก็บ Reservation ระดับชื่อเรื่อง โดยเชื่อม member_id/title_id และรองรับ recorded_at, status กับ request_id (FR-จองหนังสือ-02, FR-จองหนังสือ-05, ASM-04, ASM-05)
- [x] **T-03** กำหนดตัวเปรียบเทียบคิวให้ตรงตามเวลา ชื่อจริง นามสกุล และรหัสสมาชิก โดยถือว่าเวลาเท่ากันเมื่อเท่ากันถึงหลักวินาที (FR-จองหนังสือ-03, NFR-DATA-01, ASM-01)

### พัฒนา

- [x] **T-04** ตรวจสิทธิ์ก่อนสร้างรายการ: ต้องเข้าสู่ระบบ บัญชี Active ไม่มีหนังสือเกินกำหนด/ค่าปรับค้าง และตรวจสถานะ Copy ของชื่อเรื่อง (FR-จองหนังสือ-01, FR-จองหนังสือ-04, ASM-02, ASM-03, Constraints)
- [x] **T-05** สร้าง Reservation เป็น Waiting ในคิวระดับชื่อเรื่อง และคำนวณลำดับจากจำนวนรายการ Waiting ก่อนหน้า + 1 (FR-จองหนังสือ-02, ASM-04, AC-จองหนังสือ-01)
- [x] **T-06** ป้องกัน request_id เดิมสร้างรายการซ้ำ; ปฏิเสธคำขอใหม่เมื่อสมาชิกมี Waiting/Ready สำหรับชื่อเรื่องเดียวกัน และทำให้การตรวจ/สร้างรองรับคำขอพร้อมกัน (FR-จองหนังสือ-05, NFR-REL-01, ASM-05, AC-จองหนังสือ-01)
- [x] **T-07** เพิ่ม `POST /api/reservations` ให้รับ title_id/request_id และคืนผลสำเร็จพร้อมคิว หรือผลปฏิเสธพร้อมสาเหตุ (FR-จองหนังสือ-01 ถึง FR-จองหนังสือ-05, AC-จองหนังสือ-01, AC-จองหนังสือ-03)
- [x] **T-08** เพิ่มหน้าส่งคำขอและแสดงผลสำเร็จ/ลำดับคิว/เหตุผลปฏิเสธ โดยใช้ request_id เดิมเมื่อ retry (FR-จองหนังสือ-01, FR-จองหนังสือ-02, FR-จองหนังสือ-04, FR-จองหนังสือ-05)

### ทดสอบ

- [x] **T-09** ทดสอบ AC-จองหนังสือ-01 กรณี 01-1 ถึง 01-4: จองครั้งแรกได้คิว 1, ส่ง request_id ซ้ำ, จองซ้ำโดยตั้งใจ และคำขอสองรายการพร้อมกัน (AC-จองหนังสือ-01, FR-จองหนังสือ-05, NFR-REL-01)
- [x] **T-10** ทดสอบ AC-จองหนังสือ-02: คิวหลังสอง Waiting ได้ลำดับ 3 และจัดลำดับรายการเวลาต่างกัน/เท่ากันตามเกณฑ์ครบถ้วน (AC-จองหนังสือ-02, FR-จองหนังสือ-03, NFR-DATA-01, ASM-01, ASM-04)
- [x] **T-11** ทดสอบ AC-จองหนังสือ-03: บัญชี/สมาชิกไม่ผ่านสิทธิ์, ทุก Copy ใช้จองไม่ได้ และกรณีมี Copy Available; ตรวจข้อความและยืนยันว่าไม่มี Reservation ถูกสร้าง (AC-จองหนังสือ-03, FR-จองหนังสือ-01, FR-จองหนังสือ-04, Constraints, ASM-02, ASM-03)
