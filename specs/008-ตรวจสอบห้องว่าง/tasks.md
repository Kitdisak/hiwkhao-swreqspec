# งาน: ตรวจสอบห้องว่าง

อ้างอิง: SPEC-ตรวจสอบห้องว่าง-008 (Draft v2)

## ลำดับงาน

### ยืนยันประเด็นคงค้าง

- [ ] **T-01** ยืนยันเวลาเปิดให้จองและหน่วยแบ่งช่วงเวลา — **รอ Q-01** (FR-ตรวจสอบห้องว่าง-02, Constraint: ต้องมีข้อมูลห้องและตารางการจอง)
- [ ] **T-02** ยืนยันว่าเกณฑ์จำนวนผู้ใช้ต้องเท่ากับหรืออย่างน้อยความจุห้อง — **รอ Q-02** (FR-ตรวจสอบห้องว่าง-03)
- [ ] **T-03** ยืนยันจุดเริ่ม/สิ้นสุดการวัดและชุดข้อมูล performance — **รอ Q-03** (FR-ตรวจสอบห้องว่าง-02, NFR-PERF-01)
- [ ] **T-04** ยืนยัน AC กับ FR/NFR mapping — **รอ Q-04** (FR-ตรวจสอบห้องว่าง-01, AC-ตรวจสอบห้องว่าง-01 ถึง AC-ตรวจสอบห้องว่าง-03)
- [ ] **T-05** ตรวจนโยบายหรือค่ากำหนด UC Case.pdf — **รอ Q-05** (FR-ตรวจสอบห้องว่าง-01, FR-ตรวจสอบห้องว่าง-02)

### พัฒนาและทดสอบ

- [ ] **T-06** ใช้ข้อมูลห้องและตารางการจองที่มีอยู่เป็นแหล่งอ้างอิงผลว่าง (FR-ตรวจสอบห้องว่าง-02, Constraint: ต้องมีข้อมูลห้องและตารางการจอง; Constraint: ผลลัพธ์อ้างอิงรายการจองที่มีอยู่)
- [ ] **T-07** รับวันที่และประเภทห้องเป็นเงื่อนไขค้นหา (FR-ตรวจสอบห้องว่าง-01)
- [ ] **T-08** แสดงห้องและทุกช่วงเวลาที่ยังว่างในวันที่เลือก โดยอิงตารางการจองและช่วงเวลาที่ทีมยืนยัน — **รอ Q-01** (FR-ตรวจสอบห้องว่าง-02)
- [ ] **T-09** กรองตามจำนวนผู้ใช้โดยใช้เกณฑ์ capacity ที่ทีมยืนยัน — **รอ Q-02** (FR-ตรวจสอบห้องว่าง-03)
- [ ] **T-10** เมื่อไม่มีห้องว่าง แจ้งตาม spec โดยไม่แสดงรายการหรือคำแนะนำวัน/เวลาอื่น (FR-ตรวจสอบห้องว่าง-04)
- [ ] **T-11** ทดสอบวันที่/ประเภทห้องและตรวจห้องพร้อมทุกช่วงเวลาว่าง (FR-ตรวจสอบห้องว่าง-01, FR-ตรวจสอบห้องว่าง-02, AC-ตรวจสอบห้องว่าง-01)
- [ ] **T-12** ทดสอบตัวกรองจำนวนผู้ใช้ตามเกณฑ์ที่ยืนยัน — **รอ Q-02** (FR-ตรวจสอบห้องว่าง-03, AC-ตรวจสอบห้องว่าง-02)
- [ ] **T-13** ทดสอบวันที่ไม่มีห้องว่างและตรวจว่าไม่มีรายการหรือคำแนะนำอื่น (FR-ตรวจสอบห้องว่าง-04, AC-ตรวจสอบห้องว่าง-03)
- [ ] **T-14** วัดเวลาการแสดงตารางตามจุดวัดและชุดข้อมูลที่ทีมกำหนด — **รอ Q-03** (FR-ตรวจสอบห้องว่าง-02, NFR-PERF-01)
