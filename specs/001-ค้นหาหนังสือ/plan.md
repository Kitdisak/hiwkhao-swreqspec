# แผนงาน: ค้นหาหนังสือ

อ้างอิง: SPEC-ค้นหาหนังสือ-001 (Draft v2)

## 1. สรุปแนวทาง

- นักศึกษา/สมาชิกค้นหาด้วยคำค้นเดียวที่ตรวจชื่อหนังสือ ผู้แต่ง ISBN และคำสำคัญ โดยจับคู่ข้อความส่วนต่อเนื่อง (FR-ค้นหาหนังสือ-01, ASM-01)
- แสดงผลหนึ่งรายการต่อชื่อหนังสือ พร้อมชื่อ ผู้แต่ง ISBN และรหัสประจำเล่มทั้งหมด (FR-ค้นหาหนังสือ-01, DOM-OPAC-05, ASM-07, ASM-08)
- เลือกผลลัพธ์แล้วเชื่อมไปยังหน้ารายละเอียด UC-03 โดยไม่สร้างหน้ารายละเอียดในขอบเขตนี้ (ASM-09, Scope: Out of scope, UC-03 FR-ดูรายละเอียดและตำแหน่งหนังสือ-01)
- ตัวกรองหลายหมวดหมู่และหลายผู้แต่งต้องตรงกับทุกค่าที่เลือก; หมวดหมู่ใช้มาตรฐานที่ห้องสมุดกำหนด (FR-ค้นหาหนังสือ-03, DOM-OPAC-06, ASM-03, ASM-04)
- เมื่อไม่พบผลลัพธ์แสดงข้อความที่กำหนดเท่านั้น; เป้าหมายเวลา 3 วินาทีประเมินที่ 50/200 ผู้ใช้พร้อมกันบนชุดข้อมูลที่ทีมกำหนด (FR-ค้นหาหนังสือ-02, NFR-PERF-01, ASM-05, ASM-06)

## 3. โมเดลข้อมูล

แบบจำลองเชิงตรรกะ ไม่ผูกกับชนิดฐานข้อมูล; แยกข้อมูลชื่อเรื่องออกจากตัวเล่มเพื่อรองรับการแสดงรหัสประจำเล่มทั้งหมดต่อหนึ่งผลลัพธ์ (FR-ค้นหาหนังสือ-01, DOM-OPAC-05, ASM-08)

| Entity | ฟิลด์หลัก | รองรับ |
|---|---|---|
| CatalogRecord | `bookId` (ใช้เชื่อม UC-03), `title`, `authors[]`, `isbn`, `keywords[]`, `categories[]` | FR-ค้นหาหนังสือ-01, FR-ค้นหาหนังสือ-03, DOM-OPAC-06, ASM-08, ASM-09 |
| BookCopy | `bookId`, `itemIdentifier` (ไม่ซ้ำกัน) | FR-ค้นหาหนังสือ-01, DOM-OPAC-05, ASM-08 |
| Category | `categoryCode`, `categoryLabel` ตามมาตรฐานที่ห้องสมุดกำหนด | FR-ค้นหาหนังสือ-03, DOM-OPAC-06, ASM-04 |

- ค้นหาคำค้นจาก `title`, `authors`, `isbn` และ `keywords` โดยจับคู่ข้อความต่อเนื่องในฟิลด์อย่างน้อยหนึ่งรายการ (FR-ค้นหาหนังสือ-01, ASM-01)
- เก็บผู้แต่งและหมวดหมู่เป็นค่าหลายค่าเพื่อรองรับตัวกรองหลายค่า และคัดผลลัพธ์ที่ตรงกับทุกค่าที่เลือก (FR-ค้นหาหนังสือ-03, ASM-03)
- รวม BookCopy ใต้ CatalogRecord เพื่อส่งรหัสประจำเล่มทั้งหมดของชื่อเรื่องเดียวกันในหนึ่งรายการผลค้นหา; รหัสแต่ละเล่มต้องไม่ซ้ำ (FR-ค้นหาหนังสือ-01, DOM-OPAC-05, ASM-08)
- ไม่เพิ่มข้อมูลสถานะ/ตำแหน่งหรือหน้ารายละเอียดในโมเดลค้นหา เพราะเป็นขอบเขต UC-03 (Scope: Out of scope, ASM-09, UC-03 FR-ดูรายละเอียดและตำแหน่งหนังสือ-01 ถึง FR-ดูรายละเอียดและตำแหน่งหนังสือ-03)

## 4. API / หน้าจอ

รายการ API เป็นข้อเสนอทางเทคนิค; ส่วนการอ่านรายละเอียดใช้ endpoint ที่ระบุในแผน UC-03 โดยไม่สร้าง endpoint รายละเอียดซ้ำ (FR-ค้นหาหนังสือ-01 ถึง FR-ค้นหาหนังสือ-03, ASM-09)

| รายการ | Method / path หรือ input/output หลัก | รองรับ |
|---|---|---|
| ค้นหาและกรองหนังสือ | `GET /api/books/search`; input: `query`, ค่าหมวดหมู่ที่เลือกหลายค่า, ค่าผู้แต่งที่เลือกหลายค่า; output: หนึ่งรายการต่อ CatalogRecord ที่มี `bookId`, ชื่อ, ผู้แต่ง, ISBN และรหัสประจำเล่มทั้งหมด | FR-ค้นหาหนังสือ-01, FR-ค้นหาหนังสือ-03, DOM-OPAC-05, DOM-OPAC-06, ASM-08 |
| ผลลัพธ์ว่าง | API ส่งผลลัพธ์ว่าง; หน้าจอแสดงเฉพาะ “ไม่พบหนังสือที่ค้นหา” | FR-ค้นหาหนังสือ-02, ASM-05 |
| หน้าค้นหา | input: คำค้นและตัวกรองหลายค่า; output: รายการผลลัพธ์/ข้อความไม่พบ และลิงก์ไป UC-03 เมื่อเลือกรายการ | FR-ค้นหาหนังสือ-01 ถึง FR-ค้นหาหนังสือ-03, ASM-09, UC-03 FR-ดูรายละเอียดและตำแหน่งหนังสือ-01 |
| อ่านรายละเอียดที่ UC-03 | `GET /api/books/{bookId}`; ใช้ `bookId` จากผลค้นหาเพื่อเชื่อมหน้า UC-03; ไม่พัฒนารายละเอียดใน UC-01 | ASM-09, Scope: Out of scope, UC-03 FR-ดูรายละเอียดและตำแหน่งหนังสือ-01 ถึง FR-ดูรายละเอียดและตำแหน่งหนังสือ-03 |

การเลือกหลายค่าในตัวกรองต้องส่งทุกค่าที่เลือกและให้ผลลัพธ์ตรงทุกค่า ไม่ใช่เพียงค่าใดค่าหนึ่ง (FR-ค้นหาหนังสือ-03, ASM-03); รายละเอียดหนังสือยังคงอยู่ใน UC-03 (ASM-09, Scope: Out of scope).

## 5. ตารางตรวจ Constraints

| Constraint ID | ถูกนำไปใช้ที่ไหนใน plan | สถานะ |
|---|---|---|
| DOM-OPAC-05 | `BookCopy.itemIdentifier` ไม่ซ้ำต่อเล่ม; ผลค้นหารวมรหัสประจำเล่มทั้งหมดต่อชื่อเรื่อง (FR-ค้นหาหนังสือ-01, ASM-08) | ใช้แล้ว |
| DOM-OPAC-06 | `Category` ใช้มาตรฐานที่ห้องสมุดกำหนด; ตัวกรองและข้อมูลหมวดหมู่ยึดค่ามาตรฐานนั้น ไม่ถือว่า DDC เป็นข้อบังคับ (FR-ค้นหาหนังสือ-03, ASM-04) | ใช้แล้ว |

## 6. แผนทดสอบจาก Acceptance Criteria

| AC ID | ชื่อ test | ทดสอบอย่างไร |
|---|---|---|
| AC-ค้นหาหนังสือ-01 | `test_AC_ค้นหาหนังสือ_01` | เตรียม CatalogRecord ที่ค้นพบได้จาก partial substring ในชื่อ ผู้แต่ง ISBN และคำสำคัญ; ตรวจหนึ่งรายการต่อชื่อเรื่องพร้อมผู้แต่ง ISBN และรหัสทุกเล่ม; ตรวจลิงก์ไป UC-03. วัดตั้งแต่ส่งคำค้นจนรายการแสดงด้วยชุดข้อมูลที่ทีมกำหนด แยกที่ผู้ใช้พร้อมกัน 50 และ 200 คน โดย 3 วินาทีเป็นเป้าหมายไม่ใช่เกณฑ์ผ่าน/ตก (FR-ค้นหาหนังสือ-01, NFR-PERF-01, DOM-OPAC-05, ASM-08, ASM-09, UC-03 FR-ดูรายละเอียดและตำแหน่งหนังสือ-01) |
| AC-ค้นหาหนังสือ-02 | `test_AC_ค้นหาหนังสือ_02` | ส่งคำค้นที่ไม่มีรายการตรงกัน; ตรวจว่าผลลัพธ์เป็นสถานะไม่พบและข้อความที่แสดงมีเพียง “ไม่พบหนังสือที่ค้นหา” ไม่มีคำแนะนำอื่น (FR-ค้นหาหนังสือ-02, ASM-05) |
| AC-ค้นหาหนังสือ-03 | `test_AC_ค้นหาหนังสือ_03` | เลือกหลายหมวดหมู่และผู้แต่ง; เตรียม record ที่ตรงทุกค่ากับ record ที่ขาดอย่างน้อยหนึ่งค่าจากแต่ละกลุ่ม; ตรวจว่าคงไว้เฉพาะ record ที่ตรงทุกค่าที่เลือก (FR-ค้นหาหนังสือ-03, ASM-03) |

## 7. ลำดับงาน

1. เตรียมการเชื่อม `bookId` กับปลายทาง UC-03 และใช้ React (Vite) ตามค่าเริ่มต้นที่ทีมเลือก; ไม่สร้างหน้ารายละเอียดซ้ำ (ASM-09, Scope: Out of scope, UC-03 FR-ดูรายละเอียดและตำแหน่งหนังสือ-01)
2. ออกแบบ CatalogRecord, BookCopy และ Category เชิงตรรกะ พร้อมแยกตัวเล่มและกำหนด uniqueness ของ `itemIdentifier` (FR-ค้นหาหนังสือ-01, DOM-OPAC-05, DOM-OPAC-06, ASM-08)
3. ทำบริการค้นหา substring ข้ามชื่อ ผู้แต่ง ISBN และคำสำคัญ (FR-ค้นหาหนังสือ-01, ASM-01)
4. ทำตัวกรองหลายหมวดหมู่/ผู้แต่งให้ตรงกับทุกค่าที่เลือก (FR-ค้นหาหนังสือ-03, ASM-03)
5. ทำ API และหน้าผลลัพธ์หนึ่งรายการต่อ CatalogRecord พร้อมรหัสประจำเล่มทุกเล่ม (FR-ค้นหาหนังสือ-01, DOM-OPAC-05, ASM-08)
6. ทำข้อความผลลัพธ์ว่างให้แสดงเฉพาะข้อความที่กำหนด และลิงก์เลือกรายการไป UC-03 (FR-ค้นหาหนังสือ-02, ASM-05, ASM-09, UC-03 FR-ดูรายละเอียดและตำแหน่งหนังสือ-01)
7. สร้างการทดสอบตาม AC ทั้งสามข้อ รวมกรณีตัวกรองหลายค่า (AC-ค้นหาหนังสือ-01 ถึง AC-ค้นหาหนังสือ-03)
8. ประเมินเวลาเป้าหมายด้วยชุดข้อมูลที่ทีมกำหนดที่ 50 และ 200 ผู้ใช้พร้อมกัน และบันทึกผลโดยไม่ตีความเป้าหมายเป็นเกณฑ์บังคับ (NFR-PERF-01, ASM-06)
