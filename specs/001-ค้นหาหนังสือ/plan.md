# แผนงาน: ค้นหาหนังสือ

อ้างอิง: SPEC-ค้นหาหนังสือ-001 (Draft v2)

## 1. สรุปแนวทาง

- ฟีเจอร์นี้ให้ผู้ใช้ค้นหาหนังสือด้วยข้อมูลค้นหาที่รองรับ โดยใช้การจับคู่บางส่วน (FR-ค้นหาหนังสือ-01, ASM-01)
- ผู้ใช้หลักคือนักศึกษา/สมาชิก (SPEC-ค้นหาหนังสือ-001)
- ระบบแสดงชื่อหนังสือและข้อมูลระบุตัวเล่มบางส่วนในผลค้นหา โดยรายละเอียดหนังสือเต็มอยู่นอกขอบเขต (FR-ค้นหาหนังสือ-01, DOM-OPAC-05)
- รองรับตัวกรองหมวดหมู่ DDC และผู้แต่ง โดยผลลัพธ์ต้องตรงกับตัวกรองที่เลือกทั้งหมด (FR-ค้นหาหนังสือ-03, DOM-OPAC-06, ASM-03, ASM-04)
- เมื่อไม่พบผลลัพธ์ แสดงข้อความที่กำหนด และประเมินเวลาค้นหาตาม NFR-PERF-01 โดยรายละเอียดที่ยังเปิดอยู่รอคำตอบทีม (FR-ค้นหาหนังสือ-02, NFR-PERF-01, Q-01 ถึง Q-04)

## 2. เทคโนโลยีที่ใช้

| สิ่งที่เลือก | มาจาก | หมายเหตุ |
|---|---|---|
| React (Vite) สำหรับหน้าบ้าน | ไม่มี Constraint ระบุ; ทีมเลือกเอง ไม่ได้มาจาก spec | ค่าเริ่มต้นตามแนวทางรายวิชาใน prompt /plan |
| Python FastAPI สำหรับหลังบ้าน | ไม่มี Constraint ระบุ; ทีมเลือกเอง ไม่ได้มาจาก spec | ค่าเริ่มต้นตามแนวทางรายวิชาใน prompt /plan |

## 3. โมเดลข้อมูล

ข้อเสนอโครงสร้างข้อมูลเบื้องต้น โดยฟิลด์แสดงผลของข้อมูลระบุตัวเล่มยังรอคำตอบ Q-03

| Entity | ฟิลด์หลักที่เสนอ | รองรับ |
|---|---|---|
| Book | title, authors, isbn, keywords, item_identifier, ddc_category | FR-ค้นหาหนังสือ-01, FR-ค้นหาหนังสือ-03, DOM-OPAC-05, DOM-OPAC-06 |

`item_identifier` ต้องไม่ซ้ำกันต่อเล่ม; `ddc_category` เก็บหมวดหมู่ตาม DDC. ฟิลด์ค้นหา/กรองเหล่านี้รองรับการค้นหาบางส่วนและตัวกรองที่ระบุไว้ (DOM-OPAC-05, DOM-OPAC-06, FR-ค้นหาหนังสือ-01, FR-ค้นหาหนังสือ-03, ASM-01, ASM-04). ยังไม่กำหนดว่าข้อมูลระบุตัวเล่มใดจะแสดงแก่ผู้ใช้จนกว่าจะได้คำตอบ Q-03 (Q-03).

## 4. API / หน้าจอ

รายการต่อไปนี้เป็นข้อเสนอทางเทคนิคจากทีม ไม่ใช่ข้อกำหนด API ใน spec

| รายการ | Method / path หรือ input/output หลัก | รองรับ |
|---|---|---|
| ค้นหาหนังสือและกรองผล | `GET /api/books/search`; input: `query`, `searchType`, optional `category`, `author`; output: รายการชื่อหนังสือและข้อมูลระบุตัวเล่มบางส่วน | FR-ค้นหาหนังสือ-01, FR-ค้นหาหนังสือ-03, DOM-OPAC-05, DOM-OPAC-06 |
| หน้าค้นหาหนังสือ | input: คำค้นและตัวกรองหมวดหมู่/ผู้แต่ง; output: รายการผลลัพธ์ หรือข้อความ “ไม่พบหนังสือที่ค้นหา” | FR-ค้นหาหนังสือ-01, FR-ค้นหาหนังสือ-02, FR-ค้นหาหนังสือ-03, AC-ค้นหาหนังสือ-01, AC-ค้นหาหนังสือ-02, AC-ค้นหาหนังสือ-03 |

รูปแบบ `searchType` และรายละเอียดผลลัพธ์เป็นข้อเสนอเพื่อออกแบบเท่านั้น; รายการข้อมูลระบุตัวเล่มที่จะเปิดเผยในผลลัพธ์ยังไม่กำหนดจนกว่าจะได้คำตอบ Q-03 (FR-ค้นหาหนังสือ-01, Q-03).

## 5. ตารางตรวจ Constraints

| Constraint ID | ถูกนำไปใช้ที่ไหนใน plan | สถานะ |
|---|---|---|
| DOM-OPAC-05 | `Book.item_identifier` ระบุรหัสประจำเล่มที่ไม่ซ้ำ; ใช้ในรายการผลค้นหาโดยรอรายละเอียดฟิลด์จาก Q-03 | ใช้แล้ว |
| DOM-OPAC-06 | `Book.ddc_category` และตัวกรองหมวดหมู่ใช้มาตรฐาน DDC | ใช้แล้ว |

## 6. แผนทดสอบจาก Acceptance Criteria

| AC ID | ชื่อ test | ทดสอบอย่างไร |
|---|---|---|
| AC-ค้นหาหนังสือ-01 | `test_AC_ค้นหาหนังสือ_01` | เตรียมหนังสือที่ตรงกับคำค้นบางส่วน ส่งคำค้นด้วยข้อมูลที่ระบบรองรับหนึ่งประเภท และตรวจว่าผลแสดงชื่อหนังสือกับข้อมูลระบุตัวเล่มบางส่วน (FR-ค้นหาหนังสือ-01, AC-ค้นหาหนังสือ-01, DOM-OPAC-05) |
| AC-ค้นหาหนังสือ-02 | `test_AC_ค้นหาหนังสือ_02` | ส่งคำค้นที่ไม่มีรายการตรงกัน แล้วตรวจว่ามีข้อความ “ไม่พบหนังสือที่ค้นหา” เท่านั้น (FR-ค้นหาหนังสือ-02, AC-ค้นหาหนังสือ-02) |
| AC-ค้นหาหนังสือ-03 | `test_AC_ค้นหาหนังสือ_03` | เตรียมรายการที่ตรงกับตัวกรองเพียงข้อเดียวและรายการที่ตรงกับทุกตัวกรอง เลือกหมวดหมู่และผู้แต่งพร้อมกัน แล้วตรวจว่าผลลัพธ์มีเฉพาะรายการที่ตรงทุกเงื่อนไข (FR-ค้นหาหนังสือ-03, AC-ค้นหาหนังสือ-03) |

การอ้างอิง AC กับ FR/NFR อย่างเป็นทางการยังรอคำตอบ Q-01; ตารางนี้เชื่อมโยงตามเนื้อหาปัจจุบันเพื่อร่างแผนเท่านั้น (Q-01).

## 7. ลำดับงาน

1. ยืนยัน Open Questions ที่กระทบฟิลด์ผลลัพธ์, traceability และเกณฑ์ประสิทธิภาพก่อนล็อกขอบเขต (Q-01, Q-02, Q-03, Q-04)
2. ออกแบบโครงสร้างข้อมูลหนังสือและตรวจความไม่ซ้ำของรหัสประจำเล่ม (FR-ค้นหาหนังสือ-01, DOM-OPAC-05)
3. กำหนดและเตรียมข้อมูลหมวดหมู่ DDC สำหรับการกรอง (FR-ค้นหาหนังสือ-03, DOM-OPAC-06)
4. ออกแบบและพัฒนาการค้นหาแบบบางส่วนตามข้อมูลค้นหาที่รองรับ (FR-ค้นหาหนังสือ-01, ASM-01)
5. พัฒนาตัวกรองหมวดหมู่และผู้แต่ง โดยใช้ทุกเงื่อนไขที่ผู้ใช้เลือก (FR-ค้นหาหนังสือ-03, ASM-03)
6. พัฒนารายการผลค้นหาและสถานะไม่พบผลลัพธ์ โดยยืนยันฟิลด์ที่แสดงก่อนลงมือทำ (FR-ค้นหาหนังสือ-01, FR-ค้นหาหนังสือ-02, Q-03)
7. ทดสอบกรณีค้นหา, ไม่พบผลลัพธ์ และตัวกรองตาม AC ทั้งสามข้อ (AC-ค้นหาหนังสือ-01, AC-ค้นหาหนังสือ-02, AC-ค้นหาหนังสือ-03)
8. วัดเวลาตั้งแต่ส่งคำค้นจนผลปรากฏ และสรุปผลเทียบกับเกณฑ์หลังทีมกำหนดสภาวะทดสอบ (NFR-PERF-01, Q-04)

## 8. สิ่งที่ยังไม่ทำ

- **Q-01** AC แต่ละข้ออ้างอิง FR/NFR ID ใดบ้าง? ต้องถามทีม ส่วนที่เกี่ยวข้องกับข้อนี้จะยังไม่สร้างจนกว่าจะได้คำตอบ
- **Q-02** มีนโยบายหรือค่ากำหนดใดใน UC Case.pdf ที่ยังต้องยืนยันสำหรับฟีเจอร์นี้? ต้องถามผู้จัดทำ UC Case.pdf หรือทีม ส่วนที่เกี่ยวข้องกับข้อนี้จะยังไม่สร้างจนกว่าจะได้คำตอบ
- **Q-03** ข้อมูลระบุตัวเล่มรายการใดบ้างที่ต้องแสดงในผลการค้นหา? ต้องถามทีม ส่วนที่เกี่ยวข้องกับข้อนี้จะยังไม่สร้างจนกว่าจะได้คำตอบ
- **Q-04** “สภาวะใช้งานทั่วไป” ของ NFR-PERF-01 ต้องกำหนดข้อมูลและจำนวนผู้ใช้เท่าใด และเกณฑ์ 3 วินาทีเป็นข้อบังคับหรือเป้าหมาย? ต้องถามทีม ส่วนที่เกี่ยวข้องกับข้อนี้จะยังไม่สร้างจนกว่าจะได้คำตอบ
