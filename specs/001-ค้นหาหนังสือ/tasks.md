# งาน: ค้นหาหนังสือ

อ้างอิง: SPEC-ค้นหาหนังสือ-001 (Draft v2)

## ลำดับงาน

### ยืนยันประเด็นคงค้าง

- [ ] **T-01** ยืนยันการเชื่อมโยง AC แต่ละข้อกับ FR/NFR ก่อนล็อก traceability — **รอ Q-01** (FR-ค้นหาหนังสือ-01, FR-ค้นหาหนังสือ-02, FR-ค้นหาหนังสือ-03, NFR-PERF-01, AC-ค้นหาหนังสือ-01 ถึง AC-ค้นหาหนังสือ-03)
- [ ] **T-02** ตรวจ UC Case.pdf และยืนยันว่ามีนโยบายหรือค่ากำหนดที่เกี่ยวข้องกับข้อกำหนดฟีเจอร์นี้หรือไม่ — **รอ Q-02** (FR-ค้นหาหนังสือ-01, FR-ค้นหาหนังสือ-02, FR-ค้นหาหนังสือ-03, NFR-PERF-01)
- [ ] **T-03** ยืนยันว่าข้อมูลระบุตัวเล่มรายการใดต้องแสดงในผลค้นหา — **รอ Q-03** (FR-ค้นหาหนังสือ-01, DOM-OPAC-05, AC-ค้นหาหนังสือ-01)
- [ ] **T-04** ยืนยันชุดข้อมูล จำนวนผู้ใช้ และสถานะของเกณฑ์ 3 วินาที เพื่อกำหนดการทดสอบประสิทธิภาพ — **รอ Q-04** (FR-ค้นหาหนังสือ-01, NFR-PERF-01)

### พัฒนาและทดสอบ

- [ ] **T-05** ออกแบบข้อมูลหนังสือให้รองรับชื่อ ผู้แต่ง ISBN คำสำคัญ รหัสประจำเล่ม และหมวดหมู่ DDC (FR-ค้นหาหนังสือ-01, FR-ค้นหาหนังสือ-03, DOM-OPAC-05, DOM-OPAC-06)
- [ ] **T-06** ตรวจให้รหัสประจำเล่มไม่ซ้ำกันในแต่ละเล่ม (DOM-OPAC-05, FR-ค้นหาหนังสือ-01)
- [ ] **T-07** รองรับข้อมูลหมวดหมู่ตามมาตรฐาน DDC สำหรับการกรอง (DOM-OPAC-06, FR-ค้นหาหนังสือ-03)
- [ ] **T-08** รองรับการค้นหาแบบบางส่วนด้วยชื่อหนังสือ ผู้แต่ง ISBN หรือคำสำคัญ โดยใช้ข้อมูลค้นหาอย่างน้อยหนึ่งประเภท (FR-ค้นหาหนังสือ-01, ASM-01)
- [ ] **T-09** รองรับตัวกรองหมวดหมู่และผู้แต่ง และคืนเฉพาะรายการที่ตรงกับทุกตัวกรองที่เลือก (FR-ค้นหาหนังสือ-03, ASM-03)
- [ ] **T-10** แสดงชื่อหนังสือและข้อมูลระบุตัวเล่มบางส่วนตามรายการที่ทีมยืนยัน — **รอ Q-03** (FR-ค้นหาหนังสือ-01, DOM-OPAC-05, AC-ค้นหาหนังสือ-01)
- [ ] **T-11** เมื่อไม่มีผลลัพธ์ ให้แสดงเฉพาะข้อความ “ไม่พบหนังสือที่ค้นหา” (FR-ค้นหาหนังสือ-02, ASM-05, AC-ค้นหาหนังสือ-02)
- [ ] **T-12** ทดสอบค้นหาบางส่วนด้วยข้อมูลค้นหาหนึ่งประเภท และตรวจชื่อหนังสือกับข้อมูลระบุตัวเล่มบางส่วน — **รอ Q-03** (FR-ค้นหาหนังสือ-01, DOM-OPAC-05, AC-ค้นหาหนังสือ-01)
- [ ] **T-13** ทดสอบคำค้นที่ไม่มีรายการตรงกัน และตรวจว่าแสดงเฉพาะข้อความที่กำหนด (FR-ค้นหาหนังสือ-02, AC-ค้นหาหนังสือ-02)
- [ ] **T-14** ทดสอบกรณีเลือกตัวกรองหมวดหมู่และผู้แต่งพร้อมกัน และตรวจว่าผลลัพธ์ตรงทุกเงื่อนไข (FR-ค้นหาหนังสือ-03, DOM-OPAC-06, AC-ค้นหาหนังสือ-03)
- [ ] **T-15** วัดเวลาตั้งแต่ส่งคำค้นจนรายการผลลัพธ์ปรากฏตามสภาวะทดสอบที่ทีมยืนยัน — **รอ Q-04** (FR-ค้นหาหนังสือ-01, NFR-PERF-01)
