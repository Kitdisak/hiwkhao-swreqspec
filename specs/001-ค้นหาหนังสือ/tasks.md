# งาน: ค้นหาหนังสือ

อ้างอิง: SPEC-ค้นหาหนังสือ-001 (Draft v2), specs/001-ค้นหาหนังสือ/plan.md
Task ID ต่อเนื่องจากรายการงานรุ่นก่อน; รายการนี้สะท้อนขอบเขต spec/plan ปัจจุบัน

## ลำดับงาน

- [ ] **T-16** ออกแบบแบบจำลอง CatalogRecord, BookCopy และ Category ให้แยกชื่อเรื่องจากตัวเล่ม รองรับผู้แต่ง/หมวดหมู่หลายค่า และกำหนด `itemIdentifier` ไม่ซ้ำต่อเล่ม (FR-ค้นหาหนังสือ-01, FR-ค้นหาหนังสือ-03, DOM-OPAC-05, DOM-OPAC-06, ASM-08)
- [ ] **T-17** ปรับบริการค้นหาให้รับคำค้นเดียวและจับคู่ข้อความส่วนต่อเนื่องในชื่อหนังสือ ผู้แต่ง ISBN หรือคำสำคัญโดยอัตโนมัติ (FR-ค้นหาหนังสือ-01, ASM-01)
- [ ] **T-18** ปรับตัวกรองหมวดหมู่และผู้แต่งให้รับหลายค่า และคืนผลเฉพาะรายการที่ตรงกับค่าทุกค่าที่เลือกในแต่ละประเภท (FR-ค้นหาหนังสือ-03, ASM-03)
- [ ] **T-19** จัดกลุ่มผลลัพธ์เป็นหนึ่งรายการต่อชื่อหนังสือ พร้อมชื่อ ผู้แต่ง ISBN และรหัสประจำเล่มทั้งหมด (FR-ค้นหาหนังสือ-01, DOM-OPAC-05, ASM-07, ASM-08)
- [ ] **T-20** สร้างหน้าค้นหาด้วย React (Vite) ให้ส่งคำค้นและตัวกรองหลายค่าไปยัง API และแสดงข้อมูลผลลัพธ์ตาม spec (FR-ค้นหาหนังสือ-01, FR-ค้นหาหนังสือ-03, ASM-07)
- [ ] **T-21** เชื่อมการเลือกรายการผลค้นหาไปยังหน้ารายละเอียด UC-03 โดยใช้ `bookId` และไม่สร้างรายละเอียดหนังสือซ้ำใน UC-01 (FR-ค้นหาหนังสือ-01, ASM-09, UC-03 FR-ดูรายละเอียดและตำแหน่งหนังสือ-01)
- [ ] **T-22** เมื่อไม่มีผลลัพธ์ ให้แสดงเฉพาะข้อความ “ไม่พบหนังสือที่ค้นหา” (FR-ค้นหาหนังสือ-02, ASM-05)
- [ ] **T-23** ทดสอบ AC-ค้นหาหนังสือ-01 ด้วยคำค้นบางส่วนจากแต่ละฟิลด์ ตรวจหนึ่งรายการต่อชื่อเรื่อง ข้อมูลแสดงผลและรหัสทุกเล่ม รวมทั้งลิงก์ไป UC-03; ตั้งชื่อ test `test_AC_ค้นหาหนังสือ_01` (FR-ค้นหาหนังสือ-01, DOM-OPAC-05, ASM-08, ASM-09, AC-ค้นหาหนังสือ-01)
- [ ] **T-24** ทดสอบกรณีไม่มีผลลัพธ์และยืนยันข้อความที่แสดงตรงตามข้อกำหนดเท่านั้น; ตั้งชื่อ test `test_AC_ค้นหาหนังสือ_02` (FR-ค้นหาหนังสือ-02, AC-ค้นหาหนังสือ-02)
- [ ] **T-25** ทดสอบการเลือกหลายหมวดหมู่และหลายผู้แต่ง โดยตรวจว่าผลลัพธ์ต้องตรงกับทุกค่าที่เลือก; ตั้งชื่อ test `test_AC_ค้นหาหนังสือ_03` (FR-ค้นหาหนังสือ-03, DOM-OPAC-06, AC-ค้นหาหนังสือ-03)
- [ ] **T-26** วัดเวลาตั้งแต่ส่งคำค้นจนรายการผลลัพธ์ปรากฏ ด้วยชุดข้อมูลทดสอบที่ทีมกำหนดที่ผู้ใช้พร้อมกัน 50 และ 200 คน และบันทึกผลเทียบกับเป้าหมาย 3 วินาทีโดยไม่ถือเป็นเกณฑ์ผ่าน/ตก (NFR-PERF-01, ASM-06, AC-ค้นหาหนังสือ-01)
