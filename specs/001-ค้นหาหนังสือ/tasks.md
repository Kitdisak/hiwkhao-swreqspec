# งาน: ค้นหาหนังสือ

อ้างอิง: SPEC-ค้นหาหนังสือ-001 (Draft v2), specs/001-ค้นหาหนังสือ/plan.md
Task ID ต่อเนื่องจากรายการงานรุ่นก่อน; รายการนี้สะท้อนขอบเขต spec/plan ปัจจุบัน

## ลำดับงาน

- [x] **T-16** ออกแบบแบบจำลอง CatalogRecord, BookCopy และ Category ให้แยกชื่อเรื่องจากตัวเล่ม รองรับผู้แต่ง/หมวดหมู่หลายค่า และกำหนด `itemIdentifier` ไม่ซ้ำต่อเล่ม — เสร็จแล้ว: เพิ่มโมเดลและตรวจรหัสประจำเล่มซ้ำ (FR-ค้นหาหนังสือ-01, FR-ค้นหาหนังสือ-03, DOM-OPAC-05, DOM-OPAC-06, ASM-08)
- [x] **T-17** ปรับบริการค้นหาให้รับคำค้นเดียวและจับคู่ข้อความส่วนต่อเนื่องในชื่อหนังสือ ผู้แต่ง ISBN หรือคำสำคัญโดยอัตโนมัติ — เสร็จแล้ว (FR-ค้นหาหนังสือ-01, ASM-01)
- [x] **T-18** ปรับตัวกรองหมวดหมู่และผู้แต่งให้รับหลายค่า และคืนผลเฉพาะรายการที่ตรงกับค่าทุกค่าที่เลือกในแต่ละประเภท — เสร็จแล้ว; API รับ query parameter ซ้ำหลายค่าได้ (FR-ค้นหาหนังสือ-03, ASM-03)
- [x] **T-19** จัดกลุ่มผลลัพธ์เป็นหนึ่งรายการต่อชื่อหนังสือ พร้อมชื่อ ผู้แต่ง ISBN และรหัสประจำเล่มทั้งหมด — เสร็จแล้วผ่าน CatalogRecord ที่บรรจุ BookCopy หลายรายการ (FR-ค้นหาหนังสือ-01, DOM-OPAC-05, ASM-07, ASM-08)
- [x] **T-20** สร้างหน้าค้นหาด้วย React (Vite) ให้ส่งคำค้นและตัวกรองหลายค่าไปยัง API และแสดงข้อมูลผลลัพธ์ตาม spec — เสร็จแล้ว (FR-ค้นหาหนังสือ-01, FR-ค้นหาหนังสือ-03, ASM-07)
- [x] **T-21** เชื่อมการเลือกรายการผลค้นหาไปยังหน้ารายละเอียด UC-03 ผ่าน `/books/{bookId}` โดยไม่สร้างรายละเอียดหนังสือซ้ำใน UC-01 — เสร็จแล้ว: ชื่อหนังสือเป็นลิงก์และใช้ `book_id` (FR-ค้นหาหนังสือ-01, ASM-09, UC-03 FR-ดูรายละเอียดและตำแหน่งหนังสือ-01)
- [x] **T-22** เมื่อไม่มีผลลัพธ์ ให้แสดงเฉพาะข้อความ “ไม่พบหนังสือที่ค้นหา” — เสร็จแล้ว: UI แสดงข้อความ API โดยไม่แสดงรายการหนังสือ (FR-ค้นหาหนังสือ-02, ASM-05)
- [x] **T-23** ทดสอบ AC-ค้นหาหนังสือ-01 ด้วยคำค้นบางส่วนจากชื่อ ผู้แต่ง ISBN และคำสำคัญ ตรวจหนึ่งรายการต่อชื่อเรื่องและข้อมูล/รหัสทุกเล่ม; ตรวจลิงก์ UC-03 ใน UI; ตั้งชื่อ test `test_AC_ค้นหาหนังสือ_01` — เสร็จแล้ว (FR-ค้นหาหนังสือ-01, DOM-OPAC-05, ASM-08, ASM-09, AC-ค้นหาหนังสือ-01)
- [x] **T-24** ทดสอบกรณีไม่มีผลลัพธ์ที่ API และยืนยัน empty state ใน UI ว่าไม่มีรายการหนังสือ; ตั้งชื่อ test `test_AC_ค้นหาหนังสือ_02` — เสร็จแล้ว (FR-ค้นหาหนังสือ-02, AC-ค้นหาหนังสือ-02)
- [x] **T-25** ทดสอบการเลือกหลายหมวดหมู่และหลายผู้แต่ง โดยตรวจว่าผลลัพธ์ต้องตรงกับทุกค่าที่เลือก; ตั้งชื่อ test `test_AC_ค้นหาหนังสือ_03` — เสร็จแล้ว (FR-ค้นหาหนังสือ-03, DOM-OPAC-06, AC-ค้นหาหนังสือ-03)
- [x] **T-26** วัดเวลาตั้งแต่ส่งคำค้นจนรายการผลลัพธ์ปรากฏ ด้วยข้อมูล seed 4 ชื่อเรื่องที่ผู้ใช้พร้อมกัน 50 และ 200 คน และบันทึกผลเทียบเป้าหมาย 3 วินาทีโดยไม่ถือเป็นเกณฑ์ผ่าน/ตก — เพิ่มสคริปต์วัด API และตรวจผลแสดงใน browser ระหว่างโหลดร่วม (NFR-PERF-01, ASM-06, AC-ค้นหาหนังสือ-01)
