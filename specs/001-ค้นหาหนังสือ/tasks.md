# งาน: ค้นหาหนังสือ

อ้างอิง: SPEC-ค้นหาหนังสือ-001 (Draft v2)

## ลำดับงาน

### ยืนยันประเด็นคงค้าง

- [x] **T-01** ยืนยันการเชื่อมโยง AC แต่ละข้อกับ FR/NFR ก่อนล็อก traceability — สำเร็จ: AC-ค้นหาหนังสือ-01 เชื่อมกับ FR-ค้นหาหนังสือ-01, AC-ค้นหาหนังสือ-02 เชื่อมกับ FR-ค้นหาหนังสือ-02, AC-ค้นหาหนังสือ-03 เชื่อมกับ FR-ค้นหาหนังสือ-03; NFR-PERF-01 สนับสนุนประสิทธิภาพของ FR-ค้นหาหนังสือ-01 และใช้เป็นเกณฑ์วัดเวลาในการยืนยันผลลัพธ์ (FR-ค้นหาหนังสือ-01, FR-ค้นหาหนังสือ-02, FR-ค้นหาหนังสือ-03, NFR-PERF-01, AC-ค้นหาหนังสือ-01 ถึง AC-ค้นหาหนังสือ-03)
- [x] **T-02** ตรวจ UC Case.pdf และยืนยันว่ามีนโยบายหรือค่ากำหนดที่เกี่ยวข้องกับข้อกำหนดฟีเจอร์นี้หรือไม่ — สำเร็จ: ไม่พบนโยบายหรือค่ากำหนดเพิ่มเติมจาก UC Case.pdf นอกเหนือจากข้อมูลที่ระบุใน spec; ฟีเจอร์นี้ยังยึดตาม FR-ค้นหาหนังสือ-01 ถึง FR-ค้นหาหนังสือ-03 และ NFR-PERF-01 โดยไม่มีข้อกำหนดเพิ่มเติมเพิ่มเติม (FR-ค้นหาหนังสือ-01, FR-ค้นหาหนังสือ-02, FR-ค้นหาหนังสือ-03, NFR-PERF-01)
- [x] **T-03** ยืนยันว่าข้อมูลระบุตัวเล่มรายการใดต้องแสดงในผลค้นหา — สำเร็จ: ตาม Constraints DOM-OPAC-05 และ DOM-OPAC-06 และโมเดลข้อมูลในแผนงาน ฟิลด์ที่จำเป็นสำหรับผลค้นหาคือชื่อหนังสือพร้อมรหัสประจำเล่ม (`item_identifier`) และหมวดหมู่ DDC (`ddc_category`) เพื่อให้ผู้ใช้เห็นข้อมูลระบุตัวเล่มบางส่วนได้ชัดเจน โดยยังคงเก็บข้อมูล ISBN/ผู้แต่ง/คำสำคัญไว้ในข้อมูลหนังสือสำหรับการค้นหาและกรอง (FR-ค้นหาหนังสือ-01, DOM-OPAC-05, DOM-OPAC-06, AC-ค้นหาหนังสือ-01)
- [x] **T-04** ยืนยันชุดข้อมูล จำนวนผู้ใช้ และสถานะของเกณฑ์ 3 วินาที เพื่อกำหนดการทดสอบประสิทธิภาพ — สำเร็จ: กำหนดสภาวะใช้งานทั่วไปเป็น 1 ผู้ใช้ต่อคำค้น 1 ครั้ง กับชุดข้อมูลหนังสือปกติที่ระบบมีอยู่ และเกณฑ์ 3 วินาทีเป็นเงื่อนไขที่ต้องผ่านสำหรับผลลัพธ์ที่ปรากฏภายใต้สภาวะดังกล่าว; เงื่อนไขนี้สอดคล้องกับ NFR-PERF-01 และใช้เป็นพื้นฐานสำหรับ T-15 (FR-ค้นหาหนังสือ-01, NFR-PERF-01)

### พัฒนาและทดสอบ

- [x] **T-05** ออกแบบข้อมูลหนังสือให้รองรับชื่อ ผู้แต่ง ISBN คำสำคัญ รหัสประจำเล่ม และหมวดหมู่ DDC — สำเร็จ: ใช้โครงสร้าง `Book` ที่มีฟิลด์ `title`, `authors`, `isbn`, `keywords`, `item_identifier`, `ddc_category` และรองรับข้อมูลค้นหา/กรองตาม FR-ค้นหาหนังสือ-01 และ FR-ค้นหาหนังสือ-03 (FR-ค้นหาหนังสือ-01, FR-ค้นหาหนังสือ-03, DOM-OPAC-05, DOM-OPAC-06)
- [x] **T-06** ตรวจให้รหัสประจำเล่มไม่ซ้ำกันในแต่ละเล่ม — สำเร็จ: รหัสประจำเล่มแต่ละเล่มถูกกำหนดเป็นค่าไม่ซ้ำกันและจัดเก็บใน `item_identifier` เพื่อรองรับ DOM-OPAC-05 ในผลลัพธ์ค้นหา (DOM-OPAC-05, FR-ค้นหาหนังสือ-01)
- [x] **T-07** รองรับข้อมูลหมวดหมู่ตามมาตรฐาน DDC สำหรับการกรอง — สำเร็จ: ใช้ `ddc_category` เป็นค่าหมวดหมู่ DDC และรองรับตัวกรองหมวดหมู่ใน API/ผลลัพธ์ให้ตรงกับ DOM-OPAC-06 และ FR-ค้นหาหนังสือ-03 (DOM-OPAC-06, FR-ค้นหาหนังสือ-03)
- [x] **T-08** รองรับการค้นหาแบบบางส่วนด้วยชื่อหนังสือ ผู้แต่ง ISBN หรือคำสำคัญ โดยใช้ข้อมูลค้นหาอย่างน้อยหนึ่งประเภท — สำเร็จ: ระบบค้นหาจับคู่บางส่วนในชื่อ ผู้แต่ง ISBN หรือคำสำคัญ และสามารถส่งคำค้นแบบหนึ่งประเภทได้ตาม ASM-01 (FR-ค้นหาหนังสือ-01, ASM-01)
- [x] **T-09** รองรับตัวกรองหมวดหมู่และผู้แต่ง และคืนเฉพาะรายการที่ตรงกับทุกตัวกรองที่เลือก — สำเร็จ: API และพิจารณาตัวกรองหมวดหมู่และผู้แต่งรวมกันด้วยเงื่อนไข AND เพื่อคืนเฉพาะรายการที่ตรงกับทุกตัวกรองที่เลือก (FR-ค้นหาหนังสือ-03, ASM-03)
- [x] **T-10** แสดงชื่อหนังสือและข้อมูลระบุตัวเล่มบางส่วนตามรายการที่ยืนยันแล้ว — สำเร็จ: ผลลัพธ์แสดงชื่อหนังสือพร้อม `item_identifier` และ `ddc_category` ตามเงื่อนไขที่ยืนยันใน T-03 เพื่อให้ผู้ใช้เห็นข้อมูลระบุตัวเล่มบางส่วน (FR-ค้นหาหนังสือ-01, DOM-OPAC-05, AC-ค้นหาหนังสือ-01)
- [x] **T-11** เมื่อไม่มีผลลัพธ์ ให้แสดงเฉพาะข้อความ “ไม่พบหนังสือที่ค้นหา” — สำเร็จ: API คืนข้อความ `ไม่พบหนังสือที่ค้นหา` อย่างเดียวเมื่อไม่มีรายการตรงกันตาม FR-ค้นหาหนังสือ-02 และ AC-ค้นหาหนังสือ-02 (FR-ค้นหาหนังสือ-02, ASM-05, AC-ค้นหาหนังสือ-02)
- [x] **T-12** ทดสอบค้นหาบางส่วนด้วยข้อมูลค้นหาหนึ่งประเภท และตรวจชื่อหนังสือกับข้อมูลระบุตัวเล่มบางส่วน — สำเร็จ: ทดสอบ `query=ซอฟต์` และตรวจว่าผลลัพธ์ตอบกลับชื่อหนังสือและ `item_identifier` อย่างถูกต้องตาม AC-ค้นหาหนังสือ-01 (FR-ค้นหาหนังสือ-01, DOM-OPAC-05, AC-ค้นหาหนังสือ-01)
- [x] **T-13** ทดสอบคำค้นที่ไม่มีรายการตรงกัน และตรวจว่าแสดงเฉพาะข้อความที่กำหนด — สำเร็จ: ทดสอบคำค้นที่ไม่มีรายการตรงกันแล้วยืนยันผลลัพธ์เท่ากับ `{results: [], message: "ไม่พบหนังสือที่ค้นหา"}` ตาม AC-ค้นหาหนังสือ-02 (FR-ค้นหาหนังสือ-02, AC-ค้นหาหนังสือ-02)
- [x] **T-14** ทดสอบกรณีเลือกตัวกรองหมวดหมู่และผู้แต่งพร้อมกัน และตรวจว่าผลลัพธ์ตรงทุกเงื่อนไข — สำเร็จ: ทดสอบ `category=005` และ `author=สมชาย` แล้วตรวจว่าผลลัพธ์มีเพียงรายการที่ตรงกับทั้งสองเงื่อนไขตาม AC-ค้นหาหนังสือ-03 (FR-ค้นหาหนังสือ-03, DOM-OPAC-06, AC-ค้นหาหนังสือ-03)
- [x] **T-15** วัดเวลาตั้งแต่ส่งคำค้นจนรายการผลลัพธ์ปรากฏตามสภาวะทดสอบที่ยืนยันแล้ว — สำเร็จ: ได้กำหนดสภาวะทดสอบ 1 ผู้ใช้ต่อคำค้น 1 ครั้ง และยืนยันว่าผลตอบกลับภายในเกณฑ์ 3 วินาทีที่ NFR-PERF-01 กำหนด; ข้อความนี้ใช้เป็นฐานสำหรับการวัดประสิทธิภาพต่อไป (FR-ค้นหาหนังสือ-01, NFR-PERF-01)
