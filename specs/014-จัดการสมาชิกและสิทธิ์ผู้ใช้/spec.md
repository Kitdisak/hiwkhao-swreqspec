# Feature: จัดการสมาชิกและสิทธิ์ผู้ใช้
Spec ID: SPEC-จัดการสมาชิกและสิทธิ์ผู้ใช้-014 | Source: SRS v0.3 | Use case: UC-14
Owner: ทีม หิวข้าว  | Status: Draft v2 | Updated: 2569-10-11

## Goal
ผู้ดูแลระบบจัดการบัญชีผู้ใช้ สถานะบัญชี บทบาท และสิทธิ์ตามอำนาจที่ได้รับ

## Primary Actor
ผู้ดูแลระบบ (System Administrator)

## Scope
### In scope
- ค้นหาบัญชีผู้ใช้
- เพิ่มหรือแก้ไขข้อมูลบัญชี
- ระงับหรือเปิดใช้งานบัญชี
- กำหนด Role/Permission และบันทึกประวัติการเปลี่ยนแปลง
### Out of scope
- ตรวจสอบประวัติการใช้งานโดยละเอียด (อยู่นอกขอบเขต UC-14 และเกี่ยวข้องกับงาน Audit)

## Constraints
- Admin ต้องเข้าสู่ระบบและมีสิทธิ์จัดการผู้ใช้
- ต้องป้องกันการเข้าถึงข้อมูลโดยไม่ได้รับอนุญาต
- การเปลี่ยน Permission ต้องบันทึกใน Audit Log

## Requirements
- **FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-01** ระบบต้องให้ Admin ค้นหาและเลือกบัญชีผู้ใช้เพื่อจัดการได้
- **FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-02** ระบบต้องให้ Admin แก้ไขข้อมูลบัญชีทั่วไปของบัญชีอื่นที่ตนมีสิทธิ์จัดการ และกำหนด Role/Permission จากรายการที่มีอยู่ได้ไม่เกินอำนาจของตน
- **FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-03** ระบบต้องอนุญาตให้ระงับหรือเปิดใช้งานบัญชีผู้ใช้อื่นที่ Admin มีสิทธิ์จัดการ; เมื่อเปิดใช้งาน สถานะบัญชีต้องเป็น Active
- **FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-04** เมื่อระงับบัญชี ระบบต้องเปลี่ยนสถานะเป็น Suspended (UC-14 Alternative 4a)
- **FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-05** หาก Admin พยายามกำหนดสิทธิ์ที่ตนไม่มีอำนาจ ระบบต้องปฏิเสธ (UC-14 Exception 5a)
- **FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-06** ระบบต้องบันทึกผู้กระทำ เวลา ค่าเดิม และค่าใหม่ของการเปลี่ยนแปลงบัญชีและสิทธิ์ใน Audit Log; หากบันทึก Audit Log ไม่สำเร็จ ระบบต้องไม่เปลี่ยนแปลงบัญชีหรือสิทธิ์

## Quality Requirements
- **NFR-SEC-01** ต้องควบคุมสิทธิ์การจัดการบัญชีและ Permission
- **NFR-AUDIT-01** การเปลี่ยน Permission ต้องถูกบันทึกใน Audit Log พร้อมผู้กระทำ เวลา ค่าเดิม และค่าใหม่; หากบันทึกไม่สำเร็จ การเปลี่ยน Permission ต้องไม่ถูกนำไปใช้

## Acceptance Criteria
- [ ] **AC-จัดการสมาชิกและสิทธิ์ผู้ใช้-01** (FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-02, FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-06, NFR-AUDIT-01)
  - **Given** Admin มีสิทธิ์จัดการบัญชี
  - **When** Admin เปลี่ยน Role หรือสถานะบัญชีและยืนยัน
  - **Then** ระบบอัปเดตข้อมูลและบันทึกผู้กระทำ เวลา ค่าเดิม และค่าใหม่ใน Audit Log
- [ ] **AC-จัดการสมาชิกและสิทธิ์ผู้ใช้-02** (FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-05, NFR-SEC-01)
  - **Given** Admin ไม่มีสิทธิ์กำหนด Permission ที่ร้องขอ
  - **When** Admin ยืนยันการเปลี่ยนสิทธิ์
  - **Then** ระบบปฏิเสธและไม่เปลี่ยน Permission
- [ ] **AC-จัดการสมาชิกและสิทธิ์ผู้ใช้-03** (FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-01, FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-03, FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-04)
  - **Given** Admin เลือกระงับบัญชี
  - **When** Admin ยืนยันการระงับ
  - **Then** ระบบเปลี่ยนสถานะบัญชีเป็น Suspended

## Assumptions
- **ASM-01** Admin มอบ Role/Permission ได้เฉพาะรายการที่มีอยู่และไม่เกินอำนาจของตน
- **ASM-02** Admin จัดการได้เฉพาะบัญชีอื่น ไม่แก้ไขหรือเปลี่ยนสถานะบัญชีของตนเอง
- **ASM-03** การเปิดใช้งานบัญชีเปลี่ยนสถานะเป็น Active
- **ASM-04** Audit Log เก็บผู้กระทำ เวลา ค่าเดิม และค่าใหม่; หากบันทึกไม่สำเร็จ การเปลี่ยนแปลงบัญชี/Permission จะไม่ถูกนำไปใช้
- **ASM-05** การตรวจ NFR-SEC-01 ครอบคลุมกรณีผู้ไม่มี Permission ถูกปฏิเสธการจัดการบัญชีหรือสิทธิ์
- **ASM-06** AC-01 อ้างอิง FR-02/FR-06/NFR-AUDIT-01; AC-02 อ้างอิง FR-05/NFR-SEC-01; AC-03 อ้างอิง FR-01/FR-03/FR-04
- **ASM-07** ไม่มีนโยบายหรือค่ากำหนดเพิ่มเติมจากที่ระบุใน spec และ UC Case.pdf สำหรับฟีเจอร์นี้
