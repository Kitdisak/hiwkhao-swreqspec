# งาน: จัดการสมาชิกและสิทธิ์ผู้ใช้

อ้างอิง: SPEC-จัดการสมาชิกและสิทธิ์ผู้ใช้-014 (Draft v2)

## ลำดับงาน

### ยืนยันประเด็นคงค้าง

- [ ] **T-01** ยืนยันฟิลด์ที่ถือเป็นข้อมูลบัญชีทั่วไปและแก้ไขได้ — **รอ Q-01** (FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-02)

### พัฒนาและทดสอบ

- [ ] **T-02** ตรวจการเข้าสู่ระบบและ Permission ของ Admin ก่อนค้นหาหรือจัดการบัญชี; ป้องกันการเข้าถึงโดยไม่ได้รับอนุญาต (FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-01, NFR-SEC-01, Constraint: Admin ต้องเข้าสู่ระบบ/มีสิทธิ์และต้องป้องกันการเข้าถึงไม่ได้รับอนุญาต)
- [ ] **T-03** ค้นหาและเลือกบัญชีผู้ใช้ที่ Admin มีสิทธิ์จัดการ (FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-01)
- [ ] **T-04** แก้ไขข้อมูลทั่วไปของบัญชีอื่นตามฟิลด์ที่ทีมยืนยัน — **รอ Q-01** (FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-02)
- [ ] **T-05** กำหนด Role/Permission จากรายการที่มีอยู่และไม่เกินอำนาจของ Admin; ปฏิเสธสิทธิ์ที่เกินอำนาจ (FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-02, FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-05, NFR-SEC-01)
- [ ] **T-06** รองรับระงับบัญชีเป็น Suspended และเปิดใช้งานเป็น Active (FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-03, FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-04)
- [ ] **T-07** บันทึกผู้กระทำ เวลา ค่าเดิม และค่าใหม่ใน Audit Log; หากบันทึกไม่สำเร็จ ห้ามใช้การเปลี่ยนบัญชีหรือ Permission (FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-06, NFR-AUDIT-01, Constraint: การเปลี่ยน Permission ต้องบันทึกใน Audit Log)
- [ ] **T-08** ทดสอบการเปลี่ยน Role/สถานะและ Audit Log รวมกรณี Audit Log ล้มเหลวแล้วไม่มีการเปลี่ยนแปลง (FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-02, FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-06, NFR-AUDIT-01, AC-จัดการสมาชิกและสิทธิ์ผู้ใช้-01)
- [ ] **T-09** ทดสอบ Admin ไม่มีอำนาจกำหนด Permission แล้วถูกปฏิเสธและ Permission คงเดิม (FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-05, NFR-SEC-01, AC-จัดการสมาชิกและสิทธิ์ผู้ใช้-02)
- [ ] **T-10** ทดสอบค้นหาบัญชีและระงับบัญชีที่เลือกให้เป็น Suspended (FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-01, FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-03, FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-04, AC-จัดการสมาชิกและสิทธิ์ผู้ใช้-03)

## ตรวจสอบความครอบคลุม

| รายการใน spec | งานที่รองรับ |
|---|---|
| AC-จัดการสมาชิกและสิทธิ์ผู้ใช้-01 | T-08 |
| AC-จัดการสมาชิกและสิทธิ์ผู้ใช้-02 | T-09 |
| AC-จัดการสมาชิกและสิทธิ์ผู้ใช้-03 | T-10 |

| Constraint: เปลี่ยน Permission ต้องบันทึก Audit Log | T-07, T-08 |
