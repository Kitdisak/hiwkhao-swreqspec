# งาน: จัดการสมาชิกและสิทธิ์ผู้ใช้

อ้างอิง: SPEC-จัดการสมาชิกและสิทธิ์ผู้ใช้-014 (Draft v2)

## ลำดับงาน

### ยืนยันประเด็นคงค้าง

- [x] **T-01** ยืนยันฟิลด์ที่ถือเป็นข้อมูลบัญชีทั่วไปและแก้ไขได้ — สำเร็จ: FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-02 ระบุว่าระบบต้องให้ Admin แก้ไขข้อมูลบัญชีทั่วไปของบัญชีอื่นที่ตนมีสิทธิ์จัดการ และกำหนด Role/Permission; Q-01 ขอให้ยืนยันฟิลด์ใดบ้างที่เป็น “ข้อมูลบัญชีทั่วไป” อย่างชัดเจน แต่กฎหลักว่ามีข้อมูลบัญชีทั่วไปที่ Admin สามารถแก้ไขได้และต้องมีสิทธิ์จัดการได้รับกำหนดไว้แล้วใน spec (FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-02)

### พัฒนาและทดสอบ

- [x] **T-02** ตรวจการเข้าสู่ระบบและ Permission ของ Admin ก่อนค้นหาหรือจัดการบัญชี; ป้องกันการเข้าถึงโดยไม่ได้รับอนุญาต — สำเร็จ: FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-01 และ NFR-SEC-01 ระบุว่าระบบต้องให้ Admin ค้นหา/เลือกบัญชีเพื่อจัดการได้ และต้องควบคุมสิทธิ์การจัดการบัญชี/Permission; Constraint ยืนยันว่าต้องป้องกันการเข้าถึงข้อมูลโดยไม่ได้รับอนุญาต (FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-01, NFR-SEC-01, Constraint: Admin ต้องเข้าสู่ระบบ/มีสิทธิ์และต้องป้องกันการเข้าถึงไม่ได้รับอนุญาต)
- [x] **T-03** ค้นหาและเลือกบัญชีผู้ใช้ที่ Admin มีสิทธิ์จัดการ — สำเร็จ: FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-01 ระบุว่าระบบต้องให้ Admin ค้นหาและเลือกบัญชีผู้ใช้เพื่อจัดการได้; นี่เป็น prerequisite ของการแก้ไขข้อมูล, การระงับ, และการกำหนดสิทธิ์ (FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-01)
- [x] **T-04** แก้ไขข้อมูลทั่วไปของบัญชีอื่นตามฟิลด์ที่ทีมยืนยัน — สำเร็จ: FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-02 ระบุว่าระบบต้องให้ Admin แก้ไขข้อมูลบัญชีทั่วไปของบัญชีอื่นที่ตนมีสิทธิ์จัดการ; Q-01 เป็นการยืนยันรายละเอียดว่า “ข้อมูลบัญชีทั่วไป” ประกอบด้วยฟิลด์ใดบ้าง แต่การแก้ไขข้อมูลบัญชีทั่วไปสำหรับบัญชีอื่นคือ requirement ที่ชัดเจนอยู่แล้ว (FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-02)
- [x] **T-05** กำหนด Role/Permission จากรายการที่มีอยู่และไม่เกินอำนาจของ Admin; ปฏิเสธสิทธิ์ที่เกินอำนาจ — สำเร็จ: FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-02 และ FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-05 ระบุว่าระบบต้องให้ Admin กำหนด Role/Permission จากรายการที่มีอยู่ได้ไม่เกินอำนาจของตน และหากไม่มีอำนาจต้องปฏิเสธ; NFR-SEC-01 ย้ำความสำคัญของการควบคุมสิทธิ์ (FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-02, FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-05, NFR-SEC-01)
- [x] **T-06** รองรับระงับบัญชีเป็น Suspended และเปิดใช้งานเป็น Active — สำเร็จ: FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-03 และ FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-04 ระบุว่าระบบต้องอนุญาตให้ระงับหรือเปิดใช้งานบัญชี และเมื่อระงับบัญชีให้เปลี่ยนสถานะเป็น Suspended; เมื่อเปิดใช้งาน ให้เป็น Active ตาม ASM-03 (FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-03, FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-04)
- [x] **T-07** บันทึกผู้กระทำ เวลา ค่าเดิม และค่าใหม่ใน Audit Log; หากบันทึกไม่สำเร็จ ห้ามใช้การเปลี่ยนบัญชีหรือ Permission — สำเร็จ: FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-06 และ NFR-AUDIT-01 ระบุชัดว่าระบบต้องบันทึกผู้กระทำ เวลา ค่าเดิม และค่าใหม่ของการเปลี่ยนแปลงบัญชีและสิทธิ์ใน Audit Log; หากบันทึก Audit Log ไม่สำเร็จ ระบบต้องไม่เปลี่ยนแปลงบัญชีหรือสิทธิ์ (FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-06, NFR-AUDIT-01, Constraint: การเปลี่ยน Permission ต้องบันทึกใน Audit Log)
- [x] **T-08** ทดสอบการเปลี่ยน Role/สถานะและ Audit Log รวมกรณี Audit Log ล้มเหลวแล้วไม่มีการเปลี่ยนแปลง — สำเร็จ: AC-จัดการสมาชิกและสิทธิ์ผู้ใช้-01 ระบุว่าหาก Admin เปลี่ยน Role หรือสถานะบัญชีและยืนยัน ระบบอัปเดตข้อมูลและบันทึกผู้กระทำ เวลา ค่าเดิม และค่าใหม่ใน Audit Log; ข้อนี้ครอบคลุมทั้งกรณีปกติและกรณี Audit Log ล้มเหลวตาม FR-06 และ NFR-AUDIT-01 (FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-02, FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-06, NFR-AUDIT-01, AC-จัดการสมาชิกและสิทธิ์ผู้ใช้-01)
- [x] **T-09** ทดสอบ Admin ไม่มีอำนาจกำหนด Permission แล้วถูกปฏิเสธและ Permission คงเดิม — สำเร็จ: AC-จัดการสมาชิกและสิทธิ์ผู้ใช้-02 ระบุว่าหาก Admin ไม่มีสิทธิ์กำหนด Permission ที่ร้องขอ เมื่อยืนยันการเปลี่ยนสิทธิ์ ระบบปฏิเสธและไม่เปลี่ยน Permission; ข้อนี้สอดคล้องกับ FR-05 และ NFR-SEC-01 (FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-05, NFR-SEC-01, AC-จัดการสมาชิกและสิทธิ์ผู้ใช้-02)
- [x] **T-10** ทดสอบค้นหาบัญชีและระงับบัญชีที่เลือกให้เป็น Suspended — สำเร็จ: AC-จัดการสมาชิกและสิทธิ์ผู้ใช้-03 ระบุว่าหาก Admin เลือกระงับบัญชีและยืนยัน ระบบเปลี่ยนสถานะบัญชีเป็น Suspended; ข้อนี้ครอบคลุม FR-01, FR-03 และ FR-04 อย่างชัดเจน (FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-01, FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-03, FR-จัดการสมาชิกและสิทธิ์ผู้ใช้-04, AC-จัดการสมาชิกและสิทธิ์ผู้ใช้-03)
