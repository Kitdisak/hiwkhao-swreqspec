# งาน: ต่ออายุการยืมหนังสือ

อ้างอิง: SPEC-ต่ออายุการยืมหนังสือ-006 (Draft v2)

## ลำดับงาน

### ยืนยันประเด็นคงค้าง

- [ ] **T-01** ยืนยันจำนวนครั้งสูงสุดและระยะเวลายืมใหม่แยกตามประเภทหนังสือ/สมาชิก — **รอ Q-01** (FR-ต่ออายุการยืมหนังสือ-02, FR-ต่ออายุการยืมหนังสือ-03, Constraint: จำนวนและระยะเวลาขึ้นกับประเภท)
- [ ] **T-02** กำหนดความหมายเชิงตัวเลขของ “ใกล้ครบกำหนด” — **รอ Q-02** (FR-ต่ออายุการยืมหนังสือ-02, AC-ต่ออายุการยืมหนังสือ-03)
- [ ] **T-03** ยืนยันส่วนของระบบที่ต้องอัปเดตวันคืนใหม่และแนวทางกรณีอัปเดตไม่ครบ — **รอ Q-03** (FR-ต่ออายุการยืมหนังสือ-05, NFR-DATA-01)
- [ ] **T-04** ยืนยันวิธีทดสอบความสอดคล้องของวันคืนและ AC ที่ครอบคลุม — **รอ Q-04** (FR-ต่ออายุการยืมหนังสือ-05, NFR-DATA-01)

### พัฒนาและทดสอบ

- [ ] **T-05** แสดงรายการหนังสือที่สมาชิกกำลังยืม (FR-ต่ออายุการยืมหนังสือ-01)
- [ ] **T-06** ตรวจวันครบกำหนด คิวจอง และจำนวนครั้งที่ต่ออายุตามนโยบายที่ยืนยัน — **รอ Q-01** (FR-ต่ออายุการยืมหนังสือ-02, Constraint: ต้องไม่เกินกำหนด ไม่มีผู้จองต่อ และไม่เกินจำนวนครั้ง)
- [ ] **T-07** เมื่อผ่านเงื่อนไข กำหนดวันคืนใหม่ตามประเภทหนังสือและสมาชิก — **รอ Q-01** (FR-ต่ออายุการยืมหนังสือ-03, Constraint: ระยะเวลาขึ้นกับประเภท)
- [ ] **T-08** เมื่อเกินกำหนด มีผู้จองต่อ หรือครบจำนวนครั้งสูงสุด ให้ปฏิเสธด้วยข้อความทั่วไปตาม spec (FR-ต่ออายุการยืมหนังสือ-04)
- [ ] **T-09** อัปเดตวันคืนใหม่ในทุกส่วนที่ทีมยืนยันและรักษาความสอดคล้อง — **รอ Q-03, Q-04** (FR-ต่ออายุการยืมหนังสือ-05, NFR-DATA-01)
- [ ] **T-10** ทดสอบการต่ออายุที่ผ่านเงื่อนไขและผลวันคืนใหม่ — **รอ Q-01** (FR-ต่ออายุการยืมหนังสือ-01, FR-ต่ออายุการยืมหนังสือ-02, FR-ต่ออายุการยืมหนังสือ-03, AC-ต่ออายุการยืมหนังสือ-01)
- [ ] **T-11** ทดสอบแยกกรณีเกินกำหนด, มีผู้จองต่อ และครบจำนวนครั้ง พร้อมข้อความปฏิเสธ — **รอ Q-01** (FR-ต่ออายุการยืมหนังสือ-04, AC-ต่ออายุการยืมหนังสือ-02)
- [ ] **T-12** ทดสอบกรณีใกล้ครบกำหนดตามเกณฑ์ที่ทีมยืนยัน — **รอ Q-02** (FR-ต่ออายุการยืมหนังสือ-02, FR-ต่ออายุการยืมหนังสือ-03, AC-ต่ออายุการยืมหนังสือ-03)
- [ ] **T-13** ทดสอบวันคืนใหม่ให้สอดคล้องทุกส่วนตามเกณฑ์ที่ยืนยัน — **รอ Q-03, Q-04** (FR-ต่ออายุการยืมหนังสือ-05, NFR-DATA-01)
