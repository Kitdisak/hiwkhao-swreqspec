# งาน: สมัครสมาชิก / เข้าสู่ระบบ

อ้างอิง: SPEC-สมัครสมาชิก-เข้าสู่ระบบ-002 (Draft v2)

## ลำดับงาน

### ยืนยันประเด็นคงค้าง

- [ ] **T-01** ยืนยันข้อมูลและแหล่งตรวจบัญชี/ข้อมูลนักศึกษาสำหรับการยืนยันตัวตน — **รอ Q-01** (FR-สมัครสมาชิก-/-เข้าสู่ระบบ-01, FR-สมัครสมาชิก-/-เข้าสู่ระบบ-03)
- [ ] **T-02** ยืนยันบทบาทกับสิทธิ์การเข้าถึงฟังก์ชัน — **รอ Q-02** (FR-สมัครสมาชิก-/-เข้าสู่ระบบ-04, Constraint: ต้องควบคุมสิทธิ์ตามบทบาท)
- [ ] **T-03** กำหนดเกณฑ์ตรวจการจัดเก็บรหัสผ่านและการควบคุมสิทธิ์ — **รอ Q-03** (FR-สมัครสมาชิก-/-เข้าสู่ระบบ-01, NFR-SEC-01)
- [ ] **T-04** ตรวจนโยบาย UC Case.pdf และยืนยัน FR/NFR ที่ AC แต่ละข้อครอบคลุม — **รอ Q-04** (FR-สมัครสมาชิก-/-เข้าสู่ระบบ-01, AC-สมัครสมาชิก-/-เข้าสู่ระบบ-01 ถึง AC-สมัครสมาชิก-/-เข้าสู่ระบบ-03)
- [ ] **T-05** ยืนยันข้อมูล ขั้นตอน และเกณฑ์ตรวจรับการสมัครสมาชิก — **รอ Q-05** (FR-สมัครสมาชิก-/-เข้าสู่ระบบ-01)
- [ ] **T-06** ยืนยันกิจกรรมที่เริ่มนับเวลาใหม่ของ session timeout — **รอ Q-06** (FR-สมัครสมาชิก-/-เข้าสู่ระบบ-01, NFR-SEC-02)

### พัฒนาและทดสอบ

- [ ] **T-07** ตรวจข้อมูลเข้าสู่ระบบและยืนยันตัวตนก่อนเข้าถึงฟังก์ชันส่วนบุคคล โดยใช้ข้อมูล/แหล่งที่ทีมยืนยัน — **รอ Q-01** (FR-สมัครสมาชิก-/-เข้าสู่ระบบ-01, Constraint: ต้องมีบัญชีถูกต้องหรือข้อมูลนักศึกษาในระบบมหาวิทยาลัย)
- [ ] **T-08** แสดงข้อความผิดพลาดที่กำหนดและให้ผู้ใช้กรอกข้อมูลเข้าสู่ระบบใหม่ได้ (FR-สมัครสมาชิก-/-เข้าสู่ระบบ-02)
- [ ] **T-09** ใช้ข้อมูลนักศึกษาเพื่อยืนยันตัวตนในกระบวนการลืมรหัสผ่าน หลังยืนยันข้อมูลที่ใช้ตรวจ — **รอ Q-01** (FR-สมัครสมาชิก-/-เข้าสู่ระบบ-03)
- [ ] **T-10** จำกัดการเข้าถึงฟังก์ชันตาม Role/Permission ที่ทีมกำหนด — **รอ Q-02** (FR-สมัครสมาชิก-/-เข้าสู่ระบบ-04, Constraint: ต้องควบคุมสิทธิ์ตามบทบาท)
- [ ] **T-11** จัดเก็บรหัสผ่านและควบคุมสิทธิ์ตามเกณฑ์ความปลอดภัยที่ทีมยืนยัน — **รอ Q-03** (FR-สมัครสมาชิก-/-เข้าสู่ระบบ-01, NFR-SEC-01)
- [ ] **T-12** ออกจากระบบเมื่อไม่มีการใช้งานครบ 10 นาที โดยใช้นิยาม activity ที่ทีมยืนยัน — **รอ Q-06** (FR-สมัครสมาชิก-/-เข้าสู่ระบบ-01, NFR-SEC-02)
- [ ] **T-13** ทดสอบเข้าสู่ระบบสำเร็จและแสดงหน้าหลัก (FR-สมัครสมาชิก-/-เข้าสู่ระบบ-01, AC-สมัครสมาชิก-/-เข้าสู่ระบบ-01)
- [ ] **T-14** ทดสอบข้อมูลเข้าสู่ระบบผิด ปฏิเสธการเข้า แสดงข้อความ และกรอกใหม่ได้ (FR-สมัครสมาชิก-/-เข้าสู่ระบบ-02, AC-สมัครสมาชิก-/-เข้าสู่ระบบ-02)
- [ ] **T-15** ทดสอบยืนยันตัวตนด้วยข้อมูลนักศึกษาเพื่อดำเนินการเปลี่ยนรหัสผ่าน (FR-สมัครสมาชิก-/-เข้าสู่ระบบ-03, AC-สมัครสมาชิก-/-เข้าสู่ระบบ-03)
- [ ] **T-16** เพิ่มและทดสอบ flow สมัครสมาชิกเมื่อทีมยืนยันข้อมูล ขั้นตอน และเกณฑ์ตรวจรับ — **รอ Q-05** (FR-สมัครสมาชิก-/-เข้าสู่ระบบ-01)
