- [ ] **T-03** สร้าง API และหน้าสมัครสมาชิกตามข้อมูลและประเภทผู้ใช้ รวมอีเมลที่บังคับเฉพาะบุคคลภายนอก วันเกิดเต็มของบุคคลภายนอก และชื่อแสดงผลจากชื่อ/นามสกุล; ยืนยัน mapping AC-to-FR ก่อนเริ่ม (FR-สมัครสมาชิก-/-เข้าสู่ระบบ-01, AC-สมัครสมาชิก-/-เข้าสู่ระบบ-01, ASM-05, ASM-06, ASM-10, ASM-11, Q-04, Q-07) — **สถานะ: รอ Q-04, Q-07**
