# งาน: สมัครสมาชิก / เข้าสู่ระบบ

อ้างอิง: [spec.md](./spec.md) (Draft v2) และ [plan.md](./plan.md)

## ลำดับงาน

- [x] **T-01** เพิ่มโมเดล Account, IdentityProfile และ AuthSession; เก็บ password_hash และแยก RolePermissionPolicy สำหรับสิทธิ์ (FR-สมัครสมาชิก-/-เข้าสู่ระบบ-01, FR-สมัครสมาชิก-/-เข้าสู่ระบบ-02, FR-สมัครสมาชิก-/-เข้าสู่ระบบ-03, FR-สมัครสมาชิก-/-เข้าสู่ระบบ-04, NFR-SEC-01, ASM-12)
- [x] **T-02** เพิ่ม registry adapter เป็นจุดเชื่อมทะเบียนเดียวพร้อม mock found/not_found/timeout และ timeout 5 วินาทีจำแนกผลการสมัคร (FR-สมัครสมาชิก-/-เข้าสู่ระบบ-01, FR-สมัครสมาชิก-/-เข้าสู่ระบบ-03, AC-สมัครสมาชิก-/-เข้าสู่ระบบ-01, AC-สมัครสมาชิก-/-เข้าสู่ระบบ-04, ASM-23, ASM-24, ASM-25, ASM-26)
- [x] **T-03** สร้าง `POST /api/auth/register` และหน้าสมัครสมาชิกตามฟิลด์ของทุกประเภทผู้ใช้ กำหนดรหัสผ่านก่อนเข้าสู่ระบบ สร้างชื่อแสดงผล และจำแนกไม่พบทะเบียนเป็นบุคคลภายนอก (AC-สมัครสมาชิก-/-เข้าสู่ระบบ-01, ASM-05, ASM-06, ASM-11, ASM-15, ASM-18)
- [x] **T-04** ปรับการเข้าสู่ระบบให้รองรับรหัสนักศึกษาเป็นตัวระบุหลักของนักศึกษา และอีเมลเป็นตัวระบุหลักของบุคลากร/บุคคลภายนอก (FR-สมัครสมาชิก-/-เข้าสู่ระบบ-01, AC-สมัครสมาชิก-/-เข้าสู่ระบบ-02, ASM-07)
- [x] **T-05** แสดงข้อความ “รหัสผ่านหรือชื่อผู้ใช้ไม่ถูกต้อง” สำหรับข้อมูลเข้าสู่ระบบผิด และอนุญาตให้ retry (FR-สมัครสมาชิก-/-เข้าสู่ระบบ-02, AC-สมัครสมาชิก-/-เข้าสู่ระบบ-03, ASM-03)
- [x] **T-06** ปรับการยืนยันตัวตนและตั้งรหัสผ่านใหม่สำหรับนักศึกษา บุคลากร และบุคคลภายนอก; ตรวจข้อมูลตรงและ registry timeout ตาม ASM-13/ASM-17/ASM-19 (FR-สมัครสมาชิก-/-เข้าสู่ระบบ-03, AC-สมัครสมาชิก-/-เข้าสู่ระบบ-04, ASM-09, ASM-10)
- [x] **T-07** บังคับสิทธิ์ให้ทุกบทบาทมีสิทธิ์เดียวกัน ยกเว้นบุคคลภายนอกห้ามยืมหนังสือ (FR-สมัครสมาชิก-/-เข้าสู่ระบบ-04, ASM-14)
- [x] **T-08** เพิ่ม policy helper สำหรับห้ามบัญชีบุคคลภายนอกยืมหนังสือ (FR-สมัครสมาชิก-/-เข้าสู่ระบบ-04, AC-สมัครสมาชิก-/-เข้าสู่ระบบ-01, ASM-08)
- [x] **T-09** เพิ่ม idle timeout 10 นาที โดยรีเซ็ตเวลาจากคำขอที่เข้าถึงระบบและคืน 401 สำหรับ protected endpoint เมื่อหมดเวลา (NFR-SEC-02, ACกรณีทดสอบของ AC-สมัครสมาชิก-/-เข้าสู่ระบบ-02, ASM-04, ASM-16)
- [x] **T-10** บังคับรหัสผ่านอย่างน้อย 5 ตัวที่มีตัวอักษรและตัวเลข และจัดเก็บด้วย PBKDF2-SHA256 hash (NFR-SEC-01, ASM-12)
- [x] **T-11** เพิ่มทดสอบ AC-สมัครสมาชิก-/-เข้าสู่ระบบ-01 สำหรับสมัครบุคคลภายนอก, password policy และ registry timeout (AC-สมัครสมาชิก-/-เข้าสู่ระบบ-01, ASM-13, ASM-18, ASM-19)
- [x] **T-12** เพิ่มทดสอบเข้าสู่ระบบสำเร็จและ idle timeout สำหรับ AC-สมัครสมาชิก-/-เข้าสู่ระบบ-02 (AC-สมัครสมาชิก-/-เข้าสู่ระบบ-02, FR-สมัครสมาชิก-/-เข้าสู่ระบบ-01, NFR-SEC-02)
- [x] **T-13** เพิ่มทดสอบข้อมูลเข้าสู่ระบบผิดและ retry สำหรับ AC-สมัครสมาชิก-/-เข้าสู่ระบบ-03 (AC-สมัครสมาชิก-/-เข้าสู่ระบบ-03, FR-สมัครสมาชิก-/-เข้าสู่ระบบ-02)
- [x] **T-14** เพิ่มทดสอบลืมรหัสผ่านข้อมูลตรง/ไม่ตรงและ registry timeout สำหรับ AC-สมัครสมาชิก-/-เข้าสู่ระบบ-04 (AC-สมัครสมาชิก-/-เข้าสู่ระบบ-04, FR-สมัครสมาชิก-/-เข้าสู่ระบบ-03, ASM-13, ASM-17)
- [x] **T-15** เชื่อมหน้าบ้าน React สำหรับ login/register/forgot-password และ build frontend หลังเพิ่ม route ใหม่ (AC-สมัครสมาชิก-/-เข้าสู่ระบบ-01 ถึง AC-สมัครสมาชิก-/-เข้าสู่ระบบ-04)
