# งาน: ชำระค่าปรับออนไลน์

อ้างอิง: SPEC-ชำระค่าปรับออนไลน์-007 (Draft v2)

## ลำดับงาน

### ยืนยันประเด็นคงค้าง

- [ ] **T-01** กำหนดการแสดงสถานะและการดำเนินการเมื่อ Gateway ไม่ตอบหรือตอบล่าช้า — **รอ Q-01** (FR-ชำระค่าปรับออนไลน์-02, FR-ชำระค่าปรับออนไลน์-04)
- [ ] **T-02** ยืนยันข้อมูลจับคู่ผล Gateway กับคำขอ/ค่าปรับและการจัดการผลซ้ำ — **รอ Q-02** (FR-ชำระค่าปรับออนไลน์-03, NFR-REL-01)
- [ ] **T-03** ยืนยันบทบาทผู้เริ่มชำระและบทบาท Gateway ใน flow — **รอ Q-03** (FR-ชำระค่าปรับออนไลน์-02)
- [ ] **T-04** ยืนยันยอดและรายละเอียดที่ผู้ใช้ต้องเห็นก่อนยืนยัน — **รอ Q-04** (FR-ชำระค่าปรับออนไลน์-01)
- [ ] **T-05** ยืนยัน AC/FR/NFR mapping และขั้นตอนส่งคำขอก่อนรับผล Gateway — **รอ Q-05** (FR-ชำระค่าปรับออนไลน์-02, AC-ชำระค่าปรับออนไลน์-01 ถึง AC-ชำระค่าปรับออนไลน์-03)
- [ ] **T-06** ตรวจนโยบายหรือค่ากำหนด UC Case.pdf — **รอ Q-06** (FR-ชำระค่าปรับออนไลน์-01, FR-ชำระค่าปรับออนไลน์-02)

### พัฒนาและทดสอบ

- [ ] **T-07** อ่านและแสดงยอดค่าปรับค้างชำระก่อนเริ่มชำระ; ใช้ยอดที่มีอยู่และไม่คำนวณค่าปรับใน UC-07 (FR-ชำระค่าปรับออนไลน์-01, Constraint: ต้องมีค่าปรับค้างชำระและอ้างอิงอัตรากฎห้องสมุด; Out of scope: UC-12)
- [ ] **T-08** แสดงข้อมูลยอด/รายละเอียดตามที่ทีมยืนยันเพื่อให้ผู้ใช้ตรวจรายการก่อนชำระ — **รอ Q-04** (FR-ชำระค่าปรับออนไลน์-01)
- [ ] **T-09** ส่งข้อมูลการชำระผ่านช่องทางปลอดภัย เช่น HTTPS (FR-ชำระค่าปรับออนไลน์-02, NFR-SEC-01, Constraint: ส่งข้อมูลผ่านช่องทางปลอดภัย)
- [ ] **T-10** เปลี่ยนสถานะเป็น “ชำระแล้ว” และบันทึกการชำระเฉพาะเมื่อ Gateway ยืนยันสำเร็จ โดยอิงคำขอที่จับคู่ได้ — **รอ Q-02** (FR-ชำระค่าปรับออนไลน์-03, NFR-REL-01)
- [ ] **T-11** เมื่อ Gateway แจ้งล้มเหลว คงสถานะค้างชำระและให้ผู้ใช้ลองใหม่ (FR-ชำระค่าปรับออนไลน์-04)
- [ ] **T-12** ให้เปลี่ยนช่องทางก่อนยืนยัน และใช้ช่องทางใหม่เมื่อยืนยันแล้ว (FR-ชำระค่าปรับออนไลน์-05, ASM-01)
- [ ] **T-13** ทดสอบ Gateway ยืนยันสำเร็จและการบันทึกสถานะตามผล (FR-ชำระค่าปรับออนไลน์-03, NFR-REL-01, AC-ชำระค่าปรับออนไลน์-01)
- [ ] **T-14** ทดสอบ Gateway แจ้งไม่สำเร็จ โดยสถานะยังค้างและมีทางให้ลองใหม่ (FR-ชำระค่าปรับออนไลน์-04, AC-ชำระค่าปรับออนไลน์-02)
- [ ] **T-15** ทดสอบเปลี่ยนช่องทางก่อนยืนยันและตรวจคำขอใช้ช่องทางใหม่ (FR-ชำระค่าปรับออนไลน์-05, AC-ชำระค่าปรับออนไลน์-03)
