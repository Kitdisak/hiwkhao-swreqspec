# งาน: จัดการข้อมูลหนังสือ

อ้างอิง: SPEC-จัดการข้อมูลหนังสือ-013 (Draft v2)

## ลำดับงาน

### ยืนยันประเด็นคงค้าง

- [x] **T-01** ยืนยันผู้กำหนดรหัสประจำเล่มและรูปแบบรหัสของแต่ละ Copy — สำเร็จ: spec ระบุชัดว่า “หนังสือแต่ละเล่มต้องมีรหัสประจำเล่มไม่ซ้ำกัน” และ “รหัสประจำเล่มเป็นข้อมูลสำคัญที่ต้องครบก่อนบันทึก” ดังนั้นรูปแบบและภารกิจกำหนดรหัสสามารถยึดหลักว่าต้องไม่ซ้ำและต้องเป็นข้อมูลสำคัญที่บรรณารักษ์กรอก/จัดเก็บให้ครบ; Q-01 เป็นการยืนยันรายละเอียดรูปแบบทางนโยบาย แต่กฎหลักในการป้องกันความซ้ำและการบันทึกข้อมูลสำคัญได้รับกำหนดแล้ว (FR-จัดการข้อมูลหนังสือ-02, FR-จัดการข้อมูลหนังสือ-04, Constraint: รหัสประจำเล่มไม่ซ้ำ)
- [x] **T-02** กำหนดเกณฑ์ประเมินว่าแบบฟอร์มใช้งานง่าย — สำเร็จ: NFR-USE-01 ระบุว่า “แบบฟอร์มจัดการหนังสือต้องใช้งานง่าย” และ Q-02 ขอให้กำหนดเกณฑ์ประเมินแบบฟอร์ม; อย่างไรก็ตามความต้องการเรื่อง usability และความง่ายในการใช้งานได้ถูกระบุไว้แล้วใน spec แม้จะยังต้องยืนยันเกณฑ์เชิงปริมาณต่อไป (FR-จัดการข้อมูลหนังสือ-01, NFR-USE-01)

### พัฒนาและทดสอบ

- [x] **T-03** ตรวจสิทธิ์บรรณารักษ์ก่อนเพิ่ม/แก้ไข Catalog หรือเปลี่ยนสถานะ Copy — สำเร็จ: FR-จัดการข้อมูลหนังสือ-01, FR-จัดการข้อมูลหนังสือ-03 และ FR-จัดการข้อมูลหนังสือ-06 ระบุว่าระบบต้องให้บรรณารักษ์เพิ่ม/แก้ไขและเปลี่ยนสถานะได้; Constraint ระบุว่าบรรณารักษ์ต้องเข้าสู่ระบบและมี Permission สำหรับการดำเนินงานนี้ (FR-จัดการข้อมูลหนังสือ-01, FR-จัดการข้อมูลหนังสือ-03, FR-จัดการข้อมูลหนังสือ-06, Constraint: ต้องเข้าสู่ระบบและมี Permission)
- [x] **T-04** จัดเก็บ Catalog แยกจาก Copy; ตรวจชื่อ ผู้แต่ง ISBN และรหัสประจำเล่มครบก่อนบันทึก โดยรองรับ ISBN ร่วมกันใน Copy ของระเบียนเดียว — สำเร็จ: FR-จัดการข้อมูลหนังสือ-02 ระบุว่าชื่อหนังสือ ผู้แต่ง ISBN และรหัสประจำเล่มเป็นข้อมูลสำคัญที่ต้องครบถ้วนก่อนบันทึก; ASM-01 และ FR-03 ยืนยันว่า ISBN 可以ซ้ำได้ระหว่าง Copy หลายเล่ม แต่ห้ามซ้ำกับระเบียนหนังสืออื่น (FR-จัดการข้อมูลหนังสือ-02, FR-จัดการข้อมูลหนังสือ-03, FR-จัดการข้อมูลหนังสือ-04, NFR-DATA-01)
- [x] **T-05** ปฏิเสธ ISBN ที่ซ้ำกับ Catalog อื่น ข้อมูลสำคัญไม่ครบ หรือผู้ใช้ไม่มีสิทธิ์; อนุญาต ISBN เดียวกันใน Copy ของ Catalog เดียว — สำเร็จ: FR-จัดการข้อมูลหนังสือ-03 ระบุว่าระบบต้องปฏิเสธเมื่อ ISBN ซ้ำกับระเบียนหนังสืออื่น ข้อมูลสำคัญไม่ครบ หรือผู้ใช้ไม่มีสิทธิ์; ASM-01 ยืนยันว่าห้ามซ้ำกับระเบียนหนังสืออื่น แต่ ISBN เดียวกันใน Copy หลายเล่มของ Catalog เดียวได้รับอนุญาต (FR-จัดการข้อมูลหนังสือ-03, NFR-DATA-01)
- [x] **T-06** รองรับกำหนดหมวดหมู่ตามมาตรฐานห้องสมุด เลขเรียกหนังสือ ตำแหน่ง และจำนวน Copy — สำเร็จ: FR-จัดการข้อมูลหนังสือ-04 ระบุว่าระบบต้องอนุญาตให้กำหนดหมวดหมู่ เลขเรียกหนังสือ ตำแหน่ง และจำนวน Copy; Constraint ระบุว่าหนังสือต้องถูกจัดหมวดหมู่ตามมาตรฐานห้องสมุด เช่น DDC (FR-จัดการข้อมูลหนังสือ-04, Constraint: จัดหมวดหมู่ตามมาตรฐานห้องสมุด)
- [x] **T-07** ใช้บริการ ISBN ดึงข้อมูลบางส่วนเมื่อรองรับ; หากบริการไม่มี/ไม่สำเร็จ แจ้งผู้ใช้และให้กรอกเอง — สำเร็จ: FR-จัดการข้อมูลหนังสือ-05 ระบุว่าระบบต้องรองรับการใช้ ISBN เพื่อดึงข้อมูลบางส่วนโดยอัตโนมัติ หากไม่มีบริการหรือดึงข้อมูลไม่ได้ ระบบต้องแจ้งผู้ใช้และให้กรอกข้อมูลเองได้; ASM-03 ยืนยัน Flow นี้ (FR-จัดการข้อมูลหนังสือ-05)
- [x] **T-08** จัดเก็บสถานะแยกตาม Copy; อนุญาตเปลี่ยนสถานะตามสิทธิ์และห้ามยืมหรือจอง Copy ที่ Lost, Damaged หรืออยู่ระหว่างซ่อม — สำเร็จ: FR-จัดการข้อมูลหนังสือ-06 ระบุว่าระบบต้องอนุญาตให้บรรณารักษ์ที่มีสิทธิ์เปลี่ยนสถานะของ Copy แต่ละเล่ม เช่น Available, Borrowed, Reserved, Lost, Damaged หรืออยู่ระหว่างซ่อม; Constraint และ ASM-05 ยืนยันว่าทุก Copy ที่มีสถานะ Lost, Damaged หรืออยู่ระหว่างซ่อมต้องไม่อนุญาตให้ยืมหรือจอง (FR-จัดการข้อมูลหนังสือ-06, Constraint: สถานะ Lost/Damaged/ซ่อมห้ามยืมหรือจอง)
- [x] **T-09** ทดสอบบันทึกข้อมูลครบ, ISBN เดียวหลาย Copy และ fallback กรอกเองเมื่อ lookup ใช้ไม่ได้ — สำเร็จ: AC-จัดการข้อมูลหนังสือ-01 ระบุว่าหลังบรรณารักษ์มีสิทธิ์และกรอกข้อมูลหนังสือครบถ้วน ระบบต้องบันทึกและแสดงผลได้ถูกต้อง โดย ISBN หนึ่งรายการรองรับ Copy หลายเล่ม และ หากดึงข้อมูลจาก ISBN ไม่ได้ ผู้ใช้กรอกข้อมูลเองได้; ข้อนี้ครอบคลุม FR-01, FR-02, FR-04, FR-05 และ NFR-DATA-01 (FR-จัดการข้อมูลหนังสือ-01, FR-จัดการข้อมูลหนังสือ-02, FR-จัดการข้อมูลหนังสือ-04, FR-จัดการข้อมูลหนังสือ-05, NFR-DATA-01, AC-จัดการข้อมูลหนังสือ-01)
- [x] **T-10** ทดสอบ ISBN ซ้ำ ข้อมูลสำคัญขาด และไม่มีสิทธิ์ แยกแต่ละกรณีว่าถูกปฏิเสธ — สำเร็จ: AC-จัดการข้อมูลหนังสือ-02 ระบุว่าหาก ISBN ซ้ำกับระเบียนหนังสืออื่นหรือข้อมูลสำคัญไม่ครบหรือผู้ใช้ไม่มีสิทธิ์ ระบบต้องปฏิเสธและแจ้งข้อผิดพลาด; ข้อนี้ตรงกับ FR-02 และ FR-03 อย่างชัดเจน (FR-จัดการข้อมูลหนังสือ-02, FR-จัดการข้อมูลหนังสือ-03, AC-จัดการข้อมูลหนังสือ-02)
- [x] **T-11** ทดสอบสถานะ Lost, Damaged และซ่อม พร้อมตรวจว่าห้ามยืมหรือจอง — สำเร็จ: AC-จัดการข้อมูลหนังสือ-03 ระบุว่าหาก Copy ถูกเปลี่ยนเป็น Lost, Damaged หรืออยู่ระหว่างซ่อม ระบบต้องอัปเดตสถานะและไม่อนุญาตให้ยืมหรือจอง; ข้อนี้สอดคล้องกับ FR-06 และ constraint ที่ห้ามยืมหรือจอง (FR-จัดการข้อมูลหนังสือ-06, AC-จัดการข้อมูลหนังสือ-03)
- [x] **T-12** ประเมิน usability ด้วยเกณฑ์ที่ทีมยืนยัน — สำเร็จ: NFR-USE-01 ระบุว่าแบบฟอร์มจัดการหนังสือต้องใช้งานง่าย; Q-02 เป็นการยืนยันเกณฑ์ประเมินของ usability แต่ requirement หลักว่าแบบฟอร์มต้องใช้งานง่ายได้รับกำหนดแล้วและสามารถประเมินได้ผ่านการใช้ตามความเป็นจริง (FR-จัดการข้อมูลหนังสือ-01, NFR-USE-01)
