- [x] **T-02** สร้าง repository และ validation สำหรับข้อมูลบังคับ, ISBN 10/13 หลักและ checksum, ISBN ไม่ซ้ำข้ามระเบียน, รหัส Copy ที่ trim แล้วไม่ซ้ำ และ transaction แบบ all-or-nothing (FR-จัดการข้อมูลหนังสือ-02, FR-จัดการข้อมูลหนังสือ-03, NFR-DATA-01, ASM-01, ASM-02, ASM-09, ASM-14)
- [x] **T-03** ปรับบริการค้นหา รายละเอียด ยืม จอง และคืนให้อ่าน Catalog/Copy และสถานะจาก store ร่วมชุดเดียวกัน โดยไม่แก้กฎยืม/คืนที่อยู่นอกขอบเขต (FR-จัดการข้อมูลหนังสือ-06, AC-จัดการข้อมูลหนังสือ-01, ASM-14)

- [x] **T-06** เพิ่ม API เปลี่ยนสถานะ Copy ตาม transition ที่อนุญาต ตรวจ Permission และปฏิเสธ Borrowed/Reserved หรือ Copy ที่มี Loan/Reservation Ready ค้าง; ให้ flow ยืม/จองปฏิเสธ Lost/Damaged/อยู่ระหว่างซ่อม (FR-จัดการข้อมูลหนังสือ-06, AC-จัดการข้อมูลหนังสือ-03, ASM-04, ASM-05, ASM-10, ASM-15)

## ข้อจำกัดและคำถามที่ยังเปิดอยู่

- **Q-01** รูปแบบรหัสประจำเล่มจริงของห้องสมุดเป็นอย่างไร? ผู้กำหนดรหัสคือบรรณารักษ์ตาม ASM-09 แล้ว; ต้องถามบรรณารักษ์
- **Q-02** หากหนังสือหายระหว่างถูกยืม ต้องปิดรายการยืมหรือคิดค่าเสียหายอย่างไร? ต้องถามบรรณารักษ์
- **Q-03** ห้องสมุดใช้มาตรฐานจัดหมวดหมู่และรูปแบบเลขเรียกหนังสือใดจริง? ระหว่างรอคำตอบไม่ตรวจรูปแบบตามมาตรฐาน; อ้างอิงประเด็นเปิดเดียวกับ SPEC-003 Q-02; ต้องถามบรรณารักษ์

หมายเหตุ: การบันทึกการยืมและคืนยังอยู่นอกขอบเขตฟีเจอร์นี้; T-03/T-06/T-11 ปรับเฉพาะการอ่านและบังคับใช้สถานะ Copy ที่เกี่ยวข้องกับ FR-จัดการข้อมูลหนังสือ-06 และ ASM-14 (Scope: Out of scope, FR-จัดการข้อมูลหนังสือ-06, ASM-14).
