# งาน: จัดการข้อมูลหนังสือ

อ้างอิง: SPEC-จัดการข้อมูลหนังสือ-013 (Draft v2)

## ลำดับงาน

### ยืนยันประเด็นคงค้าง

- [ ] **T-01** ยืนยันผู้กำหนดรหัสประจำเล่มและรูปแบบรหัสของแต่ละ Copy — **รอ Q-01** (FR-จัดการข้อมูลหนังสือ-02, FR-จัดการข้อมูลหนังสือ-04, Constraint: รหัสประจำเล่มไม่ซ้ำ)
- [ ] **T-02** กำหนดเกณฑ์ประเมินว่าแบบฟอร์มใช้งานง่าย — **รอ Q-02** (FR-จัดการข้อมูลหนังสือ-01, NFR-USE-01)

### พัฒนาและทดสอบ

- [ ] **T-03** ตรวจสิทธิ์บรรณารักษ์ก่อนเพิ่ม/แก้ไข Catalog หรือเปลี่ยนสถานะ Copy (FR-จัดการข้อมูลหนังสือ-01, FR-จัดการข้อมูลหนังสือ-03, FR-จัดการข้อมูลหนังสือ-06, Constraint: ต้องเข้าสู่ระบบและมี Permission)
- [ ] **T-04** จัดเก็บ Catalog แยกจาก Copy; ตรวจชื่อ ผู้แต่ง ISBN และรหัสประจำเล่มครบก่อนบันทึก โดยรองรับ ISBN ร่วมกันใน Copy ของระเบียนเดียว (FR-จัดการข้อมูลหนังสือ-02, FR-จัดการข้อมูลหนังสือ-03, FR-จัดการข้อมูลหนังสือ-04, NFR-DATA-01)
- [ ] **T-05** ปฏิเสธ ISBN ที่ซ้ำกับ Catalog อื่น ข้อมูลสำคัญไม่ครบ หรือผู้ใช้ไม่มีสิทธิ์; อนุญาต ISBN เดียวกันใน Copy ของ Catalog เดียว (FR-จัดการข้อมูลหนังสือ-03, NFR-DATA-01)
- [ ] **T-06** รองรับกำหนดหมวดหมู่ตามมาตรฐานห้องสมุด เลขเรียกหนังสือ ตำแหน่ง และจำนวน Copy (FR-จัดการข้อมูลหนังสือ-04, Constraint: จัดหมวดหมู่ตามมาตรฐานห้องสมุด)
- [ ] **T-07** ใช้บริการ ISBN ดึงข้อมูลบางส่วนเมื่อรองรับ; หากบริการไม่มี/ไม่สำเร็จ แจ้งผู้ใช้และให้กรอกเอง (FR-จัดการข้อมูลหนังสือ-05)
- [ ] **T-08** จัดเก็บสถานะแยกตาม Copy; อนุญาตเปลี่ยนสถานะตามสิทธิ์และห้ามยืมหรือจอง Copy ที่ Lost, Damaged หรืออยู่ระหว่างซ่อม (FR-จัดการข้อมูลหนังสือ-06, Constraint: สถานะ Lost/Damaged/ซ่อมห้ามยืมหรือจอง)
- [ ] **T-09** ทดสอบบันทึกข้อมูลครบ, ISBN เดียวหลาย Copy และ fallback กรอกเองเมื่อ lookup ใช้ไม่ได้ (FR-จัดการข้อมูลหนังสือ-01, FR-จัดการข้อมูลหนังสือ-02, FR-จัดการข้อมูลหนังสือ-04, FR-จัดการข้อมูลหนังสือ-05, NFR-DATA-01, AC-จัดการข้อมูลหนังสือ-01)
- [ ] **T-10** ทดสอบ ISBN ซ้ำ ข้อมูลสำคัญขาด และไม่มีสิทธิ์ แยกแต่ละกรณีว่าถูกปฏิเสธ (FR-จัดการข้อมูลหนังสือ-02, FR-จัดการข้อมูลหนังสือ-03, AC-จัดการข้อมูลหนังสือ-02)
- [ ] **T-11** ทดสอบสถานะ Lost, Damaged และซ่อม พร้อมตรวจว่าห้ามยืมหรือจอง (FR-จัดการข้อมูลหนังสือ-06, AC-จัดการข้อมูลหนังสือ-03)
- [ ] **T-12** ประเมิน usability ด้วยเกณฑ์ที่ทีมยืนยัน — **รอ Q-02** (FR-จัดการข้อมูลหนังสือ-01, NFR-USE-01)
