# Feature: จัดการข้อมูลหนังสือ
Spec ID: SPEC-จัดการข้อมูลหนังสือ-013 | Source: SRS v0.3 | Use case: UC-13
Owner: ทีม หิวข้าว | Status: Draft v2 | Updated: 2569-11-19

## Goal
บรรณารักษ์เพิ่ม แก้ไข จัดหมวดหมู่ กำหนดตำแหน่ง และปรับสถานะข้อมูลหนังสือใน Catalog

## Primary Actor
บรรณารักษ์

## Scope
### In scope
- เพิ่มหรือค้นหาหนังสือเดิม
- กรอกและแก้ไขชื่อ ผู้แต่ง ISBN สำนักพิมพ์ และปีพิมพ์
- กำหนดหมวดหมู่ เลขเรียกหนังสือ ตำแหน่ง และจำนวน Copy
- กำหนดสถานะหนังสือ
### Out of scope
- บันทึกการยืมและคืน (UC-11, UC-12)

## Constraints
- บรรณารักษ์ต้องเข้าสู่ระบบและมี Permission
- หนังสือแต่ละเล่มต้องมีรหัสประจำเล่มไม่ซ้ำกัน โดยบรรณารักษ์กรอกหรือสแกนจากบาร์โค้ดที่ติดบนเล่ม
- หนังสือต้องถูกจัดหมวดหมู่ตามมาตรฐานที่ห้องสมุดกำหนด โดย DDC เป็นตัวอย่าง ไม่ใช่ข้อบังคับ; มาตรฐานและรูปแบบที่ใช้จริงยังรอคำตอบตาม Q-03
- หนังสือ Lost, Damaged หรืออยู่ระหว่างซ่อมต้องไม่สามารถยืมหรือจองได้

## Requirements
- **FR-จัดการข้อมูลหนังสือ-01** ระบบต้องให้บรรณารักษ์เพิ่มและแก้ไขข้อมูลหนังสือได้
- **FR-จัดการข้อมูลหนังสือ-02** ระบบต้องตรวจสอบว่าชื่อหนังสือ ผู้แต่ง ISBN และรหัสประจำเล่มของทุก Copy ครบถ้วนก่อนบันทึก โดยรหัสประจำเล่มต้องตัดช่องว่างหน้าและหลัง และห้ามว่าง
- **FR-จัดการข้อมูลหนังสือ-03** ระบบต้องปฏิเสธการบันทึกเมื่อ ISBN ซ้ำกับระเบียนหนังสืออื่น รหัสประจำเล่มซ้ำกับ Copy ใดในระบบ ข้อมูลสำคัญไม่ครบ หรือผู้ใช้ไม่มีสิทธิ์; ISBN เดียวกันใช้กับ Copy หลายเล่มในระเบียนเดียวกันได้; เมื่อรหัสประจำเล่มซ้ำ ระบบแจ้ง “รหัสประจำเล่มนี้มีอยู่แล้ว”
- **FR-จัดการข้อมูลหนังสือ-04** ระบบต้องอนุญาตให้กำหนดหมวดหมู่ได้หลายรายการ โดยแต่ละรายการประกอบด้วยรหัสและชื่อ, เลขเรียกหนังสือซึ่งเป็นข้อความอิสระและห้ามว่าง, ตำแหน่งซึ่งประกอบด้วยชั้นและโซนแบบข้อความ และจำนวน Copy; ไม่ตรวจรูปแบบหมวดหมู่ เลขเรียกหนังสือ หรือตำแหน่งตามมาตรฐาน; การเพิ่ม Copy ต้องระบุรหัสประจำเล่มทีละเล่ม; ห้ามลบ Copy เดิม; หากแก้ไขจำนวนให้ต่ำกว่าจำนวน Copy ที่มีอยู่ ระบบต้องไม่บันทึกและแจ้ง “ไม่สามารถลดจำนวน Copy ได้ ให้เปลี่ยนสถานะเล่มที่เลิกใช้แทน”; Copy ที่เลิกใช้ให้เปลี่ยนสถานะเป็น Lost หรือ Damaged ตาม FR-จัดการข้อมูลหนังสือ-06 เพื่อเก็บประวัติที่อ้างถึง Copy นั้นไว้
- **FR-จัดการข้อมูลหนังสือ-05** ระบบต้องให้บรรณารักษ์ใช้ ISBN เพื่อเรียก Open Library Books API และนำชื่อหนังสือกับผู้แต่งที่ได้มาเติมในฟอร์มให้บรรณารักษ์ตรวจและแก้ไขก่อนบันทึก โดยระบบต้องไม่บันทึกข้อมูลที่ดึงมาเอง; หากใช้เวลาเกิน 5 วินาที บริการไม่ตอบหรือเกิดข้อผิดพลาด หรือไม่พบหนังสือ ระบบต้องแจ้งผู้ใช้และให้กรอกข้อมูลเองได้
- **FR-จัดการข้อมูลหนังสือ-06** Copy ใหม่ต้องมีสถานะเริ่มต้น Available; บรรณารักษ์ที่เข้าสู่ระบบและมี Permission จัดการหนังสือเปลี่ยนสถานะด้วยมือได้ตามนี้: Available เป็น Lost, Damaged หรืออยู่ระหว่างซ่อม; Lost, Damaged หรืออยู่ระหว่างซ่อมเป็น Available หรือเปลี่ยนระหว่างสามสถานะดังกล่าวได้; บรรณารักษ์เปลี่ยนสถานะด้วยมือเป็น Borrowed หรือ Reserved ไม่ได้ และ Copy ที่มีรายการยืมหรือจอง Ready ค้างอยู่เปลี่ยนสถานะด้วยมือไม่ได้ โดยระบบแจ้ง “ไม่สามารถเปลี่ยนสถานะได้ เนื่องจากมีรายการยืมหรือจองค้างอยู่”; ผู้ไม่มี Permission ต้องถูกปฏิเสธ; Copy สถานะ Lost, Damaged หรืออยู่ระหว่างซ่อมต้องไม่สามารถยืมหรือจองได้

## Quality Requirements
- **NFR-DATA-01** ระบบต้องไม่บันทึกเมื่อช่องบังคับ ได้แก่ ชื่อหนังสือ ผู้แต่ง ISBN หรือรหัสประจำเล่มว่าง; ISBN ต้องมี 10 หรือ 13 หลักและมีเลขตรวจสอบถูกต้อง; รหัสประจำเล่มหลังตัดช่องว่างหน้าและหลังต้องไม่ซ้ำกับ Copy ใดในระบบ; ISBN ต้องไม่ซ้ำกับระเบียนอื่น แต่ใช้ซ้ำระหว่าง Copy ในระเบียนเดียวกันได้; การบันทึกระเบียนพร้อม Copy ต้องเป็นแบบ all-or-nothing
- **NFR-USE-01** ทุกช่องในแบบฟอร์มต้องมีป้ายกำกับ; ช่องบังคับ ได้แก่ ชื่อหนังสือ ผู้แต่ง ISBN และรหัสประจำเล่มต้องมีเครื่องหมายระบุว่าบังคับ; ข้อผิดพลาดจากการตรวจสอบข้อมูลต้องแสดงข้างช่องที่ผิด; เมื่อบันทึกไม่สำเร็จ ข้อมูลที่กรอกไว้ต้องไม่หาย

## Acceptance Criteria
- [ ] **AC-จัดการข้อมูลหนังสือ-01** (FR-จัดการข้อมูลหนังสือ-01, FR-จัดการข้อมูลหนังสือ-02, FR-จัดการข้อมูลหนังสือ-04, FR-จัดการข้อมูลหนังสือ-05, NFR-DATA-01, NFR-USE-01)
  - **Given** บรรณารักษ์มีสิทธิ์และกรอกข้อมูลครบถ้วน หรือเลือกข้อมูลที่ดึงจาก ISBN แล้ว
  - **When** บรรณารักษ์เพิ่มหรือแก้ไขข้อมูลหนังสือและบันทึก
  - **Then** ระบบบันทึกสำเร็จและแสดงข้อความ “บันทึกข้อมูลหนังสือแล้ว” พร้อมข้อมูลที่อ่านกลับจากระบบ ได้แก่ ชื่อหนังสือ ผู้แต่ง ISBN หมวดหมู่หลายรายการ เลขเรียก ตำแหน่ง และรายการ Copy ซึ่งประกอบด้วยรหัสประจำเล่มและสถานะ; ISBN หนึ่งรายการรองรับ Copy หลายเล่ม
  - **And** หนังสือที่เพิ่มต้องค้นพบได้ในหน้าค้นหาของ SPEC-001 และเปิดดูรายละเอียดได้ใน SPEC-003 หลังบันทึกสำเร็จ
  - **Given** บริการค้นข้อมูลด้วย ISBN ไม่ตอบภายใน 5 วินาที เกิดข้อผิดพลาด หรือไม่พบหนังสือ
  - **When** บรรณารักษ์ใช้การค้นข้อมูลด้วย ISBN
  - **Then** ระบบแจ้งผู้ใช้และให้กรอกข้อมูลเองได้ โดยข้อมูลที่กรอกไว้ไม่หายเมื่อบันทึกไม่สำเร็จ
- [ ] **AC-จัดการข้อมูลหนังสือ-02** (FR-จัดการข้อมูลหนังสือ-02, FR-จัดการข้อมูลหนังสือ-03, FR-จัดการข้อมูลหนังสือ-04, NFR-DATA-01, NFR-USE-01)
  - **Given** ISBN ซ้ำกับระเบียนอื่น รหัสประจำเล่มซ้ำ ISBN ไม่ถูกต้อง ข้อมูลสำคัญไม่ครบ หรือผู้ใช้ไม่มีสิทธิ์
  - **When** บรรณารักษ์บันทึกข้อมูล
  - **Then** ระบบปฏิเสธการบันทึก; ข้อผิดพลาดจากการตรวจสอบข้อมูลแสดงข้างช่องที่ผิด และคงข้อมูลที่กรอกไว้; หากรหัสประจำเล่มซ้ำ ระบบแจ้ง “รหัสประจำเล่มนี้มีอยู่แล้ว”
  - **Given** มี Copy อย่างน้อยหนึ่งรายการในระเบียนที่ไม่ผ่านการตรวจสอบ
  - **When** บรรณารักษ์บันทึกระเบียนพร้อม Copy หลายรายการ
  - **Then** ระบบไม่บันทึกระเบียนหรือ Copy ใดในรายการนั้น
  - **Given** จำนวน Copy ที่ส่งมาในฟอร์มแก้ไขน้อยกว่าจำนวน Copy ที่มีอยู่
  - **When** บรรณารักษ์บันทึกการแก้ไข
  - **Then** ระบบไม่บันทึกและแจ้ง “ไม่สามารถลดจำนวน Copy ได้ ให้เปลี่ยนสถานะเล่มที่เลิกใช้แทน”; Copy เดิมและประวัติที่อ้างถึง Copy ต้องไม่ถูกลบ
- [ ] **AC-จัดการข้อมูลหนังสือ-03** (FR-จัดการข้อมูลหนังสือ-06)
  - **Given** Copy ใหม่ หรือ Copy ที่มีสถานะ Available, Lost, Damaged หรืออยู่ระหว่างซ่อม และไม่มีรายการยืมหรือจอง Ready ค้าง
  - **When** บรรณารักษ์ที่มี Permission จัดการหนังสือบันทึกสถานะตามการเปลี่ยนผ่านที่กำหนดใน FR-จัดการข้อมูลหนังสือ-06
  - **Then** ระบบอัปเดตสถานะ; Copy ใหม่เริ่มต้นเป็น Available; สถานะ Lost, Damaged และอยู่ระหว่างซ่อมไม่สามารถยืมหรือจองได้
  - **Given** Copy มีรายการยืมหรือจอง Ready ค้าง หรือผู้ใช้ไม่มี Permission จัดการหนังสือ
  - **When** ผู้ใช้พยายามเปลี่ยนสถานะด้วยมือ
  - **Then** ระบบปฏิเสธ; หากมีรายการค้างให้แจ้ง “ไม่สามารถเปลี่ยนสถานะได้ เนื่องจากมีรายการยืมหรือจองค้างอยู่”
  - **Given** Copy ไม่มีรายการยืมหรือจอง Ready ค้าง
  - **When** บรรณารักษ์พยายามตั้งสถานะเป็น Borrowed หรือ Reserved ด้วยมือ
  - **Then** ระบบปฏิเสธการเปลี่ยนสถานะ

## Assumptions
- **ASM-01** ISBN ซ้ำได้ระหว่าง Copy หลายเล่มในระเบียน Catalog เดียวกัน แต่ห้ามซ้ำกับระเบียนหนังสืออื่น
- **ASM-02** ชื่อหนังสือ ผู้แต่ง ISBN และรหัสประจำเล่มเป็นข้อมูลสำคัญที่ต้องครบก่อนบันทึก
- **ASM-03** เมื่อบริการค้นข้อมูล ISBN ไม่มีหรือไม่ตอบ ระบบแจ้งผู้ใช้และอนุญาตให้กรอกข้อมูลเอง
- **ASM-04** สถานะจัดเก็บแยกตาม Copy แต่ละเล่ม; บรรณารักษ์ที่มีสิทธิ์เปลี่ยนสถานะได้ตามเงื่อนไข
- **ASM-05** Copy ที่มีสถานะ Lost, Damaged หรืออยู่ระหว่างซ่อมต้องไม่สามารถยืมหรือจองได้
- **ASM-06** บรรณารักษ์ที่เข้าสู่ระบบและมีสิทธิ์สามารถเพิ่ม แก้ไข และเปลี่ยนสถานะได้ตามสิทธิ์ที่กำหนด
- **ASM-07** AC-01 อ้างอิง FR-01/FR-02/FR-04/FR-05/NFR-DATA-01/NFR-USE-01; AC-02 อ้างอิง FR-02/FR-03/FR-04/NFR-DATA-01/NFR-USE-01; AC-03 อ้างอิง FR-06
- **ASM-08** ไม่มีนโยบายหรือค่ากำหนดเพิ่มเติมจาก spec นี้และ UC Case.pdf นอกเหนือจากคำตอบของทีมที่ระบุใน ASM-09 ถึง ASM-15
- **ASM-09** ทีมกำหนดให้บรรณารักษ์กรอกรหัสประจำเล่มหรือสแกนบาร์โค้ดที่ติดบนเล่ม; ระบบตัดช่องว่างหน้าและหลัง ห้ามว่าง และต้องไม่ซ้ำกับ Copy ใดในระบบตาม DOM-OPAC-05 ของ SPEC-001; เมื่อซ้ำให้ไม่บันทึกและแจ้ง “รหัสประจำเล่มนี้มีอยู่แล้ว”; ยังไม่บังคับรูปแบบรหัส (FR-จัดการข้อมูลหนังสือ-02, FR-จัดการข้อมูลหนังสือ-03, NFR-DATA-01)
- **ASM-10** ทีมกำหนดการเปลี่ยนสถานะด้วยมือและสิทธิ์ตาม FR-จัดการข้อมูลหนังสือ-06; Copy ใหม่เริ่ม Available; Borrowed และ Reserved เปลี่ยนได้โดยระบบในขั้นตอนยืม (SPEC-011), รับคืน (SPEC-012) และจองเท่านั้น; ห้ามบรรณารักษ์ตั้ง Borrowed หรือ Reserved ด้วยมือ; Copy Borrowed ที่มีรายการยืมค้างหรือ Reserved ที่กันไว้ให้ผู้จอง Ready เปลี่ยนด้วยมือไม่ได้; Lost, Damaged และอยู่ระหว่างซ่อมเปลี่ยนเป็น Available หรือเปลี่ยนระหว่างกันได้ (FR-จัดการข้อมูลหนังสือ-06, AC-จัดการข้อมูลหนังสือ-03)
- **ASM-11** ทีมเลือกใช้ Open Library Books API โดยไม่ต้องใช้ key; ระบบดึงเฉพาะชื่อหนังสือและผู้แต่งเพื่อเติมฟอร์มให้บรรณารักษ์ตรวจและแก้ไขก่อนบันทึก และไม่บันทึกเอง; เมื่อเกิน 5 วินาที ไม่ตอบ เกิดข้อผิดพลาด หรือไม่พบหนังสือ ให้แจ้งและให้กรอกเอง; การทดสอบใช้ข้อมูลจำลอง ไม่เรียกบริการจริง; การเลือกบริการเป็นการตัดสินใจของทีม ไม่ได้มาจาก spec (FR-จัดการข้อมูลหนังสือ-05, AC-จัดการข้อมูลหนังสือ-01)
- **ASM-12** ทีมกำหนดให้หมวดหมู่ประกอบด้วยรหัสและชื่อ; เลขเรียกเป็นข้อความอิสระที่ห้ามว่าง; ตำแหน่งประกอบด้วยชั้นและโซนซึ่งเป็นข้อความ; ไม่ตรวจรูปแบบตามมาตรฐาน; DDC เป็นเพียงตัวอย่าง มาตรฐานและรูปแบบที่ใช้จริงยังไม่ทราบและอ้างอิงประเด็นเปิดเดียวกับ SPEC-003 Q-02 (FR-จัดการข้อมูลหนังสือ-04)
- **ASM-13** ทีมกำหนด NFR-USE-01 ให้ทุกช่องมีป้ายกำกับ ช่องบังคับมีเครื่องหมาย ข้อผิดพลาดจากการตรวจสอบข้อมูลแสดงข้างช่องที่ผิด และข้อมูลที่กรอกไว้ไม่หายเมื่อบันทึกไม่สำเร็จ (NFR-USE-01, AC-จัดการข้อมูลหนังสือ-01, AC-จัดการข้อมูลหนังสือ-02)
- **ASM-14** ทีมกำหนด NFR-DATA-01 ให้ไม่บันทึกเมื่อช่องบังคับว่าง; ISBN ต้องมี 10 หรือ 13 หลักและเลขตรวจสอบถูกต้อง; รหัสประจำเล่มต้องไม่ซ้ำ; ISBN ซ้ำได้เฉพาะระหว่าง Copy ในระเบียนเดียว; การบันทึกระเบียนพร้อม Copy เป็นแบบ all-or-nothing; หลังบันทึกสำเร็จ หนังสือที่เพิ่มค้นพบใน SPEC-001 และเปิดดูได้ใน SPEC-003 โดยใช้ที่เก็บข้อมูลหนังสือ/Copy เดียวกับ SPEC-001, SPEC-003, SPEC-011 และ SPEC-012 ไม่สร้างที่เก็บใหม่ (NFR-DATA-01, AC-จัดการข้อมูลหนังสือ-01, AC-จัดการข้อมูลหนังสือ-02)
- **ASM-15** ทีมกำหนดให้ Catalog หนึ่งรายการมีหลายหมวดหมู่; ไม่ลบ Copy เดิมและการแก้ไขเพิ่ม Copy ใหม่ได้โดยระบุรหัสประจำเล่มทีละเล่ม; หากจำนวน Copy ที่ส่งมาในฟอร์มแก้ไขต่ำกว่าจำนวนที่มีอยู่ ให้ปฏิเสธและแจ้ง “ไม่สามารถลดจำนวน Copy ได้ ให้เปลี่ยนสถานะเล่มที่เลิกใช้แทน”; การเลิกใช้ Copy ให้เปลี่ยนสถานะเป็น Lost หรือ Damaged เพื่อเก็บประวัติ Loan/ค่าปรับ/Reservation ที่อ้างถึง Copy; หาก Copy มี Loan หรือ Reservation Ready ค้าง ให้ปฏิเสธการเปลี่ยนสถานะจนกว่ารายการค้างจะปิด ตามข้อจำกัด FR-จัดการข้อมูลหนังสือ-06 (FR-จัดการข้อมูลหนังสือ-04, FR-จัดการข้อมูลหนังสือ-06, AC-จัดการข้อมูลหนังสือ-02, AC-จัดการข้อมูลหนังสือ-03)
