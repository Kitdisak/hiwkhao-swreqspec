# แผนงาน: บันทึกการยืมหนังสือ

อ้างอิง: SPEC-บันทึกการยืมหนังสือ-011 (Draft v2)

## 1. สรุปแนวทาง

- บรรณารักษ์ค้นหาสมาชิกด้วยบัตรหรือรหัสนักศึกษาและดูข้อมูลก่อนทำรายการยืม (FR-บันทึกการยืมหนังสือ-01)
- ตรวจสถานะสมาชิก สิทธิ์ จำนวนเล่ม และสถานะ Available ของหนังสือก่อนยืนยัน (FR-บันทึกการยืมหนังสือ-02, Constraints, ASM-01, ASM-02)
- กำหนดวันคืนตามประเภทสมาชิกและประเภทหนังสือ โดยค่าจำนวน/ระยะเวลารอข้อสรุป Q-01 (FR-บันทึกการยืมหนังสือ-03, Q-01)
- บันทึกเฉพาะเล่มที่ผ่านเงื่อนไข เปลี่ยนสถานะเป็น Borrowed และไม่บันทึกรหัสประจำเล่มซ้ำในรายการเดียว (FR-บันทึกการยืมหนังสือ-04, FR-บันทึกการยืมหนังสือ-06, NFR-DATA-01, ASM-03, ASM-04)
- ปฏิเสธสมาชิกที่ไม่มีสิทธิ์ด้วยข้อความทั่วไป; รายละเอียด performance และนโยบายจำนวน/วันยืมที่ยังเปิดอยู่รอ Q-01/Q-02 (FR-บันทึกการยืมหนังสือ-05, ASM-05, Q-01, Q-02)

## 2. เทคโนโลยีที่ใช้

| สิ่งที่เลือก | มาจาก | หมายเหตุ |
|---|---|---|
| React (Vite) สำหรับหน้าบ้าน | **ทีมเลือกเอง ไม่ได้มาจาก spec** | ค่าเริ่มต้นตามรายวิชาใน prompt /plan; ไม่มี Constraint ระบุเทคโนโลยี |
| Python FastAPI สำหรับหลังบ้าน | **ทีมเลือกเอง ไม่ได้มาจาก spec** | ค่าเริ่มต้นตามรายวิชาใน prompt /plan; ไม่มี Constraint ระบุภาษา/framework |

## 3. โมเดลข้อมูล

| Entity | ฟิลด์หลักที่เสนอ | รองรับ |
|---|---|---|
| Member | student identifier, membership type, active status, borrowing eligibility | FR-บันทึกการยืมหนังสือ-01, FR-บันทึกการยืมหนังสือ-02, FR-บันทึกการยืมหนังสือ-05; Constraint: รหัสนักศึกษาสถานะใช้งาน |
| BookCopy | unique item identifier, book type, circulation status | FR-บันทึกการยืมหนังสือ-02, FR-บันทึกการยืมหนังสือ-04, FR-บันทึกการยืมหนังสือ-06; Constraint: รหัสประจำเล่มไม่ซ้ำ |
| Loan | member reference, loan date, status | FR-บันทึกการยืมหนังสือ-04, NFR-DATA-01 |
| LoanItem | loan reference, unique BookCopy reference, due date | FR-บันทึกการยืมหนังสือ-03, FR-บันทึกการยืมหนังสือ-04, FR-บันทึกการยืมหนังสือ-06, NFR-DATA-01 |
| LoanPolicy | member type, book type, maximum item count, loan duration | Constraints: จำนวนสูงสุด/ระยะเวลาขึ้นกับประเภทและนโยบาย; FR-บันทึกการยืมหนังสือ-02, FR-บันทึกการยืมหนังสือ-03, Q-01 |

`LoanPolicy` แสดงโครงสร้างที่ต้องรองรับนโยบายตามประเภทเท่านั้น; ยังไม่กำหนดค่าจำนวนสูงสุดหรือระยะเวลาจนกว่าจะได้คำตอบ Q-01. การตรวจสมาชิกที่มีหนังสือเกินกำหนดหรือค่าปรับค้างใช้ข้อมูล eligibility ที่มีอยู่ โดยไม่คำนวณค่าปรับในฟีเจอร์นี้ (Constraints, FR-บันทึกการยืมหนังสือ-02, ASM-01).

## 4. API / หน้าจอ

ข้อเสนอ interface เพื่อรองรับ FR; การรับข้อมูลและผลลัพธ์ของแต่ละเล่มรองรับ partial success ตาม FR-06/ASM-03

| รายการ | Method / path หรือ input/output หลัก | รองรับ |
|---|---|---|
| ค้นหาสมาชิก | `GET /api/members/lookup?identifier={cardOrStudentId}`; input: เลขจากบัตรหรือรหัสนักศึกษา; output: ข้อมูลสมาชิกและสิทธิ์ที่ใช้ตรวจสอบ | FR-บันทึกการยืมหนังสือ-01, FR-บันทึกการยืมหนังสือ-02 |
| ตรวจสอบและบันทึกการยืม | `POST /api/loans`; input: member reference และรายการ BookCopy identifiers; output: รายการเล่มที่บันทึกสำเร็จพร้อมวันคืน และผลปฏิเสธเล่มที่ไม่ผ่าน/รหัสซ้ำ | FR-บันทึกการยืมหนังสือ-02 ถึง FR-บันทึกการยืมหนังสือ-06, NFR-DATA-01 |
| หน้าจอบันทึกการยืม | input: บัตร/รหัสนักศึกษาและรายการรหัสประจำเล่มที่สแกน; output: ข้อมูลสมาชิก, สิทธิ์, รายการเล่มที่ผ่าน/ไม่ผ่าน, วันคืน และผลบันทึก | FR-บันทึกการยืมหนังสือ-01 ถึง FR-บันทึกการยืมหนังสือ-06, AC-บันทึกการยืมหนังสือ-01 ถึง AC-บันทึกการยืมหนังสือ-03 |

## 5. ตารางตรวจ Constraints

Constraints ใน spec ไม่มี ID เฉพาะ จึงอ้างอิงด้วยข้อความ Constraint ภายใต้ SPEC-บันทึกการยืมหนังสือ-011

| Constraint ID | ถูกนำไปใช้ที่ไหนใน plan | สถานะ |
|---|---|---|
| ไม่มี ID: นักศึกษาต้องใช้รหัสนักศึกษาที่มีสถานะใช้งานอยู่ | ตรวจ `Member.active status` ก่อนพิจารณาสิทธิ์ยืม (FR-บันทึกการยืมหนังสือ-01, FR-บันทึกการยืมหนังสือ-02) | ใช้แล้ว |
| ไม่มี ID: จำนวนสูงสุดและระยะเวลายืมขึ้นอยู่กับประเภทสมาชิก ประเภทหนังสือ และนโยบายห้องสมุด | ใช้ LoanPolicy แยกตาม member type/book type; ค่าจำนวนและวันยืมรอ Q-01 | ใช้แล้ว |
| ไม่มี ID: หนังสือแต่ละเล่มต้องมีรหัสประจำเล่มไม่ซ้ำกัน | BookCopy เก็บ unique item identifier และ LoanItem อ้างอิง BookCopy ไม่ซ้ำในรายการเดียว (FR-บันทึกการยืมหนังสือ-06, NFR-DATA-01, ASM-04) | ใช้แล้ว |
| ไม่มี ID: สมาชิกที่มีหนังสือเกินกำหนดหรือค่าปรับค้างอย่างน้อยหนึ่งรายการถูกระงับสิทธิ์ยืม | ตรวจสถานะ eligibility ก่อนยืนยันและปฏิเสธเมื่อถูกระงับ (FR-บันทึกการยืมหนังสือ-02, FR-บันทึกการยืมหนังสือ-05, ASM-01) | ใช้แล้ว |

## 6. แผนทดสอบจาก Acceptance Criteria

| AC ID | ชื่อ test | ทดสอบอย่างไร |
|---|---|---|
| AC-บันทึกการยืมหนังสือ-01 | `test_AC_บันทึกการยืมหนังสือ_01` | ค้นสมาชิกที่ใช้งานและมีสิทธิ์ เตรียมหนังสือ Available ยืนยันการยืม ตรวจว่ามี Loan/LoanItem วันคืนถูกกำหนด และสถานะหนังสือเป็น Borrowed; ค่ากำหนดวันคืนรอ Q-01 (FR-บันทึกการยืมหนังสือ-01 ถึง FR-บันทึกการยืมหนังสือ-04, NFR-DATA-01, AC-บันทึกการยืมหนังสือ-01, Q-01) |
| AC-บันทึกการยืมหนังสือ-02 | `test_AC_บันทึกการยืมหนังสือ_02` | ใช้สมาชิกถูกระงับหรือยืมครบจำนวน พยายามบันทึก ตรวจว่าระบบปฏิเสธและแสดง “ไม่สามารถยืมได้” (FR-บันทึกการยืมหนังสือ-05, AC-บันทึกการยืมหนังสือ-02, ASM-05) |
| AC-บันทึกการยืมหนังสือ-03 | `test_AC_บันทึกการยืมหนังสือ_03` | สแกนหลายเล่มโดยมีทั้งเล่ม Available ที่ผ่านเงื่อนไขและเล่มไม่ผ่าน รวมรหัสประจำเล่มซ้ำ ตรวจว่าบันทึกเฉพาะเล่มที่ผ่าน ไม่ซ้ำ และสถานะ Loan/BookCopy สอดคล้อง (FR-บันทึกการยืมหนังสือ-02, FR-บันทึกการยืมหนังสือ-04, FR-บันทึกการยืมหนังสือ-06, NFR-DATA-01, AC-บันทึกการยืมหนังสือ-03, Q-01) |

การทดสอบ NFR-PERF-01 ยังระบุ pass/fail ไม่ได้จนกว่าจะได้เวลาเป้าหมายและเงื่อนไขวัดจาก Q-02.

## 7. ลำดับงาน

1. ยืนยันตาราง/กติกาจำนวนเล่มสูงสุดและระยะเวลาตามประเภทสมาชิก/หนังสือ (Constraints, FR-บันทึกการยืมหนังสือ-02, FR-บันทึกการยืมหนังสือ-03, Q-01)
2. เตรียมข้อมูลสมาชิกและตรวจสถานะรหัสนักศึกษาว่าใช้งานอยู่ (FR-บันทึกการยืมหนังสือ-01, Constraints)
3. แสดงรายการหนังสือที่สแกนและตรวจ BookCopy identifier/status (FR-บันทึกการยืมหนังสือ-02, FR-บันทึกการยืมหนังสือ-06, ASM-02, ASM-04)
4. ตรวจ eligibility, จำนวนเล่มปัจจุบัน/สูงสุด และสถานะ Available ก่อนยืนยัน (FR-บันทึกการยืมหนังสือ-02, FR-บันทึกการยืมหนังสือ-05)
5. คำนวณ due date ตาม LoanPolicy ที่ทีมยืนยัน (FR-บันทึกการยืมหนังสือ-03, Q-01)
6. บันทึกเฉพาะรายการที่ผ่านและเปลี่ยนสถานะเป็น Borrowed โดยรักษาความสอดคล้องของข้อมูล (FR-บันทึกการยืมหนังสือ-04, FR-บันทึกการยืมหนังสือ-06, NFR-DATA-01)
7. แสดงข้อความปฏิเสธทั่วไปเมื่อสมาชิกไม่มีสิทธิ์หรือยืมครบจำนวน (FR-บันทึกการยืมหนังสือ-05, ASM-05)
8. ทดสอบ AC ทั้งสามข้อและวัด performance เมื่อทีมกำหนดเกณฑ์แล้ว (AC-บันทึกการยืมหนังสือ-01 ถึง AC-บันทึกการยืมหนังสือ-03, NFR-PERF-01, Q-02)

## 8. สิ่งที่ยังไม่ทำ

- **Q-01** คำตอบที่เสนอให้ใช้จำนวนสูงสุดและระยะเวลายืมเท่ากันทุกประเภทขัดกับ Constraint ที่ระบุว่าขึ้นอยู่กับประเภทสมาชิกและประเภทหนังสือ ต้องยืนยันว่าจะใช้ตาราง/กติกาแยกตามประเภทหรือเป็นค่าเดียว? ต้องถามบรรณารักษ์/ผู้กำหนดนโยบายการยืม ส่วนที่เกี่ยวข้องกับข้อนี้จะยังไม่สร้างจนกว่าจะได้คำตอบ
- **Q-02** ใช้เกณฑ์เวลาเท่าใดและเงื่อนไขใดวัดว่า “รวดเร็ว” ตาม NFR-PERF-01? ต้องถามทีม ส่วนที่เกี่ยวข้องกับข้อนี้จะยังไม่สร้างจนกว่าจะได้คำตอบ
