# งาน: บันทึกการยืมหนังสือ

อ้างอิง: SPEC-บันทึกการยืมหนังสือ-011 (Draft v2)

## ลำดับงาน

### ยืนยันประเด็นคงค้างและการตัดสินใจของทีม

- [x] **T-01** ระบุแหล่งค่ากำหนดจำนวนเล่มสูงสุดและจำนวนวันยืม — ใช้ตาราง LoanPolicy ตามคู่ประเภทสมาชิก/ประเภทหนังสือ และค่าชั่วคราวใน ASM-09; ค่าจริงยังรอ Q-01 (FR-02, FR-03, ASM-09, Q-01)
- [x] **T-02** กำหนดเกณฑ์ทดสอบประสิทธิภาพ — API scan ไม่เกิน 1 วินาที, confirm ไม่เกิน 10 เล่มไม่เกิน 2 วินาที, ผู้ใช้พร้อมกัน 10 คน และอย่างน้อย 95% ของคำขอผ่าน (NFR-PERF-01)

### พัฒนาและทดสอบ

- [x] **T-03** ค้นหาสมาชิกจากรหัสนักศึกษา/อีเมลบุคลากร และแสดงผลเมื่อไม่พบ — ใช้ student_id และอีเมลเดิม ไม่เพิ่มฟิลด์เลขบัตรบุคลากร (FR-01, ASM-19, Q-02)
- [x] **T-04** ตรวจสถานะสมาชิก สิทธิ์ จำนวนยืม และสถานะ Copy — ปฏิเสธสมาชิกไม่ใช้งาน ถูกระงับ บุคคลภายนอก และ Copy ที่ไม่ใช่ Available หรือ Reserved ที่กันให้ผู้จอง Ready (FR-02, FR-05, ASM-01, ASM-02, ASM-11, ASM-12, ASM-17)
- [x] **T-05** กำหนดวันคืนจากค่ากำหนด — อ่านจำนวนวันจาก LoanPolicy และคำนวณวันคืนที่ server ด้วย Asia/Bangkok โดยนับวันปฏิทิน (FR-03, ASM-09, ASM-10)
- [x] **T-06** บันทึก Loan, เปลี่ยน Copy และปรับ reservation แบบ atomic — ใช้ transaction/lock ของ reservation store เดิม; เมื่อยืมสำเร็จให้เปลี่ยน Ready → Completed ในชุดเดียวกัน (FR-04, NFR-DATA-01, ASM-15, ASM-18)
- [x] **T-07** ปฏิเสธปัญหาระดับสมาชิกและโควตาที่เต็ม — ปฏิเสธทั้งรายการเมื่อเต็มตั้งแต่ต้น และปฏิเสธเล่มถัดไปเมื่อเต็มระหว่างสแกนด้วยข้อความทั่วไป (FR-05, ASM-08, ASM-11, ASM-13)
- [x] **T-08** รองรับหลายเล่มและรหัสซ้ำ — ตรวจตามลำดับสแกน บันทึกเฉพาะเล่มที่ผ่าน และแจ้งรหัสซ้ำทันทีโดยไม่นับซ้ำ (FR-06, ASM-03, ASM-04, ASM-13, ASM-14)
- [x] **T-09** ทดสอบสมาชิกและ Copy ที่ผ่านเงื่อนไข — ตรวจวันคืน, Loan, Borrowed และ Ready → Completed เมื่อเกี่ยวข้อง (AC-บันทึกการยืมหนังสือ-01)
- [x] **T-10** ทดสอบการปฏิเสธสมาชิก — ตรวจสถานะไม่ใช้งาน/ถูกระงับ/บุคคลภายนอก/ครบจำนวนตั้งแต่ต้น และข้อความ “ไม่สามารถยืมได้” (AC-บันทึกการยืมหนังสือ-02)
- [x] **T-11** ทดสอบหลายเล่มและกรณีขอบ — ตรวจลำดับผล partial success, สแกนซ้ำ, ครบจำนวนระหว่างสแกน, rollback, idempotency และการชนกันยืม Copy เดียวกัน (AC-บันทึกการยืมหนังสือ-03, NFR-DATA-01, ASM-08, ASM-14, ASM-15, ASM-16)
- [x] **T-12** วัดประสิทธิภาพผ่าน API — ทดสอบ scan/confirm ภายใต้ผู้ใช้พร้อมกัน 10 คนตามเกณฑ์ NFR-PERF-01 (NFR-PERF-01)
