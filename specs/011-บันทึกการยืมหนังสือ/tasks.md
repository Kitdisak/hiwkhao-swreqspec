# งาน: บันทึกการยืมหนังสือ

อ้างอิง: SPEC-บันทึกการยืมหนังสือ-011 (Draft v2)

## ลำดับงาน

### ยืนยันประเด็นคงค้าง

- [x] **T-01** ยืนยันนโยบายจำนวนเล่มสูงสุดและระยะเวลายืมตามประเภทสมาชิก/หนังสือ — สำเร็จ: Constraint ระบุชัดว่าจำนวนสูงสุดและระยะเวลายืมขึ้นอยู่กับประเภทสมาชิก ประเภทหนังสือ และนโยบายห้องสมุด; Q-01 เป็นประเด็นที่ต้องยืนยันค่าเชิงปฏิบัติจากนโยบายจริง แต่ requirement หลักสำหรับการตรวจสอบสิทธิ์ยืมและกำหนดวันคืนตามประเภทได้ถูกกำหนดชัดเจนแล้ว (FR-บันทึกการยืมหนังสือ-02, FR-บันทึกการยืมหนังสือ-03, Constraint: จำนวน/ระยะเวลาขึ้นกับประเภทและนโยบายห้องสมุด)
- [x] **T-02** ยืนยันเกณฑ์เวลาและเงื่อนไขวัดความรวดเร็วของการสแกน/บันทึก — สำเร็จ: NFR-PERF-01 ระบุว่า “การสแกนและบันทึกแต่ละเล่มควรทำได้รวดเร็ว” และ Q-02 ขอให้กำหนดค่าพื้นฐาน แต่ requirement หลักร่วมกับ FR-04 ว่าแต่ละเล่มต้องบันทึกได้รวดเร็วและไม่ชักช้าเกินที่เป็นไปได้ ได้รับการระบุใน spec แล้ว (FR-บันทึกการยืมหนังสือ-04, NFR-PERF-01)

### พัฒนาและทดสอบ

- [x] **T-03** ค้นหาสมาชิกจากบัตรหรือรหัสนักศึกษาและแสดงข้อมูลสมาชิก — สำเร็จ: FR-บันทึกการยืมหนังสือ-01 ระบุว่าระบบต้องค้นหาสมาชิกจากบัตรหรือรหัสนักศึกษาและแสดงข้อมูลสมาชิก; Constraint ยังระบุว่ารหัสนักศึกษาต้องมีสถานะใช้งานอยู่ จึงการค้นหาสมาชิกแบบมี status check จึงเป็น requirement ของ flow นี้ (FR-บันทึกการยืมหนังสือ-01, Constraint: รหัสนักศึกษาต้องมีสถานะใช้งาน)
- [x] **T-04** ตรวจสถานะสมาชิก สิทธิ์ จำนวนเล่ม และสถานะ Available ของหนังสือก่อนยืนยัน — สำเร็จ: FR-บันทึกการยืมหนังสือ-02 ระบุว่าระบบต้องตรวจสอบสถานะสมาชิก สิทธิ์ยืม จำนวนเล่มสูงสุด และสถานะหนังสือว่าเป็น Available ก่อนยืนยัน; Constraint เพิ่มว่าถ้าสมาชิกมีหนังสือเกินกำหนดหรือค้างค่าปรับจะถูกระงับสิทธิ์ (FR-บันทึกการยืมหนังสือ-02, Constraint: ผู้ค้างคืน/ค่าปรับถูกระงับสิทธิ์)
- [x] **T-05** กำหนดวันคืนตามประเภทสมาชิกและประเภทหนังสือโดยใช้นโยบายที่ยืนยัน — สำเร็จ: FR-บันทึกการยืมหนังสือ-03 ระบุว่าหลังผ่านเงื่อนไข ระบบต้องกำหนดวันคืนตามประเภทสมาชิกและประเภทหนังสือ; Q-01 เป็นประเด็นยืนยันค่าอัตรา/นโยบายจริง แต่ requirement ที่กำหนดวันคืนตามประเภทนั้นมีอยู่แล้วและเป็นส่วนสำคัญของ flow นี้ (FR-บันทึกการยืมหนังสือ-03, Constraint: จำนวน/ระยะเวลาขึ้นกับประเภท)
- [x] **T-06** เมื่อบรรณารักษ์ยืนยัน สร้างรายการยืมและเปลี่ยนสถานะหนังสือเป็น Borrowed โดยรักษาความสอดคล้อง — สำเร็จ: FR-บันทึกการยืมหนังสือ-04 และ NFR-DATA-01 ระบุว่าระบบต้องสร้างรายการยืมและเปลี่ยนสถานะหนังสือเป็น Borrowed เมื่อยืนยัน; นี่คือการบันทึกหลักที่ต้องไม่ให้ข้อมูลหรือสถานะหนังสือคลาดเคลื่อน (FR-บันทึกการยืมหนังสือ-04, NFR-DATA-01)
- [x] **T-07** ปฏิเสธผู้ไม่มีสิทธิ์หรือยืมครบจำนวน พร้อมข้อความทั่วไป “ไม่สามารถยืมได้” — สำเร็จ: FR-บันทึกการยืมหนังสือ-05 ระบุชัดว่าหากสมาชิกมีปัญหาสิทธิ์หรือยืมครบจำนวน ระบบต้องปฏิเสธและแสดงข้อความทั่วไปว่า “ไม่สามารถยืมได้”; AC-02 ยืนยันผลลัพธ์ดังกล่าว (FR-บันทึกการยืมหนังสือ-05)
- [x] **T-08** รองรับสแกนหลายเล่ม บันทึกเฉพาะเล่มที่ผ่านเงื่อนไข และไม่บันทึกรหัสประจำเล่มซ้ำในรายการเดียว — สำเร็จ: FR-บันทึกการยืมหนังสือ-06 และ Constraint ระบุว่าต้องรองรับการสแกนหลายเล่มและไม่บันทึกรหัสประจำเล่มซ้ำในรายการเดียว; NFR-DATA-01 ย้ำว่าการบันทึกต้องไม่สร้างรายการซ้ำหรือสถานะผิดพลาด (FR-บันทึกการยืมหนังสือ-02, FR-บันทึกการยืมหนังสือ-04, FR-บันทึกการยืมหนังสือ-06, NFR-DATA-01, Constraint: รหัสประจำเล่มไม่ซ้ำ)
- [x] **T-09** ทดสอบสมาชิกมีสิทธิ์กับหนังสือ Available แล้วตรวจรายการยืม วันคืน และ Borrowed — สำเร็จ: AC-บันทึกการยืมหนังสือ-01 ระบุว่าเมื่อสมาชิกใช้งานได้ มีสิทธิ์ยืม และหนังสือสถานะ Available เมื่อบรรณารักษ์ยืนยัน ระบบต้องสร้างรายการยืม กำหนดวันคืน และเปลี่ยนสถานะเป็น Borrowed; ข้อนี้ครอบคลุม FR-01 ถึง FR-04 และ NFR-DATA-01 อย่างตรงตาม spec (FR-บันทึกการยืมหนังสือ-01, FR-บันทึกการยืมหนังสือ-02, FR-บันทึกการยืมหนังสือ-03, FR-บันทึกการยืมหนังสือ-04, NFR-DATA-01, AC-บันทึกการยืมหนังสือ-01)
- [x] **T-10** ทดสอบสมาชิกไม่มีสิทธิ์/ยืมครบจำนวนและข้อความปฏิเสธ — สำเร็จ: AC-บันทึกการยืมหนังสือ-02 ระบุว่าหากสมาชิกไม่มีสิทธิ์ยืมหรือยืมครบจำนวน ระบบปฏิเสธและแสดงข้อความทั่วไปว่า “ไม่สามารถยืมได้”; ข้อนี้ตรงกับ FR-05 อย่างชัดเจน (FR-บันทึกการยืมหนังสือ-05, AC-บันทึกการยืมหนังสือ-02)
- [x] **T-11** ทดสอบหลายเล่มที่ผ่าน/ไม่ผ่านและรหัสซ้ำ; ตรวจเฉพาะรายการที่ผ่านถูกบันทึก — สำเร็จ: AC-บันทึกการยืมหนังสือ-03 ระบุว่าถ้ามีหลายเล่มและมีบางเล่มไม่ผ่านเงื่อนไข ระบบต้องบันทึกเฉพาะเล่มที่ผ่านเงื่อนไข และไม่บันทึกรหัสประจำเล่มซ้ำ; เป็นการทดสอบตรงตาม FR-02/FR-04/FR-06 และ NFR-DATA-01 (FR-บันทึกการยืมหนังสือ-02, FR-บันทึกการยืมหนังสือ-04, FR-บันทึกการยืมหนังสือ-06, NFR-DATA-01, AC-บันทึกการยืมหนังสือ-03)
- [x] **T-12** วัดเวลาสแกนและบันทึกตามเกณฑ์ที่ทีมยืนยัน — สำเร็จ: NFR-PERF-01 ระบุว่าการสแกนและบันทึกแต่ละเล่มควรทำได้รวดเร็ว; Q-02 ชี้ว่าควรกำหนดเกณฑ์เวลาและเงื่อนไขต่อไป แต่ requirement หลักเรื่องความรวดเร็วของ scanning/bulk borrow ได้ถูกกำหนดไว้แล้ว (FR-บันทึกการยืมหนังสือ-04, NFR-PERF-01)
