# งาน: บันทึกการยืมหนังสือ

อ้างอิง: SPEC-บันทึกการยืมหนังสือ-011 (Draft v2)

## ลำดับงาน

### ยืนยันประเด็นคงค้าง

- [ ] **T-01** ยืนยันนโยบายจำนวนเล่มสูงสุดและระยะเวลายืมตามประเภทสมาชิก/หนังสือ — **รอ Q-01** (FR-บันทึกการยืมหนังสือ-02, FR-บันทึกการยืมหนังสือ-03, Constraint: จำนวน/ระยะเวลาขึ้นกับประเภทและนโยบายห้องสมุด)
- [ ] **T-02** ยืนยันเกณฑ์เวลาและเงื่อนไขวัดความรวดเร็วของการสแกน/บันทึก — **รอ Q-02** (FR-บันทึกการยืมหนังสือ-04, NFR-PERF-01)

### พัฒนาและทดสอบ

- [ ] **T-03** ค้นหาสมาชิกจากบัตรหรือรหัสนักศึกษาและแสดงข้อมูลสมาชิก (FR-บันทึกการยืมหนังสือ-01, Constraint: รหัสนักศึกษาต้องมีสถานะใช้งาน)
- [ ] **T-04** ตรวจสถานะสมาชิก สิทธิ์ จำนวนเล่ม และสถานะ Available ของหนังสือก่อนยืนยัน (FR-บันทึกการยืมหนังสือ-02, Constraint: ผู้ค้างคืน/ค่าปรับถูกระงับสิทธิ์)
- [ ] **T-05** กำหนดวันคืนตามประเภทสมาชิกและประเภทหนังสือโดยใช้นโยบายที่ยืนยัน — **รอ Q-01** (FR-บันทึกการยืมหนังสือ-03, Constraint: จำนวน/ระยะเวลาขึ้นกับประเภท)
- [ ] **T-06** เมื่อบรรณารักษ์ยืนยัน สร้างรายการยืมและเปลี่ยนสถานะหนังสือเป็น Borrowed โดยรักษาความสอดคล้อง (FR-บันทึกการยืมหนังสือ-04, NFR-DATA-01)
- [ ] **T-07** ปฏิเสธผู้ไม่มีสิทธิ์หรือยืมครบจำนวน พร้อมข้อความทั่วไป “ไม่สามารถยืมได้” (FR-บันทึกการยืมหนังสือ-05)
- [ ] **T-08** รองรับสแกนหลายเล่ม บันทึกเฉพาะเล่มที่ผ่านเงื่อนไข และไม่บันทึกรหัสประจำเล่มซ้ำในรายการเดียว (FR-บันทึกการยืมหนังสือ-02, FR-บันทึกการยืมหนังสือ-04, FR-บันทึกการยืมหนังสือ-06, NFR-DATA-01, Constraint: รหัสประจำเล่มไม่ซ้ำ)
- [ ] **T-09** ทดสอบสมาชิกมีสิทธิ์กับหนังสือ Available แล้วตรวจรายการยืม วันคืน และ Borrowed — **รอ Q-01** (FR-บันทึกการยืมหนังสือ-01, FR-บันทึกการยืมหนังสือ-02, FR-บันทึกการยืมหนังสือ-03, FR-บันทึกการยืมหนังสือ-04, NFR-DATA-01, AC-บันทึกการยืมหนังสือ-01)
- [ ] **T-10** ทดสอบสมาชิกไม่มีสิทธิ์/ยืมครบจำนวนและข้อความปฏิเสธ (FR-บันทึกการยืมหนังสือ-05, AC-บันทึกการยืมหนังสือ-02)
- [ ] **T-11** ทดสอบหลายเล่มที่ผ่าน/ไม่ผ่านและรหัสซ้ำ; ตรวจเฉพาะรายการที่ผ่านถูกบันทึก (FR-บันทึกการยืมหนังสือ-02, FR-บันทึกการยืมหนังสือ-04, FR-บันทึกการยืมหนังสือ-06, NFR-DATA-01, AC-บันทึกการยืมหนังสือ-03)
- [ ] **T-12** วัดเวลาสแกนและบันทึกตามเกณฑ์ที่ทีมยืนยัน — **รอ Q-02** (FR-บันทึกการยืมหนังสือ-04, NFR-PERF-01)
